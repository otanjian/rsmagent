# macOS SAP 登录记忆

SAP 工作台顶部提供「记住 SAP 登录」。确认后保存当前站点的 SAP Cookie；下一次在 SAP 登录表单成功登录后，再保存账号密码。会话过期时只自动填入，登录仍由用户点击。平台登录凭据继续只在内存中。

本机文件位于 Electron userData 下的 `sap-login/`，只含 `safeStorage` 密文；macOS 钥匙串保存加密密钥。记录按平台地址、平台账号、团队、SAP 地址路径及 Client 分开。其他 SAP / SSO 来源和平台 Cookie 不保存。跨团队切换会清理前一范围在内存中的 SAP Cookie。SAP 服务端到期、注销和策略仍然生效。

「清除已记住的 SAP 登录」删除当前范围的记忆，保留正在打开的 SAP 会话；下次启动需重新登录。未启用时不保存；钥匙串不可用时不退回明文。密码不经过远程服务端、OpenCode、模型、宿主桥返回值或应用日志。

实现范围为 macOS、直接嵌入的 NetWeaver `loginForm`，识别 `sap-user` / `sap-password` / `sap-client`；不处理密码修改、SSO 或通用网站表单，不覆盖用户已修改的非空输入。会话 Cookie 最长保留 30 天，SAP 可更早使其失效。
