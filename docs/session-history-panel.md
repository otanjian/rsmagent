# 历史面板与 master 对齐

实现基线：master `48c0d79c36146950667f8d1884ab823deae62305`。修改落在 rdai 的实际 Web 页面，保留业务菜单、配色及后台接口。

- 聊天时统一通过左侧「新建对话」发起，历史面板不重复放置新对话按钮；完整历史页保留自己的新建操作。
- 点击主导航「历史会话」在该菜单下展开／收起完整列表，聊天顶部历史按钮打开同一列表。没有独立中间栏、重复标题或历史遮罩；默认收起，开关偏好按账号／租户保存。
- 历史面板按时间或空间分组，可继续滚动加载全部授权会话，不再限制 5／10 条。项目数量表示当前已加载的已保存记录数。
- 「查看全部」进入原历史页搜索；返回面板显示未筛选历史，再回完整页恢复搜索词。切换展示会从第一页读取，不保存滚动位置。
- 行尾更多菜单提供置顶、重命名、归档和删除；按钮占独立位置，F2 可重命名。普通列表重命名成功原地更新，保留已加载记录和滚动位置；搜索或有延后刷新时重查。「已归档」仍使用既有弹窗及其 50 条上限。
- 主动新建立即显示当前未发送的临时项，发送并保存后替换为正式记录；临时项不提供持久化管理操作，不创建空后端记录。刷新页面不恢复临时项。
- 手机及窄屏复用主导航抽屉，页面刷新时不自动打开抽屉；选择或新建对话后收起主导航，保留历史展开偏好。桌面折叠导航时隐藏历史，从历史入口打开会展开导航。
- 菜单、完整页和顶部提示统一为「历史会话」。语言切换同步更新分组、菜单和状态，编辑期间延后重绘，避免丢失输入。

主导航、品牌区、历史行与新对话菜单保留紧凑密度。六个工作台菜单的图标、文字分别左对齐，项目和会话保留层级缩进；折叠时菜单图标居中。主导航展开宽 208px，内嵌历史跟随导航宽度，品牌及聊天头部高 56px；原 72px 折叠主导航保留。历史列表使用导航剩余高度滚动；极低高度时菜单也可滚动，底部账号保持可达。

本次只新增面板模板、样式和展示适配；列表、查询、分页、会话操作及流处理仍由 `console.js` 统一提供。实际装载顺序为 `console.js` 后加载 `fork/views/sessions.js`，不加载上游第二份 sessions 实现。资源沿用模板版本戳，无数据库或业务数据迁移。

浏览器复查可运行 `node tests/support/session_history_preview.cjs`，访问输出的本地端口。该页面使用生产模板装配和静态资源，后端是独立内存中的 63 条测试会话；`?dark` 查看深色，`?classic` 关闭旧侧栏启动布局开关。测试数据不会写入业务数据库。关闭进程即可清理。

来源指纹、差异和验收结果见 `openspec/changes/align-session-history-with-master/evidence/`。OpenSpec 的两份 delta 已替换“不使用面板”和“5／10 条预览”的旧要求；归档时将 delta 合入主规范并同步 Purpose，本次 apply 不提前归档或修改其他 change。

## 编码会话的归档、恢复与删除（fix-coding-session-history-management）

编码会话沿用同一份历史面板、行菜单和归档弹窗，本 change 只收紧这条既有链路，不新增接口、开关或数据迁移。

- 归档／恢复／删除请求等待期间，目标行显示忙碌态并锁定指针事件；同一操作、目标 Agent 与会话在应答落地前不重复提交。失败保留记录、沿用既有 toast 说明原因，解除等待后可以再次操作；HTTP 失败与业务失败按同一路径处理，权限拒绝不扩大作用域。
- 成功回调重新校验身份上下文与当前选中会话：用户已切到别的会话或换了身份时只刷新列表，不强制跳转、不关闭后来打开的内容。恢复只重绘仍然打开的那个归档弹窗，迟到的应答不写进重新打开的列表。
- 删除当前最后一条编码会话且没有相邻项时，关闭原编码视图并进入空态（`#coding-empty-state`）：保留编码智能体的选中状态、清除已删除会话引用、隐藏普通输入区，只留一个显式「新建编码会话」入口，由既有 `newChat → seam.open` 创建，MUST NOT 自动创建远端会话。刷新页面也不会重开被删会话。有相邻会话时仍走普通 `switchSession`；普通会话仍使用原来的未持久化新对话行为。
- 选中编码智能体但没有挂载编码视图时（含删除后的空态），普通发送由 `guardCodingMessage` 直接拒绝：既不代用户创建编码会话，也不进入普通执行器，用户草稿保留并提示编码入口。
- 删除分流在服务端严格区分「普通会话」「有效编码关联」与「关联读取异常」：读取异常或已有编码记录缺关联时返回可辨识失败并保留记录，不降级为普通会话清理；已确认不存在的重复删除沿用既有幂等与权限边界。
- 文案覆盖 zh／en／zh-Hant 三语；样式追加在既有 `console.css`／`coding.css`，脚本仍在 `console.js` 内，资源沿用模板的按文件版本戳，无新增静态资源清单项。本 change 无数据迁移，代码回退不回滚已归档／已删除数据。
