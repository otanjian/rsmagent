# 桌面端指定证书例外

测试环境经用户明确授权后，可在本机 `${COW_HOME}/desktop-certificate-pins.json` 保存证书例外；未设置 `COW_HOME` 时使用 `~/.cow/desktop-certificate-pins.json`。这是本机配置，重启桌面端后继续生效，不随服务端页面或账号同步。

文件为 JSON 数组，每项包含精确 HTTPS origin（包括非默认端口，不带路径或末尾斜杠）和当前证书的 SHA-256 指纹：

```json
[
  {
    "origin": "https://sap.example:44300",
    "fingerprint": "填入经核实的 64 位十六进制 SHA-256 指纹"
  }
]
```

只有地址和指纹同时匹配，远程工作台容器才接受该证书错误。其他地址继续执行正常 TLS 验证，不修改系统证书库，也不使用全局忽略证书错误开关。若站点更换了仍不受信任的证书，需要重新核实并授权新的指纹；受正常信任的新证书无需例外。

删除对应记录并重启桌面端即可撤销例外。文件缺失、格式错误或指纹不匹配均不会放行。
