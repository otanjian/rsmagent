# 出口开票工作台交互原型

主文件：`index.html`；`dist/index.html` 是相同内容的本地预览副本。单文件、自包含 HTML，CSS、图标、脚本和演示数据全部内嵌，不需要安装前端依赖。

## 页面范围

1. 开票工作台：业务指标、处理进度、待办及重点异常。
2. 待开票业务：搜索、状态筛选、分页、批量选择、草稿生成和清单导出。
3. 单据匹配：报关明细与多个交货行匹配、分配数量核对及政策确认。
4. 开票草稿：运保费及汇率编辑、FOB 与人民币实时计算、保存与提交审核。
5. 审核中心：资料检查、审核意见、退回修改与确认通过。
6. 开票记录：模拟成功、超时及明确失败；按原申请查证；票面、回执及红冲。
7. SAP 对账：回写、失败重试、税票与凭证核对、红冲后续调整。
8. 异常处理：原因、责任岗位、指派及处理历史。
9. 商品映射：查询、新增、维护、复核及未开票草稿重新校验。
10. 数据接入：来源说明、CSV 模板与本机导入、示例批次。
11. 业务规则：新业务默认汇率、舍入差复核阈值、控制规则及演示重置。

同时提供业务详情抽屉、来源单据预览、通知、操作记录与智能助手示例。

## 建议体验路径

- 首页 Northwind Textiles：生成草稿 → 修改运费 → 提交审核 → 勾选审核确认 → 审核通过 → 选择模拟开票结果 → SAP 对账。
- Mekong Apparel：单据匹配 → 尝试取消一个交货候选，检查数量拦截 → 完整确认关联 → 商品映射复核 → 生成草稿。
- Nordic Living：开票记录 → 查证结果 → 查到已出票或确认未开具，观察后续状态。
- Orion Textile：SAP 对账 → 重试回写 → 选择模拟成功或连接失败。
- 任一已开票记录：红冲 → 填写金额与依据 → SAP 对账处理红冲调整。
- 数据接入：加载示例批次，或下载并填写 CSV 模板后导入。
- 业务规则：重置演示，恢复初始 12 笔业务。

## 原型边界

- 公司、客户、单据、编码、税票及岗位均为示例。编码不能用于正式开票。
- 诺诺、SAP、关务、电子税务局均未连接，不会开具真实发票或写入真实账务。
- 智能助手基于本机规则生成演示回答，未调用在线模型；来源预览是结构化示例，不是真实单据 OCR。
- CSV 文件在浏览器本机解析，不上传服务器。操作保存在该浏览器的 localStorage；不同浏览器及不同打开地址不共享状态。
- 单机交互用于评审业务与界面，不实现生产环境的多用户权限、后端事务、财务精度引擎或真实接口。

## 已完成的检查

- 内嵌 JavaScript 语法检查。
- 11 个页面切换及页面标题检查，浏览器错误日志无运行错误。
- 草稿生成、费用实时计算、提交审核及未勾选审核确认时的拦截。
- 开票超时后查证、补录回执、SAP 回写失败及独立重试。
- 多行匹配数量不一致拦截、关联确认及商品映射启用。
- 部分红冲、对账差额呈现及后续调整。
- 示例批次导入、业务搜索、初始数据恢复。
- CSV 解析的 BOM、CRLF、引号、带逗号字段及引号未闭合错误处理。
- 1440 像素桌面布局与 390 像素窄屏布局；窄屏整页无横向溢出，表格在容器内横向浏览。
- 可选 WebMCP 的状态读取、页面导航及无效参数拒绝；普通浏览器不依赖该能力。

浏览器工具不支持访问 `file://`，因此交互验证通过本地 HTTP 完成；未声称已在所有浏览器中逐一验证本地文件打开。
