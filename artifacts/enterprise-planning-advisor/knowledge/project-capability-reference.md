# 本项目能力匹配参考

来源：本地 rsmagent 项目结构及2026年10月21日目标网站界面。本文用于选择验证方向；具体能力须以当前部署、授权和实际试用结果为准。

## 可以参考的能力结构

项目支持普通智能体的角色说明、核心文件、技能选择和独立知识库。智能体配置可承载职责、开场语、建议问题和专属技能；本次“企业智能体规划顾问”使用该方式配置。

知识库可用于存放稳定方法、问题库、规则和模板。企业实际访谈记录应保存在当前用户获权工作区，并按企业和会话区分，不能直接汇入面向其他受访者的通用方法。

当前网站工具目录展示了 read、write、edit、ls、search_files、send、excel、web_search、web_fetch、vision 等能力。工具展示不保证所有外部服务配置齐全；每次使用须以实际返回为准。

| 业务需要 | 可检查的能力 | 试点验证重点 |
| --- | --- | --- |
| 企业公开背景 | web_search 与 web_fetch | 是否能取得可靠来源，是否匹配企业主体和业务时期 |
| 文档和工作材料读取 | read、必要时 vision | 实际格式是否可读、表格与扫描质量、出处是否可追溯 |
| 知识查询与依据整理 | 专属知识库、read、search_files | 知识是否最新、是否能检索并引用正确出处 |
| 多表核对及资料整理 | read、excel、业务匹配规则 | 字段口径、编号、单位、期间、异常与复核工时 |
| 报告与工作清单 | write、edit、send | 输出模板、可验证内容、资料准备及人工修改量 |

## 业务场景参考范围

项目的 Scene/catalog.json 列有采购、销售、生产、人事、财务、质量、法务、IT和行政等类别，以及 supplier、analysis、tender、customer、plan、quality、recruit、finance、sap、legal_review 等相关场景条目。只能据此提出“检查是否有可复用资源”的建议，不能宣称这些模块都已部署、获权或适用于用户。

本地 agent/presets/rfq_quote 示例展示了从询价输入、成本依据、逐项核对到报价草稿和人工复核的配置思路。适用性仍需具体任务、数据和规则验证，不能直接承诺自动报价。

## 匹配方法

先确认任务的输入、步骤、输出及复核方式，再查当前实际可用能力。对每项建议使用以下状态：

- 已核实可用：在当前部署及授权内完成了与任务相关的样本验证，并记录证据。
- 已有能力但待配置或验证：有对应能力线索，尚缺规则、资料、连接或真实样本验证。
- 需要额外建设：当前没有可行的现成路径，明确差距，不假设本次调研即可上线。

不要自动生成开发变更、创建下游智能体或执行外部业务操作。先选择一个岗位、一类输入、一个可检查步骤试点；使用后资料准备、操作、复核、纠错和维护成本全部计入。
