# 图纸询价智能报价

交付 `成本核算表.xlsx`、`报价单草稿.xlsx`、`待确认清单.xlsx`。先说明报价当前能否发出及原因，再给出实际生成文件的下载链接。用户只要历史校核或风险复核时，按其范围处理。

## 数据与口径

- 先读询价邮件、图纸、历史报价库、材料价格表、工时费率表，核对版本、币种、单位、税口径和有效期。每个参数和成本行记录文件名、工作表/单元格或图纸页码、版本与取值理由。
- 使用本次用户材料。缺少资料要列缺口，不从演示数据补进真实订单。只有用户明确要求演示、体验或使用内置资料时，才使用 `assets/demo/`，所有成果注明虚构演示。
- 资料只有文字引用图纸、图片模糊、DWG 无法解析时，如实说明未读取到的内容，请用户提供清晰 PDF/图片或人工参数；不得把演示参数说成 OCR 结果。装配图需人工拆分，模具/注塑需另建模型。
- 行业经验、参考模板均不是企业已批准政策。利用率、定额、加成率、管理费率和审批下限必须注明来源或“待确认假设”。`references/upstream-*.md` 是原始参考，其中示例金额和工时不完全一致；以下规则与实际输入优先，不照抄示例合计。

## 报价流程

1. 核对件号、数量、尺寸、材质、料厚、焊接、表处、外购件、公差、交期、包装运输、付款条款。可有依据地估算的缺项，用明确假设继续核算；无法量化的关键缺口列为待复核，不填零。
2. 提取净展开面积、厚度、密度、利用率、折弯数、焊缝长度、孔牙数、表面处理和精度要求。长圆孔/百叶孔需说明利用率调整理由；焊接件核对打磨，有平面度要求核对校平。净作业速度不等于含装夹的完整工时，不能直接把秒数当工时定额。
3. 按结构、材质料厚、面积、工序、表处找相似件，列出匹配依据和局限。只能用历史**实际成本**反算；逐项记录价格、面积、工序和数量差异修正。缺少工序/表处信息时不能编造匹配分数。读取历史复盘归因，命中同类损失则升级风险。
4. 直接材料（含废料抵减）+ 加工 + 表处（前处理单列）+ 包装运输 = 制造成本；制造成本 + 管理费 = 总成本。第六项是总成本，不能重复加总。重量保持精度，逐行金额四舍五入至分，再加总；用程序生成真实公式。
5. 常规、加急、批量逐档列成本调整。加急仅调整真实成本，加成率与常规相同；批量折扣按每项依据计算，检查数量是否达到阶梯，重算管理费。列加成率、按实际舍入单价计算的毛利率和订单毛利额。触及企业加成下限标记经理审批。不得自动承诺生产交期。
6. 风险取定性与金额的较高等级：材料/厚度/焊接等级/热处理/关键公差、历史同类损失或单项总成本影响超过 5% 为 A；1% 至 5% 或表处/外购品牌/包装未定至少 B；其余 C。每项列原假设、替代口径、单台及订单敞口、来源、负责人、期限、确认依据。未知金额保持“待评估”并阻止放行。

历史同口径偏差超过 8% 时先自查单位、漏项、工时和口径；修正后仍超限则停止报价。3% 至 8% 需解释来源并复核；无可靠实际成本校核时标为缺少校核依据并交技术复核。未解决 A 级、关键资料缺失或审批未完成时只能交付内部草稿，可拟区间说明和澄清函草稿，不自动发送或对外承诺。任何发邮件、写 ERP、改变台账、建立定时任务都必须有对应用户指令。

## 可执行核算

脚本路径相对本 SKILL.md。使用本项目 Python 环境（依赖见 `requirements.txt`），不下载或执行第三方安装器。

```sh
python scripts/quote.py --demo --output /当前工作区/outputs/本次询价
python scripts/quote.py --input /当前工作区/本次询价.json --output /当前工作区/outputs/本次询价
```

第一条仅用于明确的演示请求。真实订单先按 `references/input-format.md` 把本次资料提取为 JSON，保留取数依据，然后执行第二条。脚本是钣金成本核算与报表生成器，不负责 OCR、自动猜测工时或查 ERP。其他件类按实际成本模型处理，不能硬套面积/利用率公式。

脚本还生成 `核算结果.json` 供核对。校核不通过或有 A 级风险时仍生成带阻塞原因的**内部草稿**，不得把生成成功解释为允许发出。Excel 是本次输入的可复核快照；修改假设后重新运行，三个文件之间不建立外部链接。报价放行结论需重新核算与人工审批，不能仅靠编辑一格删除标记。

## 演示资料的局限

原台账只有 5 条记录，邮件中的图纸引用不代表附有可读取图纸；不得声称读了 14 条或识别了不存在的图纸。示例工时定额及若干辅料来自原模板，校平费和加急/批量差额来自原演示说明，均在输入中标注为演示假设。历史库不足以完整还原旧件各项成本，因此演示保留“历史校核未完成”，不伪造通过结果。真实报价要换成企业自己的完整依据。
