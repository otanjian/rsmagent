### 2.1 下料重量测算

| 项目 | 算式 | 数值 |
|---|---|---|
| 单位面积重量 | 板厚(mm) × 密度(g/cm³) | ____ kg/m² |

| 工序 | 工作量 | 标准工时 (h) | 费率 (元/h) | 金额（元/台） | 备注 |
|---|---|---|---|---|---|
| 激光 / 数冲下料 | | | | | |
| 折弯 | 处（二次装夹 处） | | | | 超行程按 1.6倍系数 |
| 冲孔 / 攻牙 | | | | | |
| 焊接 | m（密封焊 m） | | | | 满焊 = 段焊 × 1.4 |
| 焊后打磨 | | | | | 按焊接工时 35%-45% |
| 校平 / 整形 | | | | | 平面度 ≤ 1.0mm/m 必计 |
| 组装 / 铆接 | | | | | |
| **② 加工费合计** | | **____ h** | | **** | |

> ⚠ **「关键系数」不是工时定额 —— 不要把秒数直接 ÷ 3600。**
> 工序标准工时表里的 `秒/处`、`m/min` 是**净作业速度**，只用于工序增删时的**相对比较**；
> 真实工时还含装夹、上下料、清渣、首件复检等现场开销。
> **本技能认可的工时定额以 §9 算例的取值为准**：
> 下料 0.42 h、折弯 0.55 h（18 处）、冲孔攻牙 0.18 h（M6×24 处）、焊接 0.65 h（2.40 m，段焊口径）、
> 焊后打磨 = 焊接工时 × 40%、组装铆接 0.30 h。
> 换成别的件时**按处数 / 米数比例折算**（例：27 处折弯 → 0.55 × 27 ÷ 18 = 0.83 h）。
> 按这个口径算出来的成本能复现 §9，也能通过 Step 3 的偏差校核；直接拿系数换算会低约 11%，
> 会被 Step 3 误判成「核算有问题」。

### 口径红线

```
制造成本 = ① + ② + ③ + ④
总成本   = 制造成本 + ⑤
报价     = 总成本 × (1 + 加成率)
毛利率   = (报价 − 总成本) ÷ 报价 = 加成率 ÷ (1 + 加成率)
```

**加成率 ≠ 毛利率。** 对内核算说加成率，对客户和财务说毛利率。

## 九、完整算例（华东电气 P-CAB-02 户外机柜钣金件 · 120 台）

### 9.1 参数

| 参数 | 数值 |
|---|---|
| 材质 / 板厚 | SPCC 冷轧板 / 2.0 mm |
| 单位面积重量 | 2.0 × 7.85 = **15.70 kg/m²** |
| 展开面积（净） | **3.86 m²** |
| 板材利用率 | **78%**（含 32 个长圆百叶孔 → 取中等复杂区间下段） |
| 下料面积（毛） | 3.86 ÷ 0.78 = **4.95 m²** |
| 下料重量（毛） | 4.95 × 15.70 = **77.72 kg** |
| 废料重量 | (4.95 − 3.86) × 15.70 = **17.11 kg** |
| 折弯 | 18 处（4 处需二次装夹） |
| 焊接 | 2.40 m（密封焊 1.65 m） |
| 表面处理 | 户外粉末喷涂 60-80μm（按盐雾 500h 档） |

## 十、测算表自检清单（发出报价前必过）

- [ ] 材料费用的是**下料重量（毛）**，不是净展开重量
- [ ] 废料回收抵减已计入
- [ ] 板材利用率的取值理由已写明
- [ ] 表面处理按**展开面积（净）**计，前处理已单列
- [ ] 焊后打磨工时已计入（按焊接工时 35%-45%）
- [ ] 折弯超行程的二次装夹系数已计入
- [ ] 出口件的熏蒸木箱与贸易术语已确认
- [ ] 六项成本占比落在健康区间（见 SKILL §6.3）
- [ ] 加成率与毛利率两个数分开列，没有混用
- [ ] 报价有效期已按材料占比设定
- [ ] Step 3 双路径校核偏差 ≤ ±3%
- [ ] A 级风险项已全部技术复核并签字
