# 报价风险清单（A / B / C 三级）

> **用途**：报价发出前的风险自查表+ 报价单标准免责条款
> **配套**：`SKILL.md` §2 Step 6 风险与不确定项标注
> **版本**：v1.0 · 2026-08

---

## 一、分级标准

| 等级 | 判定条件 | 处置 | 时限 | 是否阻塞报价 |
|---|---|---|---|---|
| **A 级** | 单项影响 > 总成本 **5%**；或涉及材质/ 板厚 / 热处理 / 焊接等级 / 关键公差 | 技术复核后才可对外报价 | 技术 4 小时内回 | **阻塞** |
| **B 级** | 单项影响总成本 **1%-5%**；表面处理等级 / 外购件品牌 / 包装方式未定 | 可先报价，报价单写明假设 + 差额条款 | 与报价同步发澄清函 | 不阻塞 |
| **C 级** | 单项影响 < 总成本 **1%** | 内部记录备查，首件确认时核实 | 首件确认前 | 不阻塞 |

**判定原则**：**取最高等级作为整份报价的风险等级。** 只要有 1 项 A 级，整份报价必须先过技术复核。

**每一项风险必须写清三件事**：
1. 当前报价采用的口径
2. 换成另一个口径差多少钱（元/台 + 订单总差额）
3. 谁在什么时限内做什么动作

## 二、A 级风险全清单（必须技术复核）

| # | 风险项 | 图纸上的典型表现 | 默认报价口径 | 换口径的典型差额 | 复核动作 |
|---|---|---|---|---|---|
| A-01 | **板厚是否含镀层** | 只标t2.0，未注明镀层 | 按冷板（如SPCC）报 | 镀锌板单价高 0.8-1.0 元/kg，2.0mm 件约 **+60-70 元/台** | 技术确认牌号（SPCC / DX51D+Z / SGCC） |
| A-02 | **材质牌号不明** | 只写"冷板""不锈钢""铝板" | 按同客户历史订单推定 | 304→316L 差 **60%+**；SPCC→SPHC 差 3%-8% | 客户书面确认牌号 |
| A-03 | **焊缝等级 / 是否满焊** | 标"IP55 密封"但无焊缝符号说明 | 按段焊报 | 满焊工时是段焊 1.4 倍，含打磨与焊材约 **+40-50 元/台** | 技术确认焊接工艺规范 |
| A-04 | **关键配合公差未标** | 关键孔距 / 平面度 /垂直度无标注 | 按对应国标常规等级 | 加严等级需增加校平 / 二次加工 / 全检，**+5%-12% 加工费** | 技术确认公差要求 |
| A-05 | **热处理 / 特殊工艺要求不明** | 提到"需退火""需去应力"但无参数 | 不计入 | 热处理工序约 **+8%-15% 制造成本** | 技术确认工艺路线 |
| A-06 | **数量与批次未定** | 客户只说"先报个价" | 按客户口述数量 | 批量摊薄差 **5%-10%** | 客户确认订单量与交付批次 |
| A-07 | **无任何历史相似件（相似度 < 70%）** | 全新结构 | 逐项自下而上核算 | 校核失效，估算误差可能达 **±10%** | 技术 + 工艺双人复核，加成率 +3~+5 点 |
| A-08 | **图纸仅为手机照片 / 草图** | 客户随手拍 | 尺寸类参数标"待确认" | 尺寸误差直接放大到材料与工时全链 | 索要正式图纸；有效期缩至 7 天 |

## 三、B 级风险全清单（可报价+ 必须注明）

| # | 风险项 | 默认报价口径 | 换口径的典型差额 | 报价单必须写的话 |
|---|---|---|---|---|
| B-01 | **盐雾时长未定** | 按500h 档报 | 720h 档表处单价 +15%（相对 500h），约 **+25-30 元/台** | 「本报价按盐雾 500h 口径，如需 720h 另加 __ 元/台」 |
| B-02 | **喷涂膜厚 / 层数未定** | 按单层 60-80μm | 底粉+面粉双层 **+30%-40% 表处费** | 「按单层粉末喷涂报价」 |
| B-03 | **外购五金品牌未指定** | 按国产件报 | 进口件常高 **60%-100%** | 「五金件按国产件报价，指定品牌另计」 |
| B-04 | **包装方式未定** | 按客户历史方式 | 出口熏蒸木箱比普通木箱 **+30-60 元/台** | 「按__ 包装报价」 |
| B-05 | **运输责任 / 贸易术语未定** | 按国内汽运到厂 | FOB→DDP 差整段国际运费与关税 | 「本报价含国内运至__，不含 __」 |
| B-06 | **颜色 / 色号未定** | 按标准色（如 RAL7035） | 特殊色需单独调粉、清线，**+15-25 元/台** | 「按标准色报价，特殊色号另议」 |
| B-07 | **检验与出厂文件要求未定** | 按常规出厂检验 | 需第三方检测报告 / 材质证明 / 全检记录，**+2%-5%** | 「不含第三方检测费用」 |
| B-08 | **是否需要样品 / 首件确认** | 未计入样件成本 | 单件打样成本可达批量单价**2-4 倍** | 「样件费用另行报价」 |

## 四、C 级风险全清单（内部记录）

| # | 风险项 | 典型影响 | 处置 |
|---|---|---|---|
| C-01 | 折弯回弹造成展开偏差 | ±1.5% 展开面积 → 材料 + 表处影响 < 1% | 记入测算台账，首件实测后修正 K 因子 |
| C-02 | 铭牌 / 标签 / 说明书规格未定 | < 0.5% | 按通用规格计入辅料 |
| C-03 | 辅料差异（螺钉/ 铆钉 / 胶 / 标签） | < 0.5% | 按辅料定额计入 |
| C-04 | 工艺路线微调（如冲孔改激光切孔） | 工时差 < 1% | 由工艺部决定，不影响报价 |

| C-06 | 包装内衬缓冲材料选型 | < 0.5% | 按定额计入 |

## 六、报价单标准免责条款（可直接抄进报价单）

### 6.1 报价依据条款

```
本报价基于客户提供的图纸 [图号/版本] 及询价单[编号] 编制。
若正式技术协议或最终图纸与上述文件存在差异，本公司保留重新报价的权利。
```

### 6.2 材质与规格条款

```
本报价按 [材质牌号] [板厚] 口径编制，板厚不含镀层。
如实际要求为镀层板或其他牌号，价格另行核定。
```

### 6.3 表面处理条款

```
本报价按 [表面处理种类]、膜厚 [__]μm、耐中性盐雾 [__]h（GB/T 1771）口径编制。
如提高盐雾等级或膜厚要求，按 [__] 元/台差额另计。
颜色按标准色 [色号]，特殊色号另议。
```

### 6.4 焊接条款

```
本报价按 [段焊 / 满焊] 口径编制，焊缝总长 [__] m。
如要求全焊缝连续满焊，按 [__] 元/台差额另计。
```

### 6.5 外购件条款

```
本报价中五金配件按国产同等规格件计价。
如指定品牌或进口件，按实际采购价差额调整。
```

### 6.6 包装与运输条款

```
本报价含 [包装方式]，含国内运输至 [目的地]。
不含出口熏蒸、报关、国际运费及保险。贸易术语如有变更，价格另议。
```

### 6.7 有效期与价格调整条款

```
本报价有效期 [__] 天（自报价日起）。
主材价格波动超过 ±5% 时，双方应重新协商价格。
长期供货协议建议约定原材料价格联动机制。
```

### 6.8 数量条款

```
本报价基于数量 [__] 台。
数量变动超过 ±20% 时，单价需重新核定。
```

## 七、发出前自检（4 问）

1. **A 级项清零了吗？** —— 有一项没复核签字，就不能发。
2. **B 级项都在报价单里写明假设和差额了吗？** —— 只在内部记了不算，客户看不到等于没写。
3. **风险敞口占总成本多少？** —— 超过 15% 时，即使 A 级已复核，也建议改发区间报价。
4. **有效期设了吗？** —— 材料占比 > 45% 的件，超过 15 天就是在赌钢价。

## 八、常见"少赚钱"复盘归因表

拿这张表定期回溯实际毛利低于报价假设的单子，把归因结果回灌到本清单：

| 归因 | 对应风险项 | 复盘要更新什么 |
|---|---|---|
| 焊接口径报错（段焊 vs 满焊） | A-03 | 该客户 / 该件类的焊接默认口径 |
| 板厚含镀层未确认 | A-01 | 该客户图纸标注习惯的备注 |
| 盐雾等级跳档 | B-01 | 该客户户外件的默认盐雾档 |
| 板材利用率取高了 | — | SKILL §3.2 该件类的利用率取值区间 |
| 漏焊后打磨 / 校平工序 | — | 成本核算模板的必填工序行 |
| 出口包装漏项 | B-04 | 出口件强制走出口档的判定规则 |
| 材料涨价未及时重报 | — | 报价有效期设定规则 |

> **这张表是整个技能持续变强的入口。** 每单实际成本回灌一次，报价能力就往上走一格—— 报价能力开始逐单变强，而不是逐单重来。
