# 事务码

## 写法

`sap_transaction_open` 只接受事务码本身。接受的写法：

| 写法 | 示例 | 说明 |
|---|---|---|
| 标准事务码 | `ME21N` | 最常见 |
| 带前导区域 | `/N/ME21N` | 允许 |
| SAP 区域前缀 | `/SAPMB/...` | 允许 |

不接受：完整 URL、带主机/客户端/口令的参数、空白或超长的随意字符串。传入非法值会被服务端拒绝（`invalid_transaction`），不会静默打开别的东西。

**不要**把目标地址拼进参数。目标地址（含 SAP 主机与 client）来自服务端场景配置，由服务端自己拼接——这样它永远不会被对话内容改写。

## 常见事务码

| 事务码 | 用途 |
|---|---|
| `ME21N` | 创建采购订单 |
| `ME22N` | 修改采购订单 |
| `ME23N` | 显示采购订单 |
| `ME2M` | 按物料查采购订单 |
| `ME2L` | 按供应商查采购订单 |
| `ME2N` | 按采购订单号查询清单 |
| `ME51N` | 创建采购申请 |
| `ME53N` | 显示采购申请 |
| `MB51` | 物料凭证清单 |
| `MB52` | 库存清单 |
| `MM03` | 显示物料主数据 |
| `MIGO` | 收发料 |
| `MIRO` | 发票校验 |
| `FB60` | 录入供应商发票 |
| `FB03` | 显示会计凭证 |
| `FBL3N` | 总账科目行项目 |
| `SE16N` | 表浏览 |
| `SPRO` | 配置（后台定制） |

清单只是参考，不是白名单：任何合法事务码都可以尝试。但**打开事务码 ≠ 有权限**。没有权限、未登录或会话失效时，左侧画面会停留在登录页或报权限错误，而工具**不会**因此报错——它只报告"导航已送达"。**不得**据此推断用户看得见该事务。

## 打开之后

工具返回后，如实告知用户"已把导航发送到左侧画面，请查看左侧实际页面"。**不要**：

- 声称已确认事务标题、登录状态或权限；
- 声称已读到页面上的字段、表格或消息；
- 在用户没有明确要求时，顺手保存、提交或修改任何东西（当前也没有该能力）。
