# PMC 排产·交期·可行性综合评估 · SKILL

## 1. Skill 用途

PMC 岗位日常处理的三类核心问题：
- **订单接单评审（5.1）**：一张新订单进来，能不能按期交？瓶颈在哪？如何调整？
- **交期平衡（5.2）**：多张订单挤在同一条产线，哪张守、哪张拆、哪张延？
- **排产与插单调整（5.4）**：调整工单优先级 + 同步通知现场执行

三个问题共用同一套底层数据（订单/工单/齐套/产能），本Skill 一次导入解决三类问题。

## 2. 触发方式

- \"帮我分析一下XX 订单能不能按期交\" → 5.1
- \"本周有几张单挤在一条线，帮我看下哪张守/拆/延\" → 5.2
- \"把XX 工单优先级调紧急\" → 5.4

## 3. 输入格式

四份共用数据源：
1. **订单清单.xlsx** · 客户/产品/数量/交期/客户等级
2. **工单清单.xlsx** · 工单号/关联订单/产线/数量/状态/优先级
3. **齐套报表.xlsx** · 物料/需求/可用/缺口/替代料
4. **产能负荷表.xlsx** · 产线/总产能/已排产/剩余/是否瓶颈

## 4. 核心处理逻辑

### 5.1 · 订单可行性分析
1. 拉出订单基本信息（客户等级、交期紧迫度）
2. 检查齐套（缺口料、替代料是否可补）
3. 检查产能（瓶颈工序、在制冲突）
4. 综合评估 → 出结论（🟢 可接/ 🟡 谨慎接单 / 🔴 不建议接）+ 建议动作

### 5.2 · 交期平衡（多单取舍）
1. 拉出同产线本周所有冲突订单
2. 按 \"客户等级 × 交期紧迫度 × 齐套状态\" 三维评估
3. 输出三色建议：🟢 守约 / 🟡 拆批 / 🔴 协调延期
4. 生成对外沟通口径+ 对内分部门待办

### 5.4 · 排产调整
1. 修改工单优先级（普通 → 紧急 / 加急 → 常规）
2. 记录调整原因和调整人
3. 生成企微等 IM 平台推送通知稿

## 5. 输出格式

见 `references/output_template.md`（三种场景各有自己的模板）

## 6. Skill 组合

- 5.1 判定谨慎接单 → 5.2 拉冲突订单做交期平衡
- 5.2 决定守约的订单 → 5.4 把工单调紧急
- 5.4 调整后 → `企微等IM分部门通知` Skill 同步现场
