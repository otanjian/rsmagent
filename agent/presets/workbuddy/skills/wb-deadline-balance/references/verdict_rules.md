# 三色判定规则

## 5.1 · 订单接单可行性

| 判定 | 触发条件 |
|---|---|
| 🟢 可接单 | 齐套 OK + 产能余量足+ 无在制冲突 |
| 🟡 谨慎接单 | 有齐套缺口但替代料可补 · 或产能紧但可调整 · 需协调后接单 |
| 🔴 不建议接 | 严重齐套不足且无替代 · 或产能严重超载 · 或客户等级低但影响战略订单 |

## 5.2 · 多单交期取舍

按 客户等级 × 交期紧迫度 × 齐套齐备度 三维评估：

| 建议 | 触发条件 |
|---|---|
| 🟢 守约 | 客户等级高（战略/A类）且齐套 OK 或可补 |
| 🟡 拆批 | 客户等级中（A/B 类）· 无法一次交完但可分批 |
| 🔴 协调延期 | 客户等级低（B/C类）且交期不紧 · 或齐套/产能不允许 |

## 5.3 · 工单优先级调整规则

| 原优先级 | 新优先级 | 触发条件 |
|---|---|---|
| 普通 → 紧急 | 战略客户急单/交期临近 |
| 紧急 → 加急 | 已滞后且客户投诉 |
| 常规 → 常规 | 无需调整 |

调整后须同步：
- 相关工位（装配/喷涂/包装）
- 现场生产主管
- 客户对接销售
