# 输出骨架与渲染脚本

## 文件清单

- `SO-01_停滞商机分档清单.xlsx` —— 正式件本体 · 5 sheet · 结论栏留空 · 含签批栏
- `SO-01_待核问题清单.xlsx` —— 可派发到销售 · 每个商机一个待核问题
- `SO-01_客观痕迹明细表.xlsx` —— 逐商机列出痕迹指标与判定依据

## sheet 结构

1. `结论摘要` —— 本次结论 / 关键指标 / 输入依据 / 人工边界 / 签批栏
2. `1.实质互动定义` —— 列头：记录类型 | 本次条数 | 有对方回应 | 有具体议题 | 有下一步安排 | 是否计入实质互动
3. `2.痕迹提取` —— 列头：金额区间 | 商机个数 | 合计金额(万元) | 占在推总额 | 平均阶段停留(天) | 是否进入本次核查
4. `3.停滞判定` —— 列头：分档 | 判定依据 | 商机个数 | 合计金额(万元) | 占在推总额 | 平均阶段停留(天) | 有审批流记录的个数
5. `4.停滞归因` —— 列头：商机编号 | 客户 | 负责人 | 金额(万元) | 最后实质互动距今(天) | 在其他数据源发现的事实 | 归因判定
6. `5.唤醒清单` —— 列头：商机编号 | 客户 | 负责人 | 金额(万元) | 这个商机需要核实的那一件事 | 核实所需材料 | 结论（销售填）
7. `6.留证与签批` —— 列头：负责人 | 高度疑似停滞(个/万元) | 需核实(个/万元) | 本次待核合计(个/万元) | 其中已有其他数据源解释(个) | 核实截止日 | 结论栏

## 视觉规范

正式件本体用**风格 A**（浅灰表头 `F6F8FB` + 深字 `1A2332`）；
清单类用**风格 B**（蓝底白字 `2D6CDF`）。同一个包里不要混用。

```python
INK, MUTED, GREY = "1A2332", "5A6675", "8A94A3"
HEAD_A, HEAD_B   = "F6F8FB", "2D6CDF"
RED, AMBER, GREEN = "C62F2F", "B9770A", "1E8E5A"
FONT = "微软雅黑"
```

必做三件事：

```python
ws.freeze_panes = "A4"                          # 冻结表头
ws.auto_filter.ref = f"A3:{last_col}{last_row}"   # 开筛选
ws.sheet_view.showGridLines = False              # 关网格线，更像正式件
```

## 签批栏（正式件必备）

编制 / 审核 / 会签 / 批准四栏 + 日期列。
**推荐意见、完成质量、责任认定三栏留空。**

## 渲染脚本自检

```python
# 分项加总必须等于合计
assert abs(sum(items) - total) < 0.01, f"分项 {sum(items)} != 合计 {total}"
# 占比合计必须等于 100%
assert abs(sum(pcts) - 100) < 0.1
# 行数守恒
assert len(out_rows) == len(in_rows), "行数不守恒"
```

跑不过就不出文件 —— 从根上杜绝「合计对不上」这种一眼被看穿的错。
