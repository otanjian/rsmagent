# 风险分级规则

> 本文件是「来料跟催·风险分级与话术生成」Skill 的核心规则文档。
> 解决一件事：**采购每天按逾期天数排序打电话，先催了嗓门大的供应商，真正卡住交付的那张反而没催。**

---

## 一、为什么按逾期天数排序是错的

采购手上几十张在途单，传统做法是在 Excel 里筛"承诺到货日 < 今天且未到货"，然后按逾期天数从大到小打电话。这套做法有三个结构性缺陷：

| 缺陷 | 具体表现 |
|---|---|
| **未逾期的单一张都筛不出来** | 筛选条件是"交期已过"，那些"还没到交期但按这家供应商的历史一定会晚"的单，全部漏在筛选之外。等到交期过了再催，已经来不及安排替代方案 |
| **逾期天数不代表紧急程度** | 一张逾期 5 天的板材单，可能库存还能撑 18 天、下游工单排在下个月；一张刚下单没几天的主控板，可能库存只够 1 天、下游明天就上线 |
| **供应商改期可以洗白记录** | 供应商每次把承诺日往后改一次，逾期天数就重新归零，台账永远是干净的，履约差的供应商反而看不出来 |

结果就是：**跟催资源（电话、关系、加急产能）被浪费在不需要的单上，真正卡交付的单没有得到资源。**

---

## 二、核心原则：逾期程度和下游影响面必须分开算

这是本规则最重要的一条。

```
逾期程度   = 供应商那边的事   （他晚了没有、会晚多少）
下游影响面 = 我们自己的事     （库存能撑几天、下游几号上线、卡哪个客户）

两轴独立计算，最后交叉定色。任何一轴单独都不足以定优先级。
```

**常见错误**：看到预测会晚就直接判红。**晚不晚是供应商的事，急不急是我们自己的事。** 一家供应商稳定晚 2 天、但我们库存有 15 天，那就不急；一家供应商只晚 1 天、但我们库存只有半天，那就要命。

---

## 三、两轴的计算

### 3.1 逾期程度轴

| 指标 | 算式 | 口径要点 |
|---|---|---|
| **逾期天数** | 基准日 − **原承诺到货日**（仅计正数） | 用原承诺日，**不用最新承诺日**。供应商改期不能洗白逾期记录 |
| **有效承诺日** | 有「最新承诺到货日」取最新，否则取原承诺日 | 只用于**预测**，不用于算逾期 |
| **预测到货日** | 有效承诺日 + 该供应商平均延误天数（四舍五入取整） | 平均延误天数 = 延误天数合计 ÷ **延误单数** |
| **承诺失效兜底** | 已逾期且预测日已过基准日 → 取 基准日 + 1 天，标注"承诺失效" | 这类单的预测值只能当下限用 |
| **信息缺口** | 最新承诺日为空（供应商未给新日期）→ 强制标注 | 无承诺日比"承诺了但会晚"更严重 |

### 3.2 下游影响面轴

| 指标 | 算式 | 口径要点 |
|---|---|---|
| **可用库存** | 现有库存 − 安全库存 | 安全库存不参与，动用需 PMC 批准 |
| **可撑天数** | 可用库存 ÷ 日均耗用量（保留 1 位小数） | 日均耗用量 = 近 30 天实际领料量 ÷ 30 |
| **断料日** | 关联工单计划上线日 + ⌊可撑天数⌋ | 向下取整，不给自己留虚假余量 |
| **缺口天数** | 预测到货日 − 断料日 | > 0 = 会停线 |
| **缓冲天数** | − 缺口天数 | ≥ 0 = 暂不停线 |

**在途单 → 工单的 FIFO 配对**：同一物料被多张工单需求、同时有多张在途单时，按「工单计划上线日先后」与「在途单承诺到货日先后」一一配对。**第 2 批及以后的在途单，前批库存已被首个工单占用，可撑天数按 0 计。**

## 四、四象限定色

```
                     下游影响面
              紧 ←──────────────────────→ 松
          ┌────────────────────┬────────────────────┐
          │  🔴 紧急催│  ⚪ 逾期但不急      │
     已   │  逾期 + 缺口 > 0    │  逾期但缓冲 ≥ 7 天   │
     逾   │                │  且上线日≥ 14 天后│
     期   │  当日电话 + 书面│  本周内一封邮件留痕 │
          ├────────────────────┼────────────────────┤
          │  🔴 紧急催          │  🟢 正常            │
     未   │  未逾期但按历史推   │  未逾期且缓冲充足   │
     逾   │  算会晚 + 缺口 > 0  │                    │
     期   │  ★传统方法筛不出来 │  周例会常规跟踪     │
          └────────────────────┴────────────────────┘

           🟡 关注 = 缓冲 ≤ 2 天的临界带，或已逾期但尚有缓冲
```

### 4.1 判定顺序（严格按此顺序，命中即停）

```
① 缺口天数 > 0                → 🔴 紧急催
② 已逾期 且 缓冲 ≥ 7 天 且 最早上线日 ≥ 基准日 + 14 天    → ⚪ 逾期但不急
③ 缓冲 ≤ 2 天                                → 🟡 关注
④ 已逾期（但不满足 ②）→ 🟡 关注
⑤ 其余                                                   → 🟢 正常
```

**为什么 ① 放在最前**：缺口 > 0 意味着已经算出来会停线，这是唯一的硬结论，其他条件都不能覆盖它。哪怕这张单还没到承诺日、供应商刚刚才接单，也要判 🔴。

**为什么 ② 的三个条件必须同时满足**：

| 条件 | 缺了会怎样 |
|---|---|
| 缓冲 ≥ 7 天 |缓冲只有 3 天就判"不急"，供应商再晚一点就翻车 |
| 最早上线日 ≥ 14 天后 | 下游 5 天后就上线，即使当前缓冲够，中间任何变动都没有回旋空间 |
| 已逾期 | 未逾期的正常单归🟢，不需要单独标一个"不急"，否则 ⚪ 会被塞满 |

**把三条同时收紧，是为了防止"逾期但不急"被滥用成"逾期都不急"的偷懒借口。**

### 4.2 四色对应的动作强度

跟催资源（电话时间、供应商关系、加急产能）是有限的，分级的目的就是分配资源。

| 色 | 动作 | 渠道 | 时限 | 占用电话资源 | 是否升级 |
|---|---|---|---|---|---|
| 🔴 紧急催 | 电话跟催（带履约数据）+ 索取书面承诺 + 同步 PMC 预排产 | 电话 + 邮件留痕 | 当日 | ✅ 优先| 当日 18:00 未拿到书面承诺即升级 |
| 🟡 关注 | 邮件确认发运节点并留痕 | 邮件 | 当日 | ❌ | 48 小时未回复升🔴 |
| 🟢 正常 | 周例会常规跟踪 | 无 | 周 | ❌ | 否 |
| ⚪ 逾期但不急 | 本周内一封邮件要书面到货日，**明确告知"无需加急"**；逾期计入月度履约扣分 | 邮件 | 本周内 | ❌ | 否 |

### 4.3 ⚪ 单为什么还要发邮件

两个目的，都不能省：

1. **留痕**：逾期事实必须进履约台账。不记录，月度绩效算不出准时率，年度框架谈判也没有依据
2. **明确告知不用加急**：A 级供应商被无差别催货，会把有限的加急产能浪费在不需要的单上。真正急的时候，加急产能已经被自己占掉了

一封邮件同时处理多张 ⚪ 单，成本极低。**"不需要你加急"这句话本身就是跟催体系的一部分。**

## 五、降级与升级的触发条件

### 5.1 什么情况可以降级（从🔴 / 🟡 往下调）

| 情况 | 是否可降级 | 理由 |
|---|---|---|
| 供应商电话 / 微信说"明天一定到" | ❌ 不可 | 口头承诺不改变分级。要看这家的口头承诺兑现率 |
| 拿到书面承诺（邮件 / 盖章回单） | ✅ 可降一级 | 有留痕、有责任 |
| 已发货且有可查物流单号 | ✅ 可降一级 | 预测改按物流时效算，**不再叠加历史平均延误**（货已在路上，历史数据不适用） |
| PMC 已批准调整排产，上线日推后 | ✅ 重算 | 断料日变了，重新走一遍分级 |
| PMC 批准动用安全库存 | ✅ 重算 | 可用库存变了，可撑天数重算 |

### 5.2 什么情况必须升级

| 触发条件 | 升级到| 对应手册层级 |
|---|---|---|
| 🔴 单当日 18:00 未取得书面承诺 | 采购经理 + 供应商总经理层 | L3 橙色（断供风险） |
| 供应商连续两月准时率 < 70% | 采购经理 + 月度绩效评审会 | L2 黄色（履约恶化） |
| 缺口 > 0 且调排产无空间 + 分批发货被拒 | 采购经理，启动替代料评估 | L3 橙色 |
| 确定影响客户交期| 供应链经理 + 销售，评估是否向客户报延期 | L4 红色（客户交付影响） |

**升级条件必须写成客观事实**（"18:00 未取得书面承诺"），不能写成主观感受（"供应商不配合"）。客观条件才能自动触发；主观感受只会一直拖到来不及。

## 六、分级结果的自校验

Skill 每次输出前必须自校验，不通过则拒绝输出：

```
① 四色张数加总 = 在途单总数          （不等 = 有单漏判或重复判）
② 每张单都有「判定依据」，且依据里含算式
③ 每张 🔴 / 🟡 单都有对应的跟催话术
④ 每张 🔴 单都有明确的升级触发条件与时点
⑤ 判为 ⚪ 的单，三个条件逐条可核（缓冲天数 / 上线日距今天数 / 逾期天数）
⑥ 所有可撑天数都能用「可用库存 ÷ 日均耗用量」反算回去
```

## 七、常见误判与规避

| 误判 | 表现 | 规避方法 |
|---|---|---|
| **漏判：未逾期单不进筛选** | Excel 筛"交期已过"，未逾期的高风险单一张都看不到 | 全量 18 张单都跑预测，不做前置筛选 |
| **漏判：平均延误分母用总单数** | 4.2 天算成 1.6 天，预测日提前 3 天，缺口从+1 变成 −2，判定翻转 | 分母硬性规定为延误单数，输出附算式 |
| **误判：把逾期当紧急** | 逾期 5 天判红，占掉当天最好的跟催资源 | 逾期只是一轴，必须交叉下游影响面 |
| **误判：安全库存算进可用库存** | 可撑天数虚高一倍，本该判 🔴 的判成 🟢 | 可用库存 = 现有 − 安全，写进口径说明 |
| **误判：多张在途单重复用同一批库存** | 同物料 3 张在途单都按完整库存算缓冲，全判"不急" | FIFO 配对，第 2 批起可撑天数按 0 计 |
| **误判：部分到货重复计算** | 已到的 1500kg 既在库存快照里、又在在途单数量里算了一遍 | 部分到货单只算剩余数量 |
| **误判：无下游需求的单判红** | 备库单 / 售后备件单没有关联工单，被按最保守方式判红 | 配对失败时标注"无下游需求"，判 🟢 或 ⚪ |
| **过度使用 ⚪** | 所有逾期单都塞进"逾期但不急"，等于取消了逾期管理 | ⚪ 三个条件同时满足，且逐条要能核|
| **只判定不动作** | 分完色就结束，没有话术、没有待办、没有升级条件 | 每个色强制绑定动作强度、渠道、时限 |
| **数量缺口当交期问题** | 需求 500 只下了 300，怎么催都不够 | 配对时校验需求量 vs 在途量 + 可用库存，数量不足单独提示补下单 |
