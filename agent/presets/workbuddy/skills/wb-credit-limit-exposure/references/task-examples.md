# 可选任务

## 首推默认

恒晟精工有个 186 万元的订单要下单发货，销售说他们额度够，我不放心。材料在这儿：他们的应收账款台账、已批未执行订单清单、财务的客户信用额度核定表、三系统客户主数据导出、客户工商与司法公开信息，还有客户信用与发货管理办法摘录。

三份表里客户名称不一样，先按统一社会信用代码确认是不是同一家，对不上的单列出来别硬拼。然后算他们现在总共占用了多少额度——在途没收回的、已经批了还没发货的、加上这一单，三项分开列再合计。跟核定额度比，超没超、超多少、由哪几笔构成。逾期的一起看，工商司法的公开异动也并列上。按管理办法给分级建议动作，每档写清依据。

交三份：额度占用核查单.xlsx（正式件本体，带签批栏）、超限证据链清单.xlsx（逐笔带单据号与出处）、客户风险异动摘要.xlsx（公开信息异动与应收逾期并列）。发不发货我拿去给财务和总监定，你别替我决定，也别自动拦单。

## 只算占用三构成

先只算占用这一步，风险和建议动作都先不写：把在途未清应收、已批未执行订单、本次订单 186 万元三项拉出来相加，逐项列构成。产出用 Excel 一张表：占用构成、数据来源、笔数、金额、口径依据，末行是合计与核定额度的对比。

## 换成按逾期优先排

换个口径再跑一遍：这次不按超限金额排，改按逾期严重度排——先列最可能拖垮这笔 486 万元占用的那几笔。产出用 Excel 一张表：发票号、到期日、逾期天数、未收金额、状态、该笔对占用的贡献，逾期最久的排最前面。

## 一次算三个客户

演示数据里再加另外两个客户的应收台账和额度核定表，三个客户一起算、各自出结论，最后给我一张横向对照表：客户、核定额度、累计占用、超限金额、逾期笔数与金额。产出用 Excel，对照表单独一张 sheet。

## 给财务和总监看的一页

把核查单压成财务和销售总监签批时看的一页纸：占用构成三个数、核定额度、超限多少、逾期的哪几笔、可选动作各能让占用降到多少。产出用一份 Markdown 一页纸，算式保留，明细表不要。

## 让它反驳自己

你算出来的超限金额，自己挑一下最可能被质疑的地方：对着应收账款台账、已批未执行订单清单和三系统客户主数据导出，看那两笔已批未执行订单是不是真的还没发货、客户名称对齐有没有误判。逐条说明依据出处、你的疑问、要核实什么。产出用 Excel 一张表：判断项、支撑依据、你的疑问、建议复核动作。

## 比对瑞成液压那次

专门比 2023 年瑞成液压发货那次：当时漏算了已批未执行的两笔共 112 万元，最后核销 68.4 万元。拿这次的已批未执行订单清单和当时的结构逐笔对起来。产出用 Excel 一张表：对比项、瑞成液压那次、本次恒晟、差异，漏算风险单列一栏。

## 对照管理办法自查

对照客户信用与发货管理办法摘录，把这次核查自查一遍：占用口径对不对、超限分级跟办法里的档位对得上吗、建议动作有没有越权、额度核定日期距今多久要不要提请重核。产出用 Excel 一张清单：办法条目、要求、本次现状、结论、越界或遗漏项。

## 折算成预期损失

拿客户信用与发货管理办法摘录和应收账款台账，把超限部分折算成钱：按公司近三年坏账率 1.8% 算预期损失，再参照瑞成液压 486 万元占用最后核销 68.4 万元的先例算一个对照数；同时算改为预付 30% 后占用能降到多少、还剩多少超限。产出用 Excel 一张表，算式与参数都写清。

## 沉淀成测算口径表

把这次的测算口径整理成下次直接能用的清单：占用三构成从哪份材料取、客户名称按什么对齐、超限分级怎么定、建议动作分别对应什么条件。产出用 Markdown 一份《客户额度占用测算与分级动作口径表》。
