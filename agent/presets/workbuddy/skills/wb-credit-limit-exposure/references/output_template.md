# 输出骨架与渲染脚本

## 文件清单

- `CR-01_额度占用核查单.xlsx` —— 正式件本体 · 5 sheet · 含签批栏
- `CR-01_超限证据链清单.xlsx` —— 可派发 · 逐笔带单据号与出处
- `CR-01_客户风险异动摘要.xlsx` —— 公开信息异动与应收逾期并列

## sheet 结构

1. `结论摘要` —— 本次结论 / 关键指标 / 输入依据 / 人工边界 / 签批栏
2. `1.主体对齐` —— 列头：来源系统 | 系统内编号 | 系统内客户名称 | 统一社会信用代码 | 对齐依据 | 对齐结论
3. `2.占用测算` —— 列头：占用构成 | 数据来源 | 笔数 | 金额(元) | 口径依据
4. `3.超限判定` —— 列头：项目 | 金额(元) | 占核定额度 | 判定 | 依据条款
5. `4.风险叠加` —— 列头：异动项 | 发生日期 | 涉及金额(元) | 与核定日关系 | 对额度的影响 | 触发条款
6. `5.建议动作` —— 列头：档位 | 适用条件 | 本次是否适用 | 动作 | 涉及金额(元) | 剩余超限(元) | 决策层级
7. `6.留证与签批` —— 列头：优先级 | 事项 | 依据条款 | 阻塞发货 | 动作 | 责任人 | 完成时点 | 验收标准

## 视觉规范

正式件本体用**风格 A**（浅灰表头 `F6F8FB` + 深字 `1A2332`）；
清单类用**风格 B**（蓝底白字 `2D6CDF`）。同一个包里不要混用。

```python
INK, MUTED, GREY = "1A2332", "5A6675", "8A94A3"
HEAD_A, HEAD_B   = "F6F8FB", "2D6CDF"
RED, AMBER, GREEN = "C62F2F", "B9770A", "1E8E5A"
FONT = "微软雅黑"
```

必做三件事：

```python
ws.freeze_panes = "A4"                          # 冻结表头
ws.auto_filter.ref = f"A3:{last_col}{last_row}"   # 开筛选
ws.sheet_view.showGridLines = False              # 关网格线，更像正式件
```

## 签批栏（正式件必备）

编制 / 审核 / 会签 / 批准四栏 + 日期列。
**推荐意见、完成质量、责任认定三栏留空。**

## 渲染脚本自检

```python
# 分项加总必须等于合计
assert abs(sum(items) - total) < 0.01, f"分项 {sum(items)} != 合计 {total}"
# 占比合计必须等于 100%
assert abs(sum(pcts) - 100) < 0.1
# 行数守恒
assert len(out_rows) == len(in_rows), "行数不守恒"
```

跑不过就不出文件 —— 从根上杜绝「合计对不上」这种一眼被看穿的错。
