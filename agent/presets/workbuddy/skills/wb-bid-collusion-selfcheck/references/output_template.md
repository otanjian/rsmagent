# 输出骨架与渲染脚本

## 文件清单

- `BD-04_关联方风险自查记录.xlsx` —— 正式件本体 · 4 sheet · 含签批栏
- `BD-04_交叉痕迹清单.xlsx` —— 可派发 · 每条带公开案例口径出处
- `BD-04_第三方委托重合核查表.xlsx` —— 委托方逐家核 · 含承诺函要求

## sheet 结构

1. `结论摘要` —— 本次结论 / 关键指标 / 输入依据 / 人工边界 / 签批栏
2. `1.痕迹清单` —— 列头：序号 | 痕迹类别 | 具体查什么 | 认定口径出处 | 该口径的原文要点 | 我方可否自查
3. `2.我方自查` —— 列头：比对项 | 我方及关联企业名单 | 四家投标人公开名单规模 | 重合人数 | 近三年变更是否交叉 | 结论
4. `3.第三方服务重合` —— 列头：服务商名称 | 服务类别 | 本项目委托事项 | 历史委托次数 | 是否约定排他条款 | 是否已取得承诺函 | 风险判定
5. `4.编制与上传环境` —— 列头：投标文件组成部分 | 编制人 | 编制设备与归属 | 文件属性作者 | 上传操作人与网络环境 | 判定
6. `5.风险分级与处置建议` —— 列头：档位 | 痕迹类别 | 我方现状 | 对应公开认定口径 | 处置动作（改哪份文件 · 谁负责 · 何时完成 · 拿什么验收） | 成本
7. `6.留证与签批` —— 列头：优先级 | 自查项 | 自查结论 | 依据出处（公开案例） | 处置动作 | 责任人 | 递交前可否完成

## 视觉规范

正式件本体用**风格 A**（浅灰表头 `F6F8FB` + 深字 `1A2332`）；
清单类用**风格 B**（蓝底白字 `2D6CDF`）。同一个包里不要混用。

```python
INK, MUTED, GREY = "1A2332", "5A6675", "8A94A3"
HEAD_A, HEAD_B   = "F6F8FB", "2D6CDF"
RED, AMBER, GREEN = "C62F2F", "B9770A", "1E8E5A"
FONT = "微软雅黑"
```

必做三件事：

```python
ws.freeze_panes = "A4"                          # 冻结表头
ws.auto_filter.ref = f"A3:{last_col}{last_row}"   # 开筛选
ws.sheet_view.showGridLines = False              # 关网格线，更像正式件
```

## 签批栏（正式件必备）

编制 / 审核 / 会签 / 批准四栏 + 日期列。
**推荐意见、完成质量、责任认定三栏留空。**

## 渲染脚本自检

```python
# 分项加总必须等于合计
assert abs(sum(items) - total) < 0.01, f"分项 {sum(items)} != 合计 {total}"
# 占比合计必须等于 100%
assert abs(sum(pcts) - 100) < 0.1
# 行数守恒
assert len(out_rows) == len(in_rows), "行数不守恒"
```

跑不过就不出文件 —— 从根上杜绝「合计对不上」这种一眼被看穿的错。
