# 客户单据转订单 · SKILL

## 1. 用途
销售/客服岗位 · 把客户口径混乱的叫料邮件/Excel 转成本厂规范订单。覆盖料号翻译、单位换算、日期归一、单价核对、拆行合并、新品挂起。

## 2. 触发方式
- "客户发来叫料计划，帮我转成订单"
- "客户的这些编码翻译一下"
- "这份来单能不能建单？有什么问题"

## 3. 输入格式
5 份数据：
1. 客户来单邮件（文本/图片）
2. 客户叫料计划xlsx（客户口径）
3. 客户料号对照表（现行 + 历史别名 + 规格反查）
4. 销售价格表
5. 产品主数据（含标准交期 + 最小起订量）

## 4. 核心处理逻辑
### 六步转化
1. **料号翻译**：客户料号→本厂料号 · 精确匹配 → 历史别名 → 规格反查
2. **单位换算**：套/件 等异构单位处理（1 套 = 4 件）
3. **日期归一**：5 种混乱写法统一到 yyyy-mm-dd
4. **单价核对**：对照年度价格表 · 差异标注
5. **拆行/合并**：一行多规格拆开 · 重复行合并
6. **交期评估**：对照标准交期 · 急件预警 · 最小起订量校验

### 三种归口
- ✅ 可直接建单：料号 + 单位 + 单价 + 数量 + 交期全通过
- 🟡 需澄清：有 1-2 项待客户确认
- ⚪ 需挂起：新品 · 需研发建档

## 5. Skill 组合
- 上游：报价通过后 → 本 Skill 建订单
- 下游：订单 → 5.1 订单接单评审
