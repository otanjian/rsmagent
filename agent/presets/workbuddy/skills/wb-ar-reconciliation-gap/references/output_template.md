# 输出骨架与渲染脚本

## 文件清单

- `CR-03_对账差异说明.xlsx` —— 正式件本体 · 5 sheet · 含签批栏
- `CR-03_逐笔差异归因清单.xlsx` —— 可派发 · 每笔带凭证位置与责任人
- `CR-03_凭证补齐清单.xlsx` —— 缺件逐项 · 含今日可否取到

## sheet 结构

1. `结论摘要` —— 本次结论 / 关键指标 / 输入依据 / 人工边界 / 签批栏
2. `1.多字段匹配` —— 列头：我方发票号 | 对方凭证号 | 金额 | 业务日期 | 产品 | 发票号引用 | 匹配依据 | 匹配结论
3. `2.差异分离` —— 列头：差异类别 | 笔数 | 涉及凭证 | 金额(元) | 占差额 | 方向 | 我方持有单据情况
4. `3.逐笔归因` —— 列头：归因类别 | 笔数 | 金额(元) | 占差额 | 具体凭证 | 归因依据 | 归因是否成立
5. `4.凭证索引` —— 列头：归因类别 | 金额(元) | 支撑凭证 | 凭证编号 | 凭证在谁手上 | 今日可否取到 | 缺什么
6. `5.差异汇总闭合` —— 列头：调整项 | 调整方 | 调整前余额(元) | 调整金额(元) | 调整后余额(元) | 依据条款
7. `6.留证与签批` —— 列头：优先级 | 事项 | 依据条款 | 阻塞发出 | 动作 | 责任人 | 完成时点 | 验收标准

## 视觉规范

正式件本体用**风格 A**（浅灰表头 `F6F8FB` + 深字 `1A2332`）；
清单类用**风格 B**（蓝底白字 `2D6CDF`）。同一个包里不要混用。

```python
INK, MUTED, GREY = "1A2332", "5A6675", "8A94A3"
HEAD_A, HEAD_B   = "F6F8FB", "2D6CDF"
RED, AMBER, GREEN = "C62F2F", "B9770A", "1E8E5A"
FONT = "微软雅黑"
```

必做三件事：

```python
ws.freeze_panes = "A4"                          # 冻结表头
ws.auto_filter.ref = f"A3:{last_col}{last_row}"   # 开筛选
ws.sheet_view.showGridLines = False              # 关网格线，更像正式件
```

## 签批栏（正式件必备）

编制 / 审核 / 会签 / 批准四栏 + 日期列。
**推荐意见、完成质量、责任认定三栏留空。**

## 渲染脚本自检

```python
# 分项加总必须等于合计
assert abs(sum(items) - total) < 0.01, f"分项 {sum(items)} != 合计 {total}"
# 占比合计必须等于 100%
assert abs(sum(pcts) - 100) < 0.1
# 行数守恒
assert len(out_rows) == len(in_rows), "行数不守恒"
```

跑不过就不出文件 —— 从根上杜绝「合计对不上」这种一眼被看穿的错。
