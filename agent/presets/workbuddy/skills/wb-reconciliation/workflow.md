# 对账差异核对 · SKILL

## 1. 用途
财务岗位 · 客户对账单 vs 我方销售出货明细的差异核对。覆盖字段映射、料号归一、单号归一、税率口径、期间归属、差异分类、对客回函。

## 2. 触发方式
- "帮我核对客户 X 的月度对账单"
- "客户对账单和我方合计对不上"
- "找出所有差异笔并给出处置建议"

## 3. 输入格式
4 份数据：
1. 客户对账单 xlsx（客户格式 · 可能繁体列名 + 客户零件号 + 含税单价）
2. 我方销售出货明细 xlsx（未税单价）
3. 销售价格表 xlsx（含批量档特批价）
4. 送货单回执台账 xlsx

## 4. 核心处理逻辑
### 五步差异核对
1. **字段映射**：繁→简 · 客户零件号 → 本厂料号 · 含税 ↔ 未税
2. **单号归一**：039A → 039 · 简写 0A → 完整
3. **逐行匹配**：日期+料号+数量三维匹配 · 强匹配失败降级到宽松匹配
4. **差异分类**：数量差 / 单价差 / 税率差 / 期间归属差 / 回执缺失
5. **归口判定**：客户少记 vs 我方少记 vs 双方口径差

### 五类差异
-🔴 数量差 · 以签收单为准
- 🟡 单价差 · 核对是否批量档特批
- 🔴 税率差 · 需协商归属
- 🟡 期间归属差 · 保留出货月归属
- 🔴 回执缺失 · 补录
