# 可选任务

## 首推默认

汇算清缴前做一次税收优惠体检。技能内置四份材料：年度财务报表（利润／资产／人数）、研发费用明细（工资／材料／折旧）、固定资产购入清单、历史纳税申报表。逐条把公司的实际条件和政策适用条件对上——小微、研发加计扣除、固定资产一次性扣除、残保金减免这几项，已享的、漏享的、不适用的分开写，漏享的把金额算出来。历史申报表用来看哪些去年已经享过。
产出三份：「税收优惠体检报告.xlsx」，一项优惠一行，列写适用条件、公司情况、结论（已享／漏享／不适用／可申请）、政策文件号；「漏享金额测算表.xlsx」，逐项漏享金额附计算过程；「小微边界预警.xlsx」，利润贴 300 万门槛的税负跳变写清再往上多少就跳、跳多少。
不适用就写不适用并写理由，别凑成漏享项充数；不做税务筹划、不要替我提交申报；享不享我自己定。

## 只做小微三条件判定

先只做小微判定这一步，其他优惠先不动。读年度财务报表里的人数、资产总额、应纳税所得额三项，按从业人数 ≤300、资产总额 ≤5000 万、应纳税所得额 ≤300 万逐条对照，给明确结论（符合／不符合／贴门槛）。产出 Excel 一张表，三个条件各一行，列写政策标准、公司实际数、出处（报表哪一张）、判定；末行给「是否可享小微」的结论。数据缺哪一项写「本项数据缺失」，别估。

## 只算研发加计扣除

换个口径，这次只算研发加计扣除这一项。读研发费用明细，把工资、材料、折旧三块归集出来，对照加计扣除的适用条件算能加计多少、现在漏了多少。产出 Excel 两张 sheet：一张归集明细（一行一项，写清金额和归集依据），一张测算（加计比例、适用税率、漏享金额、算式）。归集口径拿不准的标「待财务与研发确认」，别硬算成漏享。

## 一次体检三家公司

演示数据里再加两家关联公司的年度财务报表、研发费用明细和固定资产购入清单，三家一起体检，优惠项和判定口径保持一致。产出「税收优惠体检报告.xlsx」，三家各一个 sheet；另加一张横向对照表，一家一行，列写小微三条件是否全符合、漏享项数、漏享金额合计、距 300 万门槛的距离。哪家材料缺项就标「缺」，说明哪几项优惠这次判不了。

## 给老板看的版本

把体检结果压成给老板看的一页，Markdown 半页以内：今年该领没领的有几项、合计多少钱、每项还差什么材料才领得到、利润离小微门槛还有多远。政策条款不用写全，但每个金额后面要注明出自「漏享金额测算表.xlsx」的哪一项。这一页不下「该怎么筹划」的话，只摆钱和门槛。

## 让它反驳自己

你说固定资产一次性扣除是「不适用」不是漏享、依据是单价没过门槛——这个判断站得住吗？逐条回查固定资产购入清单里每台设备的单价和购入时间，跟一次性扣除的适用条件对照。产出 Markdown 一份《判断复核》：站不住的改回「待核」，写清要补哪份资料（采购合同、发票）才能定；别为了凑漏享金额把不适用的算进来。

## 比对去年跳门槛那件事

去年应纳税所得额 301 万、破了小微门槛按 25% 全额缴税那件事，跟今年的数并排列出来。材料用年度财务报表和历史纳税申报表。产出 Excel 一张对照表：去年实际、若压在门槛内的情形、今年预计三行，列写应纳税所得额、适用税率、应缴所得税、税负跳变金额，算式写清。末尾给「今年离门槛还有多少距离」这一个数，以及再涨多少会跳变、跳多少。

## 按政策条件自查

拿年度财务报表和固定资产购入清单，对照小微三条件和各项优惠的适用条件逐条自查「税收优惠体检报告.xlsx」。产出 Markdown 一份自查表，优惠项一行一条，列写政策条件、公司实际、结论、有没有挂政策文件号。重点过三件事：不适用的有没有都写了理由；有没有把不适用的凑成漏享；有没有哪项对错了适用条件的版本。列出来别动手改结论。

## 折算成漏享金额与时限

读「漏享金额测算表.xlsx」和「税收优惠体检报告.xlsx」。这几项优惠里已享的、漏享的分别折算成多少钱，产出 Excel 一张表，一行一项，列写已享金额、漏享金额、算式；另起一段写时限——漏的那几项如果拖过汇算清缴截止日再补，各会多出什么代价（滞纳金口径、还能不能补）。金额给测算值并注明是测算；时限只写公开规定的口径，别替我判断哪项一定能补。

## 沉淀成年度体检清单

把这次从年度财务报表、研发费用明细、固定资产购入清单、历史纳税申报表里跑出来的优惠适用条件对照表和漏享测算口径，整理成一份「年度税收优惠体检清单.xlsx」：一行一项优惠，列写适用条件、要读哪份材料的哪个字段、判定口径、政策文件号、本次结论。明年汇算时照这张清单跑一遍。只收这次真体检过的项，没收进来的别列。
