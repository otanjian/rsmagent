# 决策单模板 · 必备栏位与渲染要点

交付物形态：**1 份 PDF（2 页）+ 1 个 Excel（2 sheet）**。

判断标准只有一条：**这份东西能不能直接进企业的流程被签字**。只是一张展示用的表格就不合格。

---

## 一、PDF 第1 页 ·《出货放行决策单》

### 抬头区（缺了就不像真的）

| 栏位 | 说明 |
|---|---|
| 单据编号 | `QR-{YYYYMMDD}-{流水}`，如 QR-20260808-001 |
| 版本号 / 生效日期 | 本单模板版本，如 Rev.B / 2026-01-01 |
| 评估日期 | 实际评估日期 |
| 评估人 | 品质工程师姓名 |
| **依据文件栏** | 逐条列出：客户质量协议编号+版本、图纸号+版本、抽样标准（GB/T 2828.1）、内部判定规范编号 |

**依据文件栏是可信度的来源。** 只写"依据相关标准"等于没写。

### 主体区（每批一段）

| 栏位 | 必填 | 说明 |
|---|---|---|
| 交货批号 / 箱号范围 | ✓ | 精确到箱号，仓库凭此拣货 |
| 客户 / 销售订单号 / 约定交货日 | ✓ | |
| 送检数量 / 抽检数量 / 不良数 | ✓ | |
| 偏差项 | ✓ | 实测值 **vs** 图纸要求，并列写 |
| 缺陷等级（重判） | ✓ | CR / MA / MI，**若与原判不同须标注"原判 X，修正为 Y，依据…"** |
| 适用AQL / 样本量 / 接收数 Ac | ✓ | 写清档位来源|
| **三条红线勾选栏** | ✓ |① 安全特性超差 □是□否 ② 合同零缺陷 □是 □否 ③ 影响无法评估 □是 □否；命中的须写条款编号 |
| 影响评估 | ✓ | 功能 / 安全 / 外观 三个维度分别评|
| **处置建议（五选一）** | ✓ | 🟢放行 /🔵返工后复检 / 🟡暂缓放行 / ⚪让步接收 / 🔴拒收隔离 |
| 使用条件与限用范围 |让步时必填 | 仅限本批 / 仅限该型号 / 不得用于出口件… |
| 追溯方式 | ✓ | 批号标识、标签方式、如何追溯到最终用途 |
| 关闭条件与责任人 | 暂缓时必填 | 关闭条件 + 责任人 + 预计关闭时间 |
| 两边代价 | ✓ | 放行风险 / 不放行代价，并列 |

### 会签区（顺序不可乱）

```
编制（OQC/品质工程师）→ 审核（品质主管）→ 会签（生产/计划）→ 会签（业务/销售）→ 批准（总经理）
```

规则：
- **品质主管必签**，否则单据不生效
- **让步接收档须总经理签**
- 对外件加**客户签核位**
- 页脚印明：**仓库凭已签字决策单放行，无签字不得出货**

## 二、PDF 第 2 页 ·《待确认事项清单》

每条四栏：**序号 · 问谁 · 要确认什么 · 为什么必须确认（含建议话术）**

**页脚必须印明**：

> 本单结论以待确认事项落实为前提。未落实前不得据此放行。

这句话是这份交付物的诚实性所在——它明确告诉签字的人，哪些地方还是空的。

## 三、Excel sheet 1 · 批次明细与放行状态

列：`交货批号 | 箱号范围 | 产品编码 | 客户 | 总数量 | 可发数量 | 待返工 | 待剔除 | 暂缓数量 | 放行状态 | 决策单编号 | 备注`

要求：
- 冻结首行 `ws.freeze_panes = 'A2'`
- 开筛选 `ws.auto_filter.ref`
- 关网格线 `ws.sheet_view.showGridLines = False`
- **数量守恒自检**：`assert 可发 + 待返工 + 待剔除 + 暂缓 == 总数量`

## 四、Excel sheet 2 · 让步先例台账（已追加本次）

列：`序号 | 发生日期 | 客户 | 产品 | 缺陷类别 | 偏差描述 | 处置方式 | 依据条款编号 | 客户是否书面确认 | 客户后续反应 | 记录人`

要求：
- 本次处置的每一批都要追加
- **「客户后续反应」栏留空待回填**，并在表头注明"发货后 30 天回填"
- 若原台账有缺失区间，保留缺失行并标注可补录来源（如"据财务返工费用凭证可反推约 11 次"）

## 五、渲染技术要点

### Excel · openpyxl

```python
from openpyxl.styles import Font, PatternFill, Alignment, Border, Side
thin = Side(style='thin', color='C8D0DC')
BD   = Border(left=thin, right=thin, top=thin, bottom=thin)
HF, HFONT = PatternFill('solid', fgColor='2D6CDF'), Font(bold=True, color='FFFFFF', size=10)
# 语义色：高 C62F2F / 中 B9770A / 通过 1E8E5A / 次级 5A6675
ws.freeze_panes = 'A2'
ws.auto_filter.ref = f'A1:L{last_row}'
ws.sheet_view.showGridLines = False
```

复制样式必须 `copy.copy(cell.font)`，直接读 `.font.color.rgb`传给 `Font()` 会报类型错误。

### PDF · reportlab（唯一可靠）

中文必须用内置 CID 字体：

```python
from reportlab.pdfbase import pdfmetrics
from reportlab.pdfbase.cidfonts import UnicodeCIDFont
pdfmetrics.registerFont(UnicodeCIDFont('STSong-Light'))
F = 'STSong-Light'
```

- A4 竖版即可（决策单不需要 A3）
- 会签栏用Table 画，行高至少 40pt 留出手写签字空间
- 必须给Table 显式 `rowHeights`，否则内容只占上半页
- 不要试 Chrome headless / wkhtmltopdf / weasyprint，沙箱下均不可用

### 渲染脚本内置自检（跑不过就不出文件）

```python
assert 可发 + 待返工 + 待剔除 + 暂缓 ==总数量, '数量不守恒'
assert 不良数 <= 抽检数量, '不良数不能大于抽检数'
# 复核判定与 Ac 的一致性
assert (判定 == '合格') == (不良数 <= Ac), 'AQL 判定与结论矛盾'
```
