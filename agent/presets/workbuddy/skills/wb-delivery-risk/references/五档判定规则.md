# 五档判定规则· 完整版

本文件是 SKILL.md STEP 4 的展开，可直接作为企业内部《出货放行判定规范》使用。

---

## 一、判定总顺序（不可调整）

```
CR 致命缺陷？ ──是──→🔴 拒收隔离（终止）
     │否
红线①安全/特殊特性超差？ ──是──→ 🔴 拒收隔离（终止）
     │否
红线③ 影响无法评估？ ──是──→ 🔴 拒收隔离或 补齐评估依据后重判（终止）
     │否
按 CR/MA/MI 重判等级 → 用对应 AQL 档位重算 Ac
     │
不良数 ≤ Ac？ ──是──→ 🟢 放行（出排除性结论，引用等级归类依据）
     │否
红线② 合同零缺陷？ ──是──→ 让步路径关闭，跳至「返工可行性」
     │否
协议允许让步 且缺陷为 MI？ ──是──→ ⚪ 让步接收（须客户书面回函）
     │否
返工技术可行 且 完成日 ≤ 交货日？ ──是──→ 🔵 返工后复检
     │否
仍有协商空间（分批/改期/部分交付）？ ──是──→ 🟡 暂缓放行
     │否
                └──→ 🔴 拒收隔离
```

## 二、各档的前置条件与必写内容

### 🟢 放行

**前置条件（满足任一）**
- 按正确 AQL 档位复核，不良数 ≤ Ac
- 协议明文将该缺陷类型列为可让步的次要缺陷，且台账中有同类先例（客户已接收、无后续投诉）

**必须写明**
- 送货单备注内容（缺陷件数、缺陷描述）
- 是否需附让步清单
- 留存凭证方式（送货单签收件 / 客户回函 / 双方确认单）

**注意**：即使判放行，若批内确有缺陷件，仍须在送货单备注。**隐瞒缺陷发货是另一类风险**。

---

### 🔵 返工后复检

**前置条件（必须全部满足）**
1. 返工技术可行（缺陷类型允许修复）
2. **返工完成日 ≤ 约定交货日**（必须验算，见第三节）
3. 返工不会引入新的超差风险，或风险可通过复检拦住

**必须写明**
- 返工方式（修磨 / 返镀 / 重新烧录 / 挑选剔除…）
- 单件返工工时、需返工件数、返工总工时
- 可投入人力与预计完成日
- **返工本身的风险**（例：油石修磨过量会导致尺寸超下差）
- 复检项目与范围（全检 / 加严抽样），复检不合格的后续处置

**不可修复的缺陷类型（不得判返工）**
- 孔位/孔距偏移（位置尺寸不可逆）
- 材质错误、热处理硬度不足
- 尺寸超上差可修，**超下差不可修**（材料已去除）

---

### 🟡 暂缓放行

**这一档是本规范的核心，中小企业最常落此档。**

**前置条件**
- 让步路径关闭（命中红线②）或 返工不可行/来不及
- 但仍存在协商空间：与客户谈分批交付、谈改期、谈部分交付、谈降级使用

**必须写明（四要素，缺一不可）**
1. **暂缓原因**（引用条款编号或验算结论）
2. **责任人**（通常是销售负责人，因为要对外沟通）
3. **关闭条件**（达成什么条件后转为放行或其他档）
4. **预计关闭时间**

**关键表述原则**：暂缓 ≠ 不发。写成"现在还不能发，条件是 X，谁在什么时候之前落实"。**含糊地拖着是最坏的结果**——既没发货也没通知客户，等客户发现时已经失去所有协商余地。

**时间紧迫性提示**：若客户产线上线日临近，必须明确写"越晚通知代价越大"，并给出建议通知话术。

---

### ⚪ 让步接收

**前置条件（必须全部满足）**
1. 未命中任何红线
2. 客户质量协议**明文允许**让步接收
3. 缺陷等级为 MI 次要（MA 主要缺陷让步须额外工程评估与更高层级批准）
4. **已取得或确定可取得客户书面回函**

**必须写明**
- 回函要求（邮件 / 正式函件 / 系统流程）与预计周期
- 使用条件与限用范围（例：仅限本批、仅限该型号、不得用于出口件）
- 追溯方式（批号标识、箱号范围、后续如何追溯到最终用途）
- 授权层级（让步接收通常须总经理或质量总监批准）

**硬规则**：**未获客户书面回函前不得发货**。口头同意、微信同意都不算——争议发生时无法举证。

---

### 🔴 拒收隔离

**前置条件（满足任一）**
- CR 致命缺陷
- 命中红线① 安全/特殊特性超差
- 命中红线③ 影响无法评估且无法补齐依据
- 不良率远超可接受范围，返工与挑选均不经济

**必须写明**
- 标识隔离方式（红色标签 / 隔离区位置 / 系统冻结）
- **全批去向追溯**（是否已有部分流出、流向哪里、是否需召回）
- 后续处置责任人与时限（返工 / 降级/ 报废的决策路径）

## 三、交期验算方法（判返工前必做）

```
返工总工时 = 需返工件数 × 单件返工工时
返工完成日 = 开始日 + ceil(返工总工时 ÷ (可投入人力 × 每日有效工时))
外协返工完成日 = 送出日 + 外协加工天数 + 往返运输天数
复检完成日 = 返工完成日 + 复检所需天数
```

**判定**：`复检完成日 ≤ 约定交货日` → 可判返工；否则转暂缓放行。

**每日有效工时默认取 7.5 小时**（8小时减去交接与准备），企业可自行调整。

**注意**：不要用"约定交货日"直接比，要留出**出货准备与运输时间**。客户来提货的可当日交，快递发货要预留 1~2 天。

---

## 四、成品库存兜底检查（最容易被忽略的一步）

判暂缓之前，必须先做这一步。

**检查项**
1. 是否有同产品编码的已检合格成品库存
2. 库存批号对应的**图纸版本是否与本单一致**（版本不一致不可顶替）
3. 是否为客户专用件（专用件通常无通用库存）
4. 可顶替数量 vs 本批需求数量 → 缺口

**典型结论形态**
> 成品库存 LOT-XXX 有 200 件已检合格（同图纸版本），可先发 200 件保客户上线，缺口 120 件返工后补。**这样既不违约也不放不合格品。**

**这一步的价值**：它经常是唯一能同时保住质量和交期的路。跳过它会导致本可以"部分交付"的批次被整批暂缓。

## 五、两边代价的取数口径

### 放行的风险（从客户协议取）
- 批量不良索赔条款（按起数 / 按批/ 按件）
- 停线追偿条款（是否全额追偿）
- 挑选与全检费用承担方
- 供应商评分与降级影响
- 三包/质保期条款

### 不放行的代价（从订单与协议取）
- 延期交货违约金（费率 × 天数，注意上限）
- 客户产线上线日 → 延期是否导致对方停线
- 是否影响后续订单与份额
- 内部成本：返工工时、挑选人工、外协费用、加急运费

**呈现要求**：并列摆出，不做加总（口径不同不可直接相加），不推荐倾向性结论。**由签字的人权衡。**
