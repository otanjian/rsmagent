# 输出骨架与渲染脚本

## 文件清单

- `SO-02_丢单复盘事实表.xlsx` —— 正式件本体 · 5 sheet · 结论与责任栏留空 · 含签批栏
- `SO-02_待回答问题清单.xlsx` —— 可派发给销售 · 每条只问事实不作评价
- `SO-02_异议闭环追踪表.xlsx` —— 客户异议逐条 · 回应情况与间隔天数

## sheet 结构

1. `结论摘要` —— 本次结论 / 关键指标 / 输入依据 / 人工边界 / 签批栏
2. `1.痕迹归集` —— 列头：来源 | 痕迹条数 | 时间戳性质 | 可信度分级 | 本次用途
3. `2.实质互动筛选` —— 列头：来源与记录类型 | 条数 | 举例（原文） | 是否计入实质互动
4. `3.异议追踪` —— 列头：客户提出时间 | 提出方式 | 异议内容 | 我方回应记录 | 间隔天数 | 是否闭环
5. `4.决策链缺口` —— 列头：角色（MEDDIC 口径） | 客户方对应人 | 是否接触过 | 接触次数 | 最后一次接触 | 在记录中的证据
6. `5.公开事实核对` —— 列头：项目 | 我方报价/情况 | 对手（苏州锐锋） | 差额或对比 | 来源 | 可否核实
7. `6.留证与签批` —— 列头：序号 | 矛盾点 | 支撑事实（含来源） | 待回答问题（只问事实） | 回答所需材料 | 结论栏

## 视觉规范

正式件本体用**风格 A**（浅灰表头 `F6F8FB` + 深字 `1A2332`）；
清单类用**风格 B**（蓝底白字 `2D6CDF`）。同一个包里不要混用。

```python
INK, MUTED, GREY = "1A2332", "5A6675", "8A94A3"
HEAD_A, HEAD_B   = "F6F8FB", "2D6CDF"
RED, AMBER, GREEN = "C62F2F", "B9770A", "1E8E5A"
FONT = "微软雅黑"
```

必做三件事：

```python
ws.freeze_panes = "A4"                          # 冻结表头
ws.auto_filter.ref = f"A3:{last_col}{last_row}"   # 开筛选
ws.sheet_view.showGridLines = False              # 关网格线，更像正式件
```

## 签批栏（正式件必备）

编制 / 审核 / 会签 / 批准四栏 + 日期列。
**推荐意见、完成质量、责任认定三栏留空。**

## 渲染脚本自检

```python
# 分项加总必须等于合计
assert abs(sum(items) - total) < 0.01, f"分项 {sum(items)} != 合计 {total}"
# 占比合计必须等于 100%
assert abs(sum(pcts) - 100) < 0.1
# 行数守恒
assert len(out_rows) == len(in_rows), "行数不守恒"
```

跑不过就不出文件 —— 从根上杜绝「合计对不上」这种一眼被看穿的错。
