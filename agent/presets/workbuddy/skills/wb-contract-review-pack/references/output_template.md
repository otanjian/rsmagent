# 输出骨架与渲染脚本

## 文件清单

- `QC-03_合同评审齐套核验表.xlsx` —— 正式件本体 · 5 sheet · 含四段会签栏
- `QC-03_缺件与责任清单.xlsx` —— 可派发 · 每条带卡住哪段、找谁要、今日可否取
- `QC-03_会前待决问题清单.xlsx` —— 四段各自须当场拍板的问题

## sheet 结构

1. `结论摘要` —— 本次结论 / 关键指标 / 输入依据 / 人工边界 / 签批栏
2. `1.视图归集` —— 列头：会签段 | 审核要点（制度出处） | 本次挂靠材料项数 | 其中本次特有 | 占 12 项
3. `2.齐套核验` —— 列头：序号 | 材料名称 | 挂靠段 | 持有人 | 状态 | 问题说明
4. `3.主体一致性` —— 列头：核验项 | 资质原件 / 系统载明 | 合同文本载明 | 是否一致 | 有效期或范围
5. `4.缺件影响` —— 列头：缺件项 | 卡住哪一段 | 为什么卡住（制度出处） | 找谁要 | 今日可否取到 | 不处理的代价
6. `5.会前提示` —— 列头：会签段 | 须当场拍板的问题 | 依据材料 | 定不了的后果 | 拍板人
7. `6.留证与签批` —— 列头：优先级 | 待处理项 | 卡住哪一段 | 处理动作 | 责任人 | 完成时点 | 验收标准

## 视觉规范

正式件本体用**风格 A**（浅灰表头 `F6F8FB` + 深字 `1A2332`）；
清单类用**风格 B**（蓝底白字 `2D6CDF`）。同一个包里不要混用。

```python
INK, MUTED, GREY = "1A2332", "5A6675", "8A94A3"
HEAD_A, HEAD_B   = "F6F8FB", "2D6CDF"
RED, AMBER, GREEN = "C62F2F", "B9770A", "1E8E5A"
FONT = "微软雅黑"
```

必做三件事：

```python
ws.freeze_panes = "A4"                          # 冻结表头
ws.auto_filter.ref = f"A3:{last_col}{last_row}"   # 开筛选
ws.sheet_view.showGridLines = False              # 关网格线，更像正式件
```

## 签批栏（正式件必备）

编制 / 审核 / 会签 / 批准四栏 + 日期列。
**推荐意见、完成质量、责任认定三栏留空。**

## 渲染脚本自检

```python
# 分项加总必须等于合计
assert abs(sum(items) - total) < 0.01, f"分项 {sum(items)} != 合计 {total}"
# 占比合计必须等于 100%
assert abs(sum(pcts) - 100) < 0.1
# 行数守恒
assert len(out_rows) == len(in_rows), "行数不守恒"
```

跑不过就不出文件 —— 从根上杜绝「合计对不上」这种一眼被看穿的错。
