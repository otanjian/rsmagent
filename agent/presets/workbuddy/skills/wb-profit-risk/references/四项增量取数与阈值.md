---

## 一、为什么放弃"精确毛利"

一个必须承认的现实：中小制造企业的成本核算颗粒度是**只算得准料、算不准工、几乎算不到费**。

| 成本项 | 能否算准 | 原因 |
|---|---|---|
| 材料 | **能** | 领料单有明确数量与单价，BOM 有标准用量 |
| 工时 | **不能** | 车间不按工单记返工工时；标准工时表多为几年前编制未更新；工序费率未按实际调整 |
| 费用 | **基本不能** | 加急运费挂"管理费用-运输费"总账不指定订单；水电等间接费用的分摊口径是管理约定而非计算问题 |

所以：**在这种数据基础上声称能算出精确的单张订单毛利，财务一问就露。**

但反过来 —— **把单项目成本误差控制在 5% 以内，对指导报价和决策已经够了**。这是这个 Skill 的定位：做偏差信号，不做核算。

**同时必须做的一件事**：把估算部分的占比明确写出来。若估算只占增量的 2~3%，说明结论主要来自可准确归集的项，站得住；若估算占到 20% 以上，就要提示"结论较大程度依赖估算"。

## 二、四项增量成本的算式与取数

### ① 超领材料 [可准确归集]

```
超领量= 实际领用 − BOM 标准用量
超领金额 = 超领量 × 单价
```

**要点**：
- **返工补料通常是单独一张领料单**，其 BOM 标准用量为 0，整笔都是增量，容易漏
- 要区分「正常损耗略超」与「异常超领」：前者金额小、原因栏写正常损耗；后者往往写"试切废品较多""返工补料"
- 若「是否走审批」全为否（常态），说明**超领无法在发生时预警，只能事后反算** —— 这条要写进流程建议

### ② 外协增量 [可准确归集，但滞后]

```
外协增量= 实际外协费合计 − 报价内外协费
```

**要点（最容易出错的一项）**：
- **必须包含"未入账"部分**。外协对账通常滞后约 1 个月，若只取已入账，增量可能算成 0
- 留意两类报价时不存在的外协：**返工件的二次外协**（如二次热处理）、**加急外协**（如加急表面处理）
- 这两类加起来往往就是外协增量的全部

### ③ 加急运费 [常需反查，见第三节]

```
加急运费增量 = Σ 归属本订单的加急运输费用
```

报价里通常不含加急运费（因为报价时假设正常交付），所以**实际发生的加急运费几乎全额是增量**。

### ④ 返工工时 [只能估算]

```
该工序单件工序成本 = 标准工时(min) ÷ 60 × 综合费率(元/h)
返工成本估算= Σ(该工序返工件数 × 该工序单件工序成本)
```

**要点**：
- 车间只记返工件数不记工时，所以只能这样估
- **必须标注标准工时表的编制年份**（如"2025 年编制未更新"），让人知道估算的精度边界
- 同一批件的多道工序返工要分别算（如精车返工 36 件 + 热处理返工 36 件是两笔）

### ⚠ 关于「工费」为什么不做逐项比对

报价里的「工费」多为业务员按经验估算（无标准工时支撑），实际工时也拿不到。**两边都不准的项，逐项比对没有意义**，只会制造假精度。

正确做法：**工费项不做逐项比对，只并入报价成本合计看总偏差**。并在开头声明这一点。

## 三、反查未挂订单费用的方法（关键一步）

加急运费在记账时常挂"管理费用-运输费"总账，不指定订单号，于是它躺在期间费用里，**不进任何订单的成本**。

### 三个线索（必须两个以上交叉）

| 线索 | 判据| 强度 |
|---|---|---|
| **收货客户** | 与订单客户匹配 | 中（同客户可能有多张单） |
| **发货日期** | 落在该订单的交付期间| 中 |
| **备注语义** | 如"客户催货首批80 件走空运""返工件补发" | **强**（可与返工单交叉验证） |

### 判定规则

```
IF 两个以上线索同时指向同一订单:
    归入该订单，并标明"本项为反查归入，原记账科目为 XX"
ELIF 同客户有多张在制单且无法区分:
    标"无法归属，建议财务核实"，列出候选订单
ELSE:
    标"无法归属"
```

**绝不猜测。** 归错订单比不归更糟——它会让另一张单被误判。

### 这一步的额外价值

它会暴露一个流程缺口：**加急运费应在记账时就挂订单号**。

这类费用不挂订单，意味着**该企业所有订单的成本都被系统性低估**。这条建议往往比单张订单的偏差金额更值钱。

## 四、返工的连锁成本（容易只算一笔）

一次返工的真实代价不止返工工时。以案例中 36 件密封槽超差为例：

| 连锁项 | 金额 | 出处 |
|---|---|---|
| 返工补料 | 7,650.00 | 领料单 ML-20260802-118（180 kg × 42.50） |
| 二次外协热处理 | 4,320.00 | 外协对账 OS-202608-024（36 件 × 120.00） |
| 返工件补发专车 | 3,200.00 | 物流 LG-20260808-09|
| 返工工时（估算） | 396.00 | 36 件 × 热处理单件成本 11.00 |
| **合计** | **15,566.00** | —— |

**返工单上写的只是"密封槽尺寸超差 36 件"。**

所以在建议动作里要把这条链算出来，并指出：**若剩余批次的同类问题未解决，这条成本链会重复。**

## 五、阈值判定与调整

```
实际成本   = 报价成本合计 + 四项增量合计
预计毛利率 = (合同额 − 实际成本) / 合同额
偏差(pt)   = 预计毛利率 − 报价毛利率
阈值       = 报价毛利率 − 5 个百分点     # 默认
```

| 判定 | 条件 | 输出要求 |
|---|---|---|
| 🔴 已跌破 | 预计毛利率 < 阈值 | 责任面拆解 + 建议动作 + 止损建议 |
| 🟡 关注 | 未跌破但偏差 ≥ 2pt，或已发生过一次返工 | **前瞻提醒**："若再出现一次同类返工将接近阈值" |
| 🟢 正常 | 偏差 < 2pt 且无异常事件 | **明确写"正常，无需处置"** |

### 阈值怎么调

- 报价毛利率本身低（如 15% 以下）的订单，5个百分点太宽 → 建议改为「报价毛利率 × 80%」
- 长周期订单（3 个月以上）建议收紧到 3 个百分点，因为还有时间继续恶化
- **阈值是企业自己的风险偏好，Skill 只提供默认值**

### 为什么必须有"正常"行

如果一份扫描报告里所有单都异常，看的人第一反应是"这套东西在凑异常"。**正常行的作用是对照** —— 它证明这套判定不是把所有单都标红。

## 六、责任面拆解的口径

每一项增量指向哪个部门**方向**（不是定责，是给老板一个追问的起点）：

| 增量项 | 典型原因 | 归口方向 |
|---|---|---|
| 超领材料 | 试切废品多、返工补料 | 生产（工艺参数/操作） |
| 外协增量 | 返工二次外协、加急外协 | 品保（返工源头）+ 采购（加急议价） |
| 加急运费 | 客户催货、返工件补发 | 销售（交期承诺）/ 生产（延误源头） |
| 返工工时 | 工序质量问题 | 品保 + 工艺 |

**硬规则：不替老板做商业取舍判断。**

战略客户是否接受低毛利换客户关系、要不要为保交期继续追加投入 —— 这些涉及客户价值、后续订单预期、战略取舍，属商业决策。

Skill 只做一件事：**把责任面拆干净，让老板拿着这个去开会。** 并明确写"需老板判断，本报告不做此建议"。
