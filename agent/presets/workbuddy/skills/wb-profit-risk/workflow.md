# 在制订单利润风险提示 Skill

> 财务岗位场景 8.2 专用 · **事中盯单**（区别于 2.1 经营复盘的期末回看）· 从五份数据 → 四项增量成本摊回订单 → 反查未挂订单费用 → 阈值判定 → 责任面拆解 + 建议动作

---

## 1. 用途

这个岗位动作在多数中小企业**是个空位**——没人有"事中盯单毛利"这个 KPI，等财务月底结账时钱已经花完了。这个 Skill 一次做完五件事：

1. **取报价基线**：从报价测算取材料/工/外协/其他四项结构与报价毛利率
2. **归集四项增量成本**：超领材料（准）、外协增量（准但滞后）、加急运费（**常需反查**）、返工工时（**只能估算**）
3. **反查未挂订单的费用**：按收货客户 + 发货日 + 备注语义，把挂在"管理费用-运输费"总账下的加急运费归回订单
4. **阈值判定**：预计毛利率跌破「报价毛利率 − 5 个百分点」即提示
5. **责任面拆解 + 建议动作**：每笔增量指向哪个部门，含跨单的提前提醒；**不替老板做商业取舍**

**这个 Skill 明确不做什么：不做精确毛利核算。**

原因是一个必须承认的现实：中小制造企业**只算得准料、算不准工、几乎算不到费**。车间不按工单记返工工时、标准工时表往往是几年前编的、加急运费不挂订单号。在这种数据基础上声称能算出精确的单张订单毛利，财务一问就露。

但反过来：**把单项目成本误差控制在 5% 以内，对指导报价和决策已经够了**。所以这个 Skill 做的是"偏差信号"，并把估算部分的占比明确写出来，让人自己判断结论稳不稳。

## 2. 触发方式

### 2.1 用户一句话触发（推荐）

```
在制的这几张单，帮我看下有没有哪张的毛利已经跌下来了。
报价时的成本测算、领料单、外协对账、运费、返工记录我都放一起了。
工时那块我们算不准，你别硬算 —— 能估的估一下但要标出来是估的。
运费里有几笔当时没挂订单号，你按客户和发货日期看能不能对上。
跌得多的那张，告诉我钱花在哪几项、大概该找哪个部门问。
接不接这个结果我自己判断，你别替我下结论。
```

### 2.2 输入材料清单

| # | 材料 | 必需 | 已知缺陷 | 缺失时的降级策略 |
|---|---|---|---|---|
| 1 | 在制订单与报价测算 | **必需** | 「报价·工费」多为经验估算，无标准工时支撑 | **无此项无法运行** —— 没有报价基线就没有偏差。若只有合同总额无成本拆解，改为"只能给增量成本绝对值，无法算毛利偏差" |
| 2 | 领料与超领记录 | **必需** | 超领普遍不走审批，只能事后反算 | 缺失时超领项标为无法判定 |
| 3 | 外协加工对账 | 建议 | **滞后约 1 个月**，含未入账部分 | 缺失时提示"外协增量未计入，实际偏差可能更大" |
| 4 | 物流与加急运费 | 建议 | **常挂"管理费用-运输费"总账不指定订单号** | 缺失时提示"加急运费未计入，本项在类似案例中可占增量两成以上" |
| 5 | 返工记录与标准工时 | 可选 | 只记件数不记工时；标准工时表未更新 | 缺失时返工项标为无法估算 |

## 3. 五步法工作流程

### STEP 1 · 取报价基线并声明可比性

从报价测算取四项：材料费 / 工费 / 外协费 / 其他费用，以及报价成本合计与报价毛利率。

**必须先做的一个声明**：如果「报价·工费」为经验估算（多数情况），则**明确说明工费项不做逐项比对**，只并入合计看总偏差。

自检：`材料费 + 工费 + 外协费 + 其他费用 == 报价成本合计`；`报价毛利率 == (合同额 − 报价成本) / 合同额`。

### STEP 2 · 归集四项增量成本

**① 超领材料** [可准确归集]

```
超领金额 = (实际领用 − BOM 标准用量) × 单价
```
注意：返工补料通常单独一张领料单（标准用量为 0），要一并计入。

**② 外协增量** [可准确归集，但滞后]

```
外协增量 = 实际外协费合计 − 报价内外协费
```
**必须包含"未入账"部分。** 外协对账滞后约 1 个月，若只取已入账会严重低估——案例中若只取已入账，15,120 元的增量会变成 0。

要留意两类"额外"外协：**返工件的二次外协**、**加急外协**（如加急表面处理）。这两类在报价时都不存在。

**③ 加急运费** [常需反查，见 STEP 3]

**④ 返工工时** [只能估算]

```
返工成本估算 = Σ(该工序返工件数 × 该工序单件工序成本)
该工序单件工序成本 = 标准工时(min) ÷ 60 × 综合费率(元/h)
```

**所有由此推出的金额必须标注为估算值**，并在合计处给出**估算占比**。

### STEP 3 · 反查未挂订单的费用（这一步决定会不会漏掉五分之一偏差）

加急运费是四项里最容易丢的：它在记账时常挂"管理费用-运输费"总账，不指定订单号，于是躺在期间费用里，不进任何订单成本。

**反查三个线索（需交叉验证，不能只靠一个）**：

1. **收货客户** —— 与订单的客户匹配
2. **发货日期** —— 是否落在该订单的交付期间
3. **备注语义** —— 如"客户催货首批 80 件走空运""返工件补发"，后者还能与返工单交叉验证

**只有两个以上线索同时指向同一订单时才归入**，且必须在输出中标明"本项为反查归入，原记账科目为 XX"。

**若线索不足以确定归属**：标为"无法归属，建议财务核实"，**不要猜**。

**这一步会顺带暴露一个流程缺口**：加急运费应在记账时就挂订单号。这类费用不挂订单，等于**该企业所有订单的成本都被系统性低估**。这条建议要写进输出。

### STEP 4 · 阈值判定

```
实际成本 = 报价成本合计 + 四项增量合计
预计毛利率 = (合同额 − 实际成本) / 合同额
偏差(pt) = 预计毛利率 − 报价毛利率
阈值 = 报价毛利率 − 5 个百分点# 默认值，企业可调
```

| 判定 | 条件 | 输出 |
|---|---|---|
| 🔴 已跌破 | 预计毛利率 < 阈值 | 需处置+ 责任面拆解 + 建议动作 |
| 🟡 关注 | 未跌破但偏差 ≥ 2pt，或已发生一次返工 | 前瞻提醒（"若再出现一次同类返工将接近阈值"） |
| 🟢 正常 | 偏差 < 2pt 且无异常事件 | **明确判"正常，无需处置"** |

**硬规则：必须存在被判"正常"的订单行。** 如果一份扫描报告里所有单都异常，看的人第一反应是"这套东西在凑异常"。正常行的作用是对照。

### STEP 5 · 责任面拆解 + 建议动作

**责任面拆解**：每一项增量指向哪个部门方向。例如：
- 超领（试切废品）→ 生产
- 外协增量（返工二次外协 + 加急外协）→ 品保 + 采购
- 加急运费（客户催货）→ 销售 / 交期承诺

**跨单提前提醒（高价值输出）**：检查是否存在**同产品 / 同工艺 / 同客户的其他在制订单**。若某单已暴露特定工序的返工问题，而另一单同工艺且尚在制，则提示"同类返工可能重演，建议在 X、Y 两道工序提前介入首件确认"。

**这类提示的价值在于它是提前的** —— 另一单还来得及。

**流程层面建议**：把本次发现的数据缺口写出来（如运费不挂订单号、超领无审批、标准工时表过期）。这些可能比单张订单的偏差金额更值钱。

## 4. 输出结构（固定，不可缺项）

```
一、数据可比性声明（哪部分准、哪部分反查、哪部分估算、工费为何不逐项比）
二、反查结果（未挂订单的费用如何归位，含反查依据）
三、四项增量成本明细（逐笔算式+ 单据号 + 可信度标记）
四、订单毛利偏差总表（全部订单 + 阈值判定 + 含"正常"行）
五、建议动作（含责任面拆解 + 跨单提前提醒）
六、流程层面建议（本次暴露的数据缺口）
七、交付物：毛利预警 xlsx（2 sheet）+ 利润风险提示 pdf（1 页给老板）
```

## 5. 硬规则（不可违反）

1. **不声称精确毛利**。输出的是偏差信号，目标误差 5%。必须在开头声明数据可比性。
2. **估算项必须标注**，并在合计处给出估算占比。若估算占比 > 20%，须提示"结论较大程度依赖估算，建议先补齐工时数据"。
3. **反查必须两个以上线索交叉**，线索不足则标"无法归属，建议财务核实"，不得猜测。
4. **外协增量必须包含未入账部分**，否则严重低估。
5. **必须存在被判"正常"的订单行**，不允许把所有单都标异常。
6. **不替老板做商业取舍判断**。战略客户是否接受低毛利换客户关系，属商业决策，只做责任面拆解，明确写"需老板判断，本报告不做此建议"。
7. **每笔增量必须能追到原始单据号**。无单据号的金额不得写入。
8. **不做根因分析**。为什么返工、为什么试切废品多，属品质异常分析场景（9.1）。
9. **区别于经营复盘（2.1）**：本Skill 是事中盯单（颗粒度到单张在制订单），2.1 是期末回看（颗粒度到产品线/客户）。若用户要的是期末总览，提示切换。

## 6. 常见坑

| 坑 | 规避 |
|---|---|
| 追求精确毛利 | 做偏差信号，声明可比性，标注估算占比 |
| 外协只取已入账 | 必须含"未入账"部分 |
| 忽略挂在总账的加急运费 | 按客户 + 发货日 + 备注反查 |
| 反查只靠一个线索 | 两个以上交叉，不足则不归属 |
| 用返工件数直接乘一个拍脑袋的工时 | 用标准工时表，并标注该表的编制年份 |
| 把工费逐项比对 | 报价工费本身是估的，不可比，只并入合计 |
| 所有单都判异常 | 必须有"正常"行做对照 |
| 替老板判断"这单该不该接" | 只拆责任面，商业取舍留给人 |
| 漏掉返工的连锁成本 | 返工会连带：补料 + 二次外协 + 补发运费 + 工时，要算总账 |
