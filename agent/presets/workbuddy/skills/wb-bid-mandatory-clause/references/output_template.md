# 输出骨架与渲染脚本

## 文件清单

- `BD-01_实质性条款响应表.xlsx` —— 正式件本体 · 4 sheet · 含签批栏
- `BD-01_废标风险清单.xlsx` —— 可派发 · 每条带出处页码与后果
- `BD-01_答疑覆盖对照表.xlsx` —— 正本条款与答疑改动逐条对齐

## sheet 结构

1. `结论摘要` —— 本次结论 / 关键指标 / 输入依据 / 人工边界 / 签批栏
2. `1.条款抽取` —— 列头：章节 | 条款范围（正本页码） | ★号条款 | 等效强制表述 | 实质性条款合计 | 占比
3. `2.答疑覆盖` —— 列头：正本条号 | 正本原文要点 | 答疑改动 | 出自哪份答疑 | 按哪个判 | 对我方的影响
4. `3.响应比对` —— 列头：条号 | 正本页码 | 条款要点（最终版本） | 我方现状与依据 | 响应状态 | 差距
5. `4.差距归类` —— 列头：归类 | 条号 | 差在哪 | 差多少（可量化） | 替代方案（不含结论） | 谁能定
6. `5.废标风险排序` —— 列头：档位 | 条号 | 条款要点 | 招标文件写明的后果 | 本次能否在截止前解决 | 风险等级
7. `6.留证与签批` —— 列头：优先级 | 条号与出处 | 响应状态 | 处理动作 | 责任人 | 截止前可否完成 | 留证材料

## 视觉规范

正式件本体用**风格 A**（浅灰表头 `F6F8FB` + 深字 `1A2332`）；
清单类用**风格 B**（蓝底白字 `2D6CDF`）。同一个包里不要混用。

```python
INK, MUTED, GREY = "1A2332", "5A6675", "8A94A3"
HEAD_A, HEAD_B   = "F6F8FB", "2D6CDF"
RED, AMBER, GREEN = "C62F2F", "B9770A", "1E8E5A"
FONT = "微软雅黑"
```

必做三件事：

```python
ws.freeze_panes = "A4"                          # 冻结表头
ws.auto_filter.ref = f"A3:{last_col}{last_row}"   # 开筛选
ws.sheet_view.showGridLines = False              # 关网格线，更像正式件
```

## 签批栏（正式件必备）

编制 / 审核 / 会签 / 批准四栏 + 日期列。
**推荐意见、完成质量、责任认定三栏留空。**

## 渲染脚本自检

```python
# 分项加总必须等于合计
assert abs(sum(items) - total) < 0.01, f"分项 {sum(items)} != 合计 {total}"
# 占比合计必须等于 100%
assert abs(sum(pcts) - 100) < 0.1
# 行数守恒
assert len(out_rows) == len(in_rows), "行数不守恒"
```

跑不过就不出文件 —— 从根上杜绝「合计对不上」这种一眼被看穿的错。
