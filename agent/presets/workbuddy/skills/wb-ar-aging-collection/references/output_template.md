# 输出骨架与渲染脚本

## 文件清单

- `CR-02_逾期应收分档与催收方案.xlsx` —— 正式件本体 · 5 sheet · 含签批栏
- `CR-02_诉讼时效预警清单.xlsx` —— 可派发 · 按剩余天数排序 · 每笔带中断证据判定
- `CR-02_债权凭证齐备性核查表.xlsx` —— 逐笔逐项打勾 · 缺件标明后果与取件位置

## sheet 结构

1. `结论摘要` —— 本次结论 / 关键指标 / 输入依据 / 人工边界 / 签批栏
2. `1.口径归一` —— 列头：发票号码 | 客户 | 未收金额(元) | 特殊情形 | 口径处理 | 台账逾期天数 | 核准后逾期天数 | 是否调整
3. `2.账龄分档` —— 列头：账龄档 | 笔数 | 金额(元) | 占比 | 涉及客户 | 逾期天数区间
4. `3.诉讼时效` —— 列头：发票号码 | 客户 | 未收金额(元) | 时效起算日 | 起算依据 | 时效届满日 | 剩余天数 | 最后一次有效中断留痕 | 中断是否成立
5. `4.凭证齐备性` —— 列头：发票号码 | 客户 | 未收金额(元) | 合同 | 发票 | 送货签收单 | 对账确认 | 缺件后果 | 取件位置与所需动作
6. `5.风险叠加与分级` —— 列头：发票号码 | 客户 | 未收金额(元) | 账龄档 | 时效剩余 | 凭证齐备 | 公开风险信号 | 催收强度档 | 分档依据
7. `6.留证与签批` —— 列头：优先级 | 事项 | 依据条款 | 时效压力 | 动作 | 责任人 | 完成时点 | 验收标准

## 视觉规范

正式件本体用**风格 A**（浅灰表头 `F6F8FB` + 深字 `1A2332`）；
清单类用**风格 B**（蓝底白字 `2D6CDF`）。同一个包里不要混用。

```python
INK, MUTED, GREY = "1A2332", "5A6675", "8A94A3"
HEAD_A, HEAD_B   = "F6F8FB", "2D6CDF"
RED, AMBER, GREEN = "C62F2F", "B9770A", "1E8E5A"
FONT = "微软雅黑"
```

必做三件事：

```python
ws.freeze_panes = "A4"                          # 冻结表头
ws.auto_filter.ref = f"A3:{last_col}{last_row}"   # 开筛选
ws.sheet_view.showGridLines = False              # 关网格线，更像正式件
```

## 签批栏（正式件必备）

编制 / 审核 / 会签 / 批准四栏 + 日期列。
**推荐意见、完成质量、责任认定三栏留空。**

## 渲染脚本自检

```python
# 分项加总必须等于合计
assert abs(sum(items) - total) < 0.01, f"分项 {sum(items)} != 合计 {total}"
# 占比合计必须等于 100%
assert abs(sum(pcts) - 100) < 0.1
# 行数守恒
assert len(out_rows) == len(in_rows), "行数不守恒"
```

跑不过就不出文件 —— 从根上杜绝「合计对不上」这种一眼被看穿的错。
