# 输出骨架与渲染脚本

## 文件清单

- `QC-02_合同条款偏离清单.xlsx` —— 正式件本体 · 5 sheet · 含四段会签栏
- `QC-02_需法务确认项清单.xlsx` —— 可派发 · 按后果排序 · 每条带历史对照
- `QC-02_历史同类合同条款对照表.xlsx` —— 同一条款三份历史合同的表述与履约结果

## sheet 结构

1. `结论摘要` —— 本次结论 / 关键指标 / 输入依据 / 人工边界 / 签批栏
2. `1.条款拆解` —— 列头：条款项 | 标准模板条号 | 本次合同条号 | 条号粒度处理 | 本次是否有改动
3. `2.逐条比对` —— 列头：序号 | 条款项 | 标准模板原表述 | 本次合同表述 | 改动类型
4. `3.偏离方向` —— 列头：序号 | 条款项 | 分类 | 偏离方向 | 触发内控红线 | 后果与依据
5. `4.历史对照` —— 列头：合同编号 | 客户 | 成交金额(元) | 账期条款 | 逾期利息条款 | 验收视同条款 | 后续履约结果
6. `5.交叉核对` —— 列头：订单号 | 成交金额(元) | 设备运抵日 | 合同约定验收期限 | 验收单实际出具日 | 验收滞后(天) | 尾款回款情况
7. `6.留证与签批` —— 列头：优先级 | 偏离条款 | 方向 | 后果 | 处理动作 | 责任人 | 完成时点与验收

## 视觉规范

正式件本体用**风格 A**（浅灰表头 `F6F8FB` + 深字 `1A2332`）；
清单类用**风格 B**（蓝底白字 `2D6CDF`）。同一个包里不要混用。

```python
INK, MUTED, GREY = "1A2332", "5A6675", "8A94A3"
HEAD_A, HEAD_B   = "F6F8FB", "2D6CDF"
RED, AMBER, GREEN = "C62F2F", "B9770A", "1E8E5A"
FONT = "微软雅黑"
```

必做三件事：

```python
ws.freeze_panes = "A4"                          # 冻结表头
ws.auto_filter.ref = f"A3:{last_col}{last_row}"   # 开筛选
ws.sheet_view.showGridLines = False              # 关网格线，更像正式件
```

## 渲染脚本自检

```python
# 分项加总必须等于合计
assert abs(sum(items) - total) < 0.01, f"分项 {sum(items)} != 合计 {total}"
# 占比合计必须等于 100%
assert abs(sum(pcts) - 100) < 0.1
# 行数守恒
assert len(out_rows) == len(in_rows), "行数不守恒"
```

跑不过就不出文件 —— 从根上杜绝「合计对不上」这种一眼被看穿的错。
