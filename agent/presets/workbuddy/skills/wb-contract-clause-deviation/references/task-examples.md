# 可选任务

## 首推默认

恒晟精工的合同回来了，客户法务改过，销售说「就是改了几个日期」，今天要走签批。材料在这儿：销售合同标准模板的条款摘录、本次待签合同的条款摘录、合同评审制度与内控红线摘录、三份历史同类合同的同一条款对照台账，还有恒晟的历史履约记录。

帮我逐条比一遍，客户改了哪些地方——包括删掉半句、把日期改掉、把「应」改成「可」这种。每处改动标一下对我们有利还是不利，属于付款、违约、验收、知识产权、争议解决哪一类，触发内控红线的单独标出来。以前同类客户在同一条上是怎么写的、后来履约怎么样，也对一下；恒晟自己履约记录里踩过的坑一并拎出来。

交三份：合同条款偏离清单.xlsx（正式件本体，带四段会签栏）、需法务确认项清单.xlsx（按后果排序，每条带历史对照）、历史同类合同条款对照表.xlsx（同一条款三份历史合同的表述与履约结果）。这些条款能不能接受我要问法务，你别下结论，也别改合同文本。

## 只做逐条比对

先只做逐条比对这一步：标准模板和本次合同两份文本切到条款粒度，把所有改动点找出来，方向和分类都先不判。产出用 Excel 一张表：序号、条款项、标准模板原表述、本次合同表述、改动类型（新增／删除／措辞替换），删掉半句这种也要单独占一行。

## 换成按五类分类排

换个口径再跑一遍：这次不按条号顺序，改按付款、违约、验收、知识产权、争议解决五类分组排，每类里再按对我方有利还是不利分。产出用 Excel 一张表：分类、条号、偏离方向、是否触发内控红线、后果与依据。

## 一次比三份合同

演示数据里再加另外两家客户的待签合同条款摘录，三份合同一起比、各自出清单，最后给我一张横向对照表：客户、偏离处数、不利偏离处数、触发红线的条款分别是哪几条。产出用 Excel，对照表单独一张 sheet。

## 给法务顾问看的一页

把偏离清单压成法务顾问周三来那半天看的一页纸：只留不利偏离和触发红线的那几条，每条写清模板怎么写的、客户改成了什么、历史同类客户后来出了什么事。产出用一份 Markdown 一页纸，完整逐条比对表不要。

## 让它反驳自己

你判的这几处不利偏离，自己挑一下哪一处可能判重了——比如账期改 90 日，如果我们已有其他担保安排还算不算触发红线。逐条说明依据条文、你的疑问、要补什么材料才能确认。产出用 Excel 一张表：偏离条款、原判定、支撑条文、你的疑问、建议改为。

## 比对宏远机械那笔尾款

专门比 2023 年宏远机械那份合同：验收视同半句被删之后，87 万元尾款拖了 11 个月。把这次的验收条款、逾期利息条款跟他们那次逐条对起来。产出用 Excel 一张表：合同编号、客户、成交金额、账期条款、逾期利息条款、验收视同条款、后续履约结果，本次单独占一列。

## 对照内控红线自查

对照合同评审制度与内控红线摘录，把这份偏离清单自查一遍：红线条款有没有逐条核、该标的有没有标、需法务确认项有没有全提出来、四段会签栏是不是留空的。产出用 Excel 一张清单：红线条目、本次是否已核、结论、遗漏项，遗漏的排最前面。

## 折算成资金成本

拿本次待签合同的条款摘录和折扣核查结论，把账期从 30 日改到 90 日折算成钱：本单 186 万元多占 60 天，按短期融资年化 6% 算资金成本；再参照历史同类合同对照台账里宏远机械那笔尾款拖 11 个月算一个对照数。产出用 Excel 一张表，算式、利率、天数都写出来。

## 沉淀成偏离判定对照表

把这次的判定口径整理成下次评合同直接能用的清单：五类条款各看什么、哪些改动一律判不利、哪些触发内控红线、需法务确认项怎么排序。产出用 Markdown 一份《合同偏离判定与内控红线对照表》。
