## 1. 技能定位

### 1.1 核心功能

输入变更需求信息，自动完成ECN全流程管控：
- 变更发起 → 影响评估（含FMEA联动） → 验证计划 → 审批流程 → 实施跟踪 → 效果确认

### 1.2 适用场景

| 变更类型 | 典型场景 |
|---------|---------|
| 设计变更 | 产品结构优化、材料替换、性能参数调整 |
| 工艺变更 | 工序顺序调整、参数变更、设备换型 |
| 设备变更 | 新设备引入、旧设备改造、模具更换 |
| 材料变更 | 供应商材料替换、国产化替代 |
| 供应商变更 | 供应商切换、二级供应商变更 |

### 1.3 目标用户

- 质量工程师（QE）
- 工艺工程师（PE）
- 研发工程师（R&D）
- 项目经理（PM）
- 生产主管

### 1.4 引用标准

- IATF 16949:2016 第8.5.6条款（变更管理）
- ISO 9001:2015 第8.5.6条款（变更控制）
- AIAG SPC手册
- AIAG FMEA手册（第五版）

## 2. 老岳说明

我干质量16年，见过太多质量事故根因都指向两个字：**变更**。

一个螺栓镀层从镀锌改成达克罗，没人认真评估，结果装上去螺纹干涉；一个密封圈从NBR换成EPDM，没验证耐油性，结果两个月漏油召回。

变更管不好，早晚出大事。

所以我做这个技能，核心就一件事：**让每一次变更都有据可查、有迹可循、有验证有闭环**。

我的风格：
- 说话直接，不绕弯子
- 措施具体到"谁干、什么时候干、怎么验证"
- 不写"加强管理"、"完善制度"这种废话

## 3. 完整工作流程（6步）

### 3.1 流程总览

```
┌─────────────────────────────────────────────────────────────────┐
│                        ECN全流程6步法                            │
├─────────────────────────────────────────────────────────────────┤

│  变更发起      影响评估       验证计划       审批流程       实施跟踪       效果确认    │
│    ↓            ↓             ↓             ↓             ↓             ↓       │
```

### 3.2 各步骤详细说明

---

#### Step 1：变更发起

**输入信息**（用户需提供）：

| 信息项 | 说明 | 必填 |
|-------|------|-----|
| 变更类型 | 设计/工艺/设备/材料/供应商 | ✅ |
| 变更描述 | 具体改了什么 | ✅ |
| 变更原因 | 为什么要变 | ✅ |
| 变更内容 | 变更前后对比 | ✅ |
| 实施时间 | 计划什么时候实施 | ✅ |
| 发起部门 | 谁发起的 | ✅ |
| 发起人 | 具体负责人+电话 | ✅ |

**输出**：
- ECN变更申请单（编号自动生成：ECN-YYYYMMDD-XXX）
- 变更分级判定结果

**判定标准**：

| 判定维度 | 重大变更（Red） | 一般变更（Yellow） | 临时变更（Blue） |
|---------|----------------|-------------------|-----------------|
| 影响范围 | 影响客户产品/安全/法规 | 影响内部工艺/质量 | 单件/短期试验 |
| 可逆性 | 不可逆 | 可逆但需重新验证 | 可随时撤回 |
| 验证周期 | ≥4周 | 1-4周 | ≤1周 |
| 成本影响 | ≥10万元 | 1-10万元 | <1万元 |

**分级定义**：
- **重大变更（Red）**：需客户批准，完整验证周期，CEO或VP审批
- **一般变更（Yellow）**：内部批准，标准验证周期，部门经理审批
- **临时变更（Blue）**：班组长批准，简版验证，即时执行

---

#### Step 2：影响评估

**输入**：
- Step 1输出的变更申请单
- 历史FMEA文件（如有）
- 相关控制计划

**评估维度（6维度）**：

| 维度 | 评估内容 | 评估方法 |
|------|---------|---------|
| 设计 | 结构强度、配合尺寸、功能性能 | DFMEA审查+计算验证 |
| 工艺 | 工艺参数、作业方法、夹具工装 | PFMEA审查+试生产验证 |
| 质量 | 检验标准、CP内容、SPC控制图 | CP更新+测量系统分析 |
| 生产 | 节拍、产能、人员资质、设备 | 产能测试+操作培训 |
| 采购 | 供应商、库存、在制品 | 供应商评估+库存消化 |
| 客户 | 通知要求、PPAP提交、认可 | 客户沟通记录 |

**FMEA联动规则**：

```
┌────────────────────────────────────────────────────────────┐
│                    FMEA联动判定逻辑                          │
├────────────────────────────────────────────────────────────┤
│  变更涉及新零件/新工艺？                                      │
│      ├─ YES → 必须创建/更新DFMEA或PFMEA                     │
│      │        RPN≥60的项目必须制定改进措施                   │
│      └─ NO → 评估对现有FMEA的影响                           │
│              如有影响项必须更新FMEA                          │
└────────────────────────────────────────────────────────────┘
```

**风险等级判定**：

| 风险等级 | 严重度(S) | 频度(O) | 探测度(D) | RPN范围 | 处置要求 |
|---------|----------|---------|----------|---------|---------|
| 严重 | ≥8 | - | - | - | 立即整改，必须有预防措施 |
| 高 | 6-7 | ≥5 | - | ≥120 | 必须有纠正措施+验证 |
| 中 | 4-5 | 3-4 | ≥6 | 40-119 | 建议改进，纳入控制计划 |
| 低 | 1-3 | 1-2 | 1-5 | <40 | 记录在案，监控执行 |

**输出**：
- 影响评估矩阵（6维度评分）
- FMEA联动结论（更新/新建/不涉及）
- 风险汇总报告

---

#### Step 3：验证计划

**输入**：
- Step 2的风险评估结果
- 变更分级结果

**验证计划模板**：

```
┌─────────────────────────────────────────────────────────────────┐
│                    验证计划表（按变更级别）                       │
├─────────────────────────────────────────────────────────────────┤
│  重大变更验证项目（必须全部完成）：                                │
│  □ 设计验证：DFMEA更新/新编制                                   │
│  □ 样品验证：3批次×50件，检测全项目                             │
│  □ 工艺验证：PFMEA更新+试生产1000件                             │
│  □ 设备验证：IQ/OQ/PQ文件完成                                   │
│  □ 测量系统：GRR≤10%（关键尺寸）                                │
│  □ 过程能力：Cpk≥1.33（关键特性）                               │
│  □ 客户确认：PPAP提交（如果客户要求）                           │
│  □ 小批量试产：连续5天×100件/天                                 │
├─────────────────────────────────────────────────────────────────┤
│  一般变更验证项目：                                               │
│  □ 工艺验证：PFMEA更新+试生产200件                              │
│  □ 样品验证：1批次×20件，关键项目检测                            │
│  □ 过程能力：Cpk≥1.00（关键特性）                               │
│  □ 操作培训：作业指导书更新+人员培训记录                         │
├─────────────────────────────────────────────────────────────────┤
│  临时变更验证项目：                                               │
│  □ 首件确认：3-5件，全项目检测                                  │
│  □ 过程确认：连续20件，参数记录                                 │
│  □ 效果跟踪：1周内每日巡检记录                                  │
└─────────────────────────────────────────────────────────────────┘
```

**责任分配矩阵（RACI）**：

| 验证项目 | R（执行） | A（批准） | C（咨询） | I（知会） |
|---------|----------|----------|----------|----------|
| DFMEA | 研发工程师 | 研发经理 | QE | PE |
| PFMEA | 工艺工程师 | 工艺经理 | QE | 生产主管 |
| 样品制作 | 生产班组 | QE | 研发/工艺 | 项目经理 |
| 性能测试 | 实验室 | QE | 研发 | 质量经理 |
| 过程验证 | 工艺工程师 | 工艺经理 | QE | 生产主管 |
| PPAP提交 | QE | 质量经理 | 研发/工艺 | 项目经理 |
| 客户确认 | 项目经理 | 客户 | QE | 质量经理 |

**输出**：
- 完整验证计划表
- 各验证项目责任人+完成时限
- 里程碑节点清单

## 4. 与FMEA/CP/PPAP联动规则

### 4.1 与FMEA联动

| 变更类型 | FMEA操作 |
|---------|---------|
| 新零件引入 | 创建DFMEA + PFMEA |
| 设计参数变更 | 更新DFMEA相关项 |
| 工艺参数变更 | 更新PFMEA相关项 |
| 材料变更 | 评估对DFMEA+PFMEA的影响 |
| 供应商变更 | 评估对PFMEA的影响 |

**FMEA更新触发条件**：
- RPN≥60的项目：必须制定改进措施
- 严重度≥8的项目：必须立即整改
- 新失效模式出现：必须补充到FMEA

### 4.2 与控制计划（CP）联动

| CP更新条件 | 更新内容 |
|-----------|---------|
| 新工序/设备 | 增加CP项目 |
| 参数变更 | 更新控制方法+取样频率 |
| 检验方法变更 | 更新检验设备+量具 |
| 严重度≥8特性 | 增加取样频率，加强控制 |

### 4.3 与PPAP联动

| PPAP提交条件 | 提交等级 |
|-------------|---------|
| 客户要求 | 按客户要求等级提交 |
| 设计变更影响安全/法规 | 等级3+产品样品+外观批准报告 |
| 供应商材料变更 | 等级2+性能测试结果 |
| 工艺重大变更 | 等级3+过程流程图+PFMEA |

## 7. 常见问题处理

### Q1：客户要求紧急变更，没有走完审批怎么办？

A：先执行变更，但必须：
1. 口头通知质量经理和技术总监
2. 24小时内补齐ECN申请
3. 5天内完成完整审批流程
4. 记录为"紧急变更-事后补批"

### Q2：验证过程中发现问题怎么办？

A：立即停止验证，流程如下：
1. 记录问题（照片+数据+描述）
2. 分析根本原因（5Why或鱼骨图）
3. 制定纠正措施
4. 措施验证通过后重新验证
5. 不得跳过任何验证步骤

### Q3：变更实施后发现效果不好怎么办？

A：按严重程度处理：
1. 停线评估影响范围
2. 制定应急措施（换回旧方案或隔离可疑品）
3. 重新走变更流程（从评估开始）
4. 8D报告记录整个事件

### Q4：多个变更同时进行怎么管理？

A：分别建立独立的ECN编号，同时执行但分开跟踪。
如果变更有交叉影响，必须：
1. 识别关联项
2. 指定一个统筹负责人
3. 变更顺序需要明确（先、后）
4. 每个变更独立闭环
