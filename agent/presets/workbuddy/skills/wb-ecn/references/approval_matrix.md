# 变更分级与审批权限对照表

---

## 一、变更分级标准

### 1.1 分级判定矩阵

| 判定维度 | 重大变更（Red） | 一般变更（Yellow） | 临时变更（Blue） |
|---------|----------------|-------------------|-----------------|
| **影响范围** | 影响客户产品/安全/法规/主要功能 | 影响内部工艺/质量/次要功能 | 单件/短期试验/可忽略 |
| **可逆性** | 不可逆或需大量返工 | 可逆但需重新验证 | 可随时撤回 |
| **验证周期** | ≥4周 | 1-4周 | ≤1周 |
| **成本影响** | ≥10万元 | 1-10万元 | <1万元 |
| **客户要求** | 必须客户批准 | 视客户要求 | 不需要 |
| **文件影响** | BOM/图纸/FMEA/CP全部更新 | 部分文件更新 | 仅作业指导书 |

### 1.2 分级判定规则

**判定原则**：取最高等级作为最终分级

```
┌─────────────────────────────────────────────────────────────┐
│                    分级判定规则                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   满足以下任一条件 → 重大变更（Red）                         │
│   ✓ 影响安全/法规                                            │
│   ✓ 需客户批准                                               │
│   ✓ 验证周期≥4周                                             │
│   ✓ 成本影响≥10万                                            │
│   ✓ 不可逆                                                   │
│                                                             │
│   不满足重大，且满足以下任一条件 → 一般变更（Yellow）         │
│   ✓ 影响内部工艺/质量                                        │
│   ✓ 验证周期1-4周                                            │
│   ✓ 可逆但需验证                                            │
│   ✓ 成本1-10万                                               │
│                                                             │
│   不满足以上 → 临时变更（Blue）                              │
│   ✓ 单件试验/短期验证                                        │
│   ✓ 可随时撤回                                               │
│   ✓ 验证周期≤1周                                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 分级速查表

| 关键词/场景 | 推断级别 | 备注 |
|-----------|---------|-----|
| 碰撞安全件变更 | 重大 | 涉及法规 |
| 排放/环保相关 | 重大 | 涉及法规 |
| 客户指定变更 | 重大 | 需客户批准 |
| 召回相关 | 重大 | 最高优先级 |
| 供应商切换 | 视情况 | 影响大则为重大 |
| 材料国产化 | 视情况 | 一般为重大 |
| 工艺参数调整 | 一般 | |
| 设备换型 | 一般 | |
| 工装改进 | 一般 | |
| 小批量试产 | 临时 | |
| 紧急替代 | 临时 | |
| 试验件制作 | 临时 | |

## 二、审批权限矩阵

### 2.1 重大变更（Red）审批流程

**适用条件**：
- 影响安全/法规/客户产品
- 验证周期≥4周
- 成本≥10万元
- 必须客户批准

**审批节点（6级）**：

| 节点 | 审批角色 | 职责 | 审批时限 | 超时处理 |
|-----|---------|------|---------|---------|
| L1 | 发起部门经理 | 确认变更必要性、业务需求合理性 | 2工作日 | 自动晋升至L2 |
| L2 | QE主管 | 审核影响评估、FMEA联动 | 2工作日 | 自动晋升至L3 |
| L3 | 质量经理 | 批准验证计划、质量风险管控 | 2工作日 | 自动晋升至L4 |
| L4 | 技术总监 | 技术可行性、资源评估 | 3工作日 | 自动晋升至L5 |
| L5 | 客户批准 | 客户采购/质量确认 | 5工作日 | 必须等待 |
| L6 | 总经理 | 最终批准 | 2工作日 | - |

**总审批时限**：≤18工作日

## 三、特殊审批规则

### 3.1 紧急变更审批

**触发条件**：
- 客户索赔导致的紧急变更
- 产线停线需立即处理
- 安全/法规问题需立即整改

**紧急审批流程**：

| 正常流程 | 紧急流程 |
|---------|---------|
| 6级审批（18工作日） | 可跳至L3（2工作日） |
| 3级审批（5工作日） | 可跳至L2（即时） |
| 必须完整验证 | 可分阶段验证 |
| 事后48小时内补齐完整审批 |

**紧急变更记录**：

```
┌─────────────────────────────────────────────────────────────┐
│                  紧急变更事后补批记录                         │
├─────────────────────────────────────────────────────────────┤
│ ECN编号：_______________                                     │
│ 紧急原因：_______________                                     │
│ 实际执行时间：_______________                                 │
│ 发起人口头通知记录：                                          │
│   □已通知质量经理：时间_______ 方式_______                   │
│   □已通知技术总监：时间_______ 方式_______                   │
│ 补批完成时间：_______________                                 │
│ 补批审批人：_______________                                   │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 跨部门影响审批

**触发条件**：
- 变更影响≥2个部门
- 涉及采购、生产、质量等多部门

**跨部门会签要求**：

| 涉及部门 | 会签要求 | 会签人 | 时限 |
|---------|---------|-------|-----|
| 研发部 | □必须 □建议 □不需要 | | |
| 工艺部 | □必须 □建议 □不需要 | | |
| 生产部 | □必须 □建议 □不需要 | | |
| 采购部 | □必须 □建议 □不需要 | | |
| 质量部 | □必须 □建议 □不需要 | | |
| 设备部 | □必须 □建议 □不需要 | | |

**会签意见格式**：

```
部门：___________
会签人：___________
日期：___________
意见：
□ 同意，变更对本科室无影响
□ 同意，但需关注以下事项：________________
□ 不同意，原因：________________
□ 建议修改：________________
签字：___________
```

### 3.3 客户指定变更审批

**客户要求变更**：
- 提供客户书面要求
- 按客户要求时间执行
- 客户批准后跳过内部L1-L4

**审批流程简化**：

| 正常重大变更 | 客户指定变更 |
|---------|-----------|
| L1→L2→L3→L4→L5→L6 | L5(客户批准)→L6(总经理) |
| 18工作日 | 7工作日 |

### 3.4 批量变更审批

**触发条件**：
- 同一产品多个变更同时进行
- 系列化产品统一变更

**审批规则**：
- 变更编号：主编号+子编号（ECN-20240315-001-01）
- 主编号统一审批，子编号参考主编号结论
- 重大变更必须单独审批

## 四、审批时效管理

### 4.1 时效预警

| 预警级别 | 超时时间 | 处理方式 |
|---------|---------|---------|
| 绿色 | 正常 | - |
| 黄色 | 超时50% | QE发送催办提醒 |
| 橙色 | 超时80% | 自动晋升至下一级 |
| 红色 | 超时100% | 质量经理督办 |

### 4.2 加签机制

| 场景 | 加签要求 |
|-----|---------|
| 审批人休假 | 指定代理人或晋升至上一级 |
| 意见分歧 | 召开评审会议决策 |
| 特殊情况 | 技术总监+质量经理双人批准 |
