# 影响评估矩阵（6维度）

---

## 一、评估维度说明

本矩阵从6个维度对工程变更进行全面影响评估：

| 维度 | 负责部门 | 评估重点 |
|-----|---------|---------|
| 设计 | 研发部 | 产品功能、性能、安全、法规符合性 |
| 工艺 | 工艺部 | 工艺可行性、参数适配性、质量稳定性 |
| 质量 | 质量部 | 检验能力、CP更新、SPC控制、风险评估 |
| 生产 | 生产部 | 节拍产能、人员资质、设备状态、物料供应 |
| 采购 | 采购部 | 供应商资质、成本、交期、库存消化 |
| 客户 | 项目部 | PPAP要求、客户通知、规格认可 |

---

## 二、设计影响评估矩阵

### 2.1 评估项目

| 评估项 | 评估内容 | 评估方法 | 评估标准 |
|-------|---------|---------|---------|
| 结构强度 | 受力分析、疲劳寿命、安全系数 | CAE分析+试验验证 | 满足设计标准 |
| 配合尺寸 | 公差配合、互换性、装配性 | 尺寸测量+装配验证 | 符合图纸要求 |
| 功能性能 | 使用功能、工作参数、性能指标 | 功能测试+性能试验 | 满足技术规范 |
| 安全法规 | 安全要求、法规符合性 | 合规性检查 | 符合适用法规 |
| 接口匹配 | 与关联件的接口配合 | 匹配性验证 | 接口尺寸合格 |
| 可靠性 | MTBF、失效率、寿命 | 可靠性试验 | 满足设计寿命 |

### 2.2 影响程度判定

| 影响程度 | 判定标准 |
|---------|---------|
| **高** | 影响安全/法规/主要功能，需重新设计验证 |
| **中** | 影响次要功能或配合，需详细评估 |
| **低** | 几乎无影响，仅需确认 |

| 功能性能 | □有 □无 | □高 □中 □低 | | | | |

### 8.2 变更整体风险等级

| 整体风险 | 判定标准 | 综合风险说明 |
|---------|---------|-------------|
| **Red-重大** | ≥1个维度为"严重" | 必须完整验证+客户批准 |
| **Orange-较高** | ≥3个维度为"高"，无"严重" | 必须详细验证+多部门会签 |
| **Yellow-中等** | 有2-3个维度为"中"或"高" | 需要标准验证 |
| **Green-低** | 所有维度均为"低" | 简化验证即可 |

### 8.3 风险应对策略

| 风险等级 | 应对策略 | 验证要求 | 审批要求 |
|---------|---------|---------|---------|
| Red-重大 | 必须制定预防措施+应急计划 | 完整验证6项以上 | 6级审批+客户批准 |
| Orange-较高 | 必须制定改进措施 | 验证4-5项 | 4级审批 |
| Yellow-中等 | 建议改进措施 | 验证2-3项 | 3级审批 |
| Green-低 | 记录在案 | 简化验证1-2项 | 2级审批 |
