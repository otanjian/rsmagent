# 输出骨架与渲染脚本

## 文件清单

- `BD-03_投标可行性初筛意见表.xlsx` —— 正式件本体 · 4 sheet · 含签批栏
- `BD-03_硬门槛比对清单.xlsx` —— 可派发 · 逐条带招标文件出处
- `BD-03_垫资与投标成本测算表.xlsx` —— 四项目横向对比 · 含资源冲突提示

## sheet 结构

1. `结论摘要` —— 本次结论 / 关键指标 / 输入依据 / 人工边界 / 签批栏
2. `1.硬门槛筛` —— 列头：招标编号 | 项目简称 | 资质要求（公告条号） | 我方资质 | 业绩要求 | 我方业绩 | 是否接受联合体 | 硬门槛结论
3. `2.垫资测算` —— 列头：项目简称 | 测算基数(元) | 验收后付至 | 该阶段垫资(元) | 质保金比例 | 质保金金额(元) | 质保金占用(月) | 合计占用周期
4. `3.业主支付能力` —— 列头：招标人 | 近三年公开招标 / 中标公示 | 公开付款争议或涉诉记录 | 公开决算或结算情况 | 检索结论
5. `4.投标成本核算` —— 列头：招标编号 | 项目简称 | 标书制作(元) | 差旅(元) | 直接支出小计(元) | 占直接支出合计 | 投标保证金(元) | 占保证金合计
6. `5.初筛结论` —— 列头：项目简称 | 初筛档位 | 归档依据（可核） | 直接支出(元) | 保证金(元) | 质保金占用(月) | 推荐意见
7. `6.留证与签批` —— 列头：对比项 | 中州水务（第二包） | 东江水务 | 区属供水 | 化工园区

## 视觉规范

正式件本体用**风格 A**（浅灰表头 `F6F8FB` + 深字 `1A2332`）；
清单类用**风格 B**（蓝底白字 `2D6CDF`）。同一个包里不要混用。

```python
INK, MUTED, GREY = "1A2332", "5A6675", "8A94A3"
HEAD_A, HEAD_B   = "F6F8FB", "2D6CDF"
RED, AMBER, GREEN = "C62F2F", "B9770A", "1E8E5A"
FONT = "微软雅黑"
```

必做三件事：

```python
ws.freeze_panes = "A4"                          # 冻结表头
ws.auto_filter.ref = f"A3:{last_col}{last_row}"   # 开筛选
ws.sheet_view.showGridLines = False              # 关网格线，更像正式件
```

## 签批栏（正式件必备）

编制 / 审核 / 会签 / 批准四栏 + 日期列。
**推荐意见、完成质量、责任认定三栏留空。**

## 渲染脚本自检

```python
# 分项加总必须等于合计
assert abs(sum(items) - total) < 0.01, f"分项 {sum(items)} != 合计 {total}"
# 占比合计必须等于 100%
assert abs(sum(pcts) - 100) < 0.1
# 行数守恒
assert len(out_rows) == len(in_rows), "行数不守恒"
```

跑不过就不出文件 —— 从根上杜绝「合计对不上」这种一眼被看穿的错。
