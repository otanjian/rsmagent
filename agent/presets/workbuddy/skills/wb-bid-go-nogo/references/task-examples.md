# 可选任务

## 首推默认

这周来了四个招标公告，我一个人做不完。材料都在这儿：四份招标公告的关键信息汇总、四份公告的资格条款摘录、我们的资质证书与同类业绩台账、在建项目垫资占用明细、业主方公开信息检索记录，还有上季度投标投入与结果台账。

先帮我把根本没资格投的排掉，逐条对着公告原文比资质、业绩、注册地这些硬门槛。剩下的按付款条件算要垫多少钱、垫多久，垫资按最不利的节点算。业主方以前有没有拖过款、有没有涉诉，公开能查到的列出来，查不到的写明查不到。上季度投了 11 个标中了 2 个，这次每个标要花的钱也列清楚。四个项目的时间有没有撞车、我一个人做不过来，一并提示。

交三份：投标可行性初筛意见表.xlsx（正式件本体，含签批栏）、硬门槛比对清单.xlsx（逐条带招标文件出处）、垫资与投标成本测算表.xlsx（四个项目横向对比，含资源冲突提示）。投不投我拿到会上定，你别给结论，也别算中标概率。

## 只做硬门槛筛

先只做硬门槛这一步，垫资和成本先不碰：拿四份公告的资格条款摘录对资质证书与业绩台账，逐条判有没有资格投。产出用 Excel 一张表：招标编号、项目简称、资质要求（带公告条号）、我方资质、业绩要求、我方业绩、是否接受联合体、硬门槛结论。判不了的写「需确认」不要猜。

## 换成按垫资周期排序

换个口径再跑一遍：这次不按合不合格排，改按垫资周期长短排四个项目，垫资按付款条件里最不利的节点算。产出用 Excel 一张表：项目简称、测算基数、验收后付至比例、该阶段垫资、质保金比例与金额、质保金占用月数、合计占用周期，占用最长的排最前面。

## 一次排九个项目

演示数据里再加同期另外两批共五个公告的关键信息与资格条款摘录，九个项目一起过，最后给我一张九项目横向对照表：硬门槛是否通过、垫资周期、直接支出、保证金占用，按初筛档位分组排。产出用 Excel，对照表单独一张 sheet。

## 给销售总监看的一页

拿四份公告的关键信息汇总和资格条款摘录，把初筛意见压成销售总监上会看的一页纸：四个项目各一行，写清能不能投、要垫多久、这一次要花多少钱、资源有没有撞车、卡在哪一条。产出用一份 Markdown 一页纸，过程测算数据不要。

## 让它反驳自己

你给出的初筛档位，自己挑出最站不住的一两个：对着四份公告的资格条款摘录原文，说明依据的是哪一条、如果那条解读有偏差会导致什么结论变化。产出用 Excel 一张表：项目简称、原档位、支撑依据（公告条号原文）、你的疑问、建议复核动作。

## 比对去年园区项目

专门比上季度投标投入与结果台账里那个区属园区 680 万元的项目：付款条件结构、实际决算拖期、那笔还挂在应收上的 34 万元。产出用 Excel 一张表：对比项、园区项目、本次四个项目各一列，垫资周期与最终挂账情况分开列。

## 对照投标立项制度自查

对照我们的投标立项制度，把这份初筛意见自查一遍：立项前必填的保证金来源、垫资上限、资源占用确认几项齐不齐，有没有越权写了推荐意见。产出用 Excel 一张清单：制度要求项、是否齐备、缺什么、找谁要，缺的标在最前面。

## 折算成直接支出与占用

把「四个标都投」和「只投初筛通过的两个」算成钱：标书制作与差旅逐项、保证金金额与平均占用月数，两边各是多少。产出用 Excel 一张表：口径、全投合计、只投两个合计、差额，算式与单价都写出来。

## 沉淀成初筛作业清单

把这次的初筛口径整理成下次能直接用的清单：硬门槛要核哪几项、垫资按哪些节点算、成本要列哪几项、四档判据分别是什么。产出用 Markdown 一份《投标可行性初筛作业清单》，每项注明依据从哪份材料取。
