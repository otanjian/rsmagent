# 输出骨架与渲染脚本

## 文件清单

- `SO-03_合同到期与续签盘点表.xlsx` —— 正式件本体 · 5 sheet · 含签批栏
- `SO-03_最晚动作日清单.xlsx` —— 可派发 · 按紧急度排序 · 含自动续期标记
- `SO-03_条款要点与谈判依据表.xlsx` —— 逐份合同的续期与涨价条款 + 客户表现

## sheet 结构

1. `结论摘要` —— 本次结论 / 关键指标 / 输入依据 / 人工边界 / 签批栏
2. `1.台账与正本核对` —— 列头：合同编号 | 客户名称 | 履行期限（正本原文） | 台账登记到期日 | 按正本口径的到期日 | 差异(天) | 核对结论
3. `2.通知期倒推` —— 列头：合同编号 | 客户名称 | 年度金额(万元) | 到期日（正本口径） | 提前通知期 | 最晚动作日 | 距基准日(天) | 自动续期 | 紧急度
4. `3.条款要点提取` —— 列头：合同编号 | 客户名称 | 年度金额(万元) | 提前通知期 | 自动续期条款（条款号） | 续期价格 | 涨价触发条件
5. `4.谈判依据归集` —— 列头：合同编号 | 客户名称 | 年度金额(万元) | 交付及时率 | 质量异议 | 未闭环工单 | 回款率 | 逾期金额(元) | 谈判位置
6. `5.成本对照` —— 列头：成本项 | 在维保及备件成本中权重 | 上年度单位成本 | 本年度单位成本 | 涨幅 | 加权贡献
7. `6.留证与签批` —— 列头：优先级 | 合同编号 / 客户 | 年度金额(万元) | 最晚动作日 | 本次须确认的那一件事 | 条款出处 | 责任人 | 推荐意见

## 视觉规范

正式件本体用**风格 A**（浅灰表头 `F6F8FB` + 深字 `1A2332`）；
清单类用**风格 B**（蓝底白字 `2D6CDF`）。同一个包里不要混用。

```python
INK, MUTED, GREY = "1A2332", "5A6675", "8A94A3"
HEAD_A, HEAD_B   = "F6F8FB", "2D6CDF"
RED, AMBER, GREEN = "C62F2F", "B9770A", "1E8E5A"
FONT = "微软雅黑"
```

必做三件事：

```python
ws.freeze_panes = "A4"                          # 冻结表头
ws.auto_filter.ref = f"A3:{last_col}{last_row}"   # 开筛选
ws.sheet_view.showGridLines = False              # 关网格线，更像正式件
```

## 签批栏（正式件必备）

编制 / 审核 / 会签 / 批准四栏 + 日期列。
**推荐意见、完成质量、责任认定三栏留空。**

## 渲染脚本自检

```python
# 分项加总必须等于合计
assert abs(sum(items) - total) < 0.01, f"分项 {sum(items)} != 合计 {total}"
# 占比合计必须等于 100%
assert abs(sum(pcts) - 100) < 0.1
# 行数守恒
assert len(out_rows) == len(in_rows), "行数不守恒"
```

跑不过就不出文件 —— 从根上杜绝「合计对不上」这种一眼被看穿的错。
