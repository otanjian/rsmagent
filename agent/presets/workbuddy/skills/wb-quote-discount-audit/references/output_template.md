# 输出骨架与渲染脚本

## 文件清单

- `QC-01_折扣核查与签批单.xlsx` —— 正式件本体 · 5 sheet · 含五级签批栏
- `QC-01_历史报价折算对照表.xlsx` —— 可派发 · 逐单带原件出处与折算依据
- `QC-01_授权层级判定表.xlsx` —— 分档规则与本次判定结果

## sheet 结构

1. `结论摘要` —— 本次结论 / 关键指标 / 输入依据 / 人工边界 / 签批栏
2. `1.口径归一` —— 列头：报价日期 | 原件出处与格式 | 价格口径 | 当期标准价(元) | 成交价(元) | 折算后折扣率
3. `2.授权判定` —— 列头：项 | 口径与算式 | 金额(元) | 占标准价 | 对应条文 | 判定
4. `3.同客户纵向比` —— 列头：报价日期 | 对应订单号 | 当期标准价(元) | 成交价(元) | 折扣率 | 理由栏原文 | 当时签批人
5. `4.同产品横向比` —— 列头：客户 | 成交日期 | 对应合同号 | 标准价(元) | 成交价(元) | 折扣率 | 签批层级 | 回款表现
6. `5.交叉核对` —— 列头：发票号 | 对应订单号 | 开票日 | 约定到期日 | 逾期天数 | 应收余额(元) | 状态
7. `6.留证与签批` —— 列头：优先级 | 核查发现 | 条文出处 | 后果 | 处理动作 | 责任人 | 今日可否完成

## 视觉规范

正式件本体用**风格 A**（浅灰表头 `F6F8FB` + 深字 `1A2332`）；
清单类用**风格 B**（蓝底白字 `2D6CDF`）。同一个包里不要混用。

```python
INK, MUTED, GREY = "1A2332", "5A6675", "8A94A3"
HEAD_A, HEAD_B   = "F6F8FB", "2D6CDF"
RED, AMBER, GREEN = "C62F2F", "B9770A", "1E8E5A"
FONT = "微软雅黑"
```

必做三件事：

```python
ws.freeze_panes = "A4"                          # 冻结表头
ws.auto_filter.ref = f"A3:{last_col}{last_row}"   # 开筛选
ws.sheet_view.showGridLines = False              # 关网格线，更像正式件
```

## 渲染脚本自检

```python
# 分项加总必须等于合计
assert abs(sum(items) - total) < 0.01, f"分项 {sum(items)} != 合计 {total}"
# 占比合计必须等于 100%
assert abs(sum(pcts) - 100) < 0.1
# 行数守恒
assert len(out_rows) == len(in_rows), "行数不守恒"
```

跑不过就不出文件 —— 从根上杜绝「合计对不上」这种一眼被看穿的错。
