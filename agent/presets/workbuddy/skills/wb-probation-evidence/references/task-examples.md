# 可选任务

## 首推默认

业务经理要辞退一个还在试用期的员工，理由是反应慢态度差。你先帮我看看我们手里的东西够不够。

入职材料、他这几个月的周报、经理的评价我都发你了。
缺什么、哪条证据是补不了的、程序上有没有倒置的风险，都直说。

两条路的成本算给我，决定我们自己拍。

## 只跑断链诊断

先只做断链诊断：量化录用条件、书面告知签字、客观考核记录三个法定条件逐项给我「有／无／补不了」的结论，其他先别动。

## 换「再等两周」口径

换成「再等两周看能不能补齐证据」这个前提跑一遍：按剩下的试用期天数倒算，还来得及形成几份什么记录、证明力够不够。

## 一次处理三个试用期

演示数据里再加两个同期试用期员工的材料，三个人一起跑，最后给我一张横向对照表：三个法定条件各自的有无、程序风险、建议动作。

## 给业务经理看的一页

把诊断压成给业务经理看的一页：他主张的「反应慢、态度不行」能落地几条、公司手上有什么、他接下来要做什么，底稿不用给。

## 让它反驳自己

你把「工作量不达标」这条理由排除了，依据是什么？把他这几个月的周报产出数字列出来，如果结论反了就改回来，别让我拿着去谈。

## 比对上次栽的坑

把这次的材料跟去年另一个部门辞退试用期员工那次对一遍：那次程序倒置栽在哪、这次的日期链有没有同款毛病。

## 对照三条件自检

对照量化录用条件、书面告知签字、客观考核记录这三个法定条件，把入职材料、周报、经理评价再自查一遍：哪些补得了、哪些补不了只能承认没有，写明补的动作和死线。

## 折算成两路金额

按法定口径算一遍：违法解除 2N 是 7,200 元、协商解除 N+1 是 10,800 元，两个数各对应什么动作、差在哪个环节。

## 沉淀成日期链清单

把这次的日期链检查动作沉淀成一张清单：每份材料要核哪几个日期、谁签、什么时点前完成，下一个人入职就按这个走。
