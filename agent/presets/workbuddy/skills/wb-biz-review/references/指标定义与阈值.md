# 五条线指标定义与判定阈值

> 经营复盘·一页式简报 Skill · reference 文档 1/2
> 所有阈值为离散制造（工控机柜/精密结构件类）行业默认值，客户可覆盖。

---

## 0. 判定三态与四色的对应关系

| 判定 | 颜色 | 触发条件 | 处理 |
|---|---|---|---|
| 改善 | 🟢 健康 | 环比改善 且 达标 | 记录，不进问题清单 |
| 改善但存疑 | 🟡 | 环比改善 且 达标，但支撑指标反向或超上限 | **必须进矛盾检测** |
| 持平 | 🟡 | 环比与目标只满足一项 | 列为观察项 |
| 恶化 | 🔴 | 环比恶化 且 未达标 | **必须进归因下钻** |

**预警线 vs 红线**：
- 超**预警线** → 该指标进观察项，要求条线负责人给动作（对应管理层 L1/L2 升级）
- 超**红线** → 该指标必须进「三个必须关注的问题」（对应 L3 橙色升级）

## 1. 订单线

| 指标 | 计算口径 | 健康区间 | 预警线 | 红线 |
|---|---|---|---|---|
| 订单金额 | Σ(订单数量 × 单价)，不含税 | — | — | — |
| 订单金额环比 | (本月 - 上月) / 上月 | ≥ 0% | < -5% | < -15% |
| 目标达成率 | 订单金额 / 月度目标 | ≥ 100% | < 90% | < 80% |
| 单一客户集中度 | 最大客户订单金额 / 订单金额合计 | ≤ 35% | > 45% | > 60% |
| 订单张数环比 | (本月张数 - 上月张数) / 上月张数 | ≥ -10% | < -20% | < -35% |
| 平均订单金额 | 订单金额 / 订单张数 | 环比 ±15% 内 | 环比 -25% | 环比 -40% |

**本案例实测（2026-06）**
- 订单金额 = 1,260.0 + 720.0 + 460.0 = **2,440.0 万元**
- 环比 = (2,440.0 - 2,280.0) / 2,280.0 = **+7.0%** → 健康
- 达成率 = 2,440.0 / 2,400.0 = **101.7%** → 健康
- 集中度 = 850.0 / 2,440.0 = **34.8%** → 临界（逼近 35% 健康上限）
- 平均订单金额 = 2,440.0 / 57 = **42.8 万元/张**

**解读要点**：订单线是唯一一条纯健康的线。但集中度 34.8% 已贴近上限，且该客户正是 Q1 要去谈调价的对象——**调价谈判有客户流失风险，必须在简报里点明这个约束**。

## 2. 交付线

| 指标 | 计算口径 | 健康区间 | 预警线 | 红线 |
|---|---|---|---|---|
| 准时交付率 OTD | 准时交付订单数 / 应交订单数 | ≥ 95% | < 90% | < 85% |
| 应交订单数 | 本期新到期订单 + 上期结转未交订单 | — | — | — |
| 逾期交付订单数 | 应交订单数 - 准时交付订单数 | ≤ 3 张/月 | > 5 张/月 | > 10 张/月 |
| 平均交付周期 | Σ(实际交付日 - 下单日) / 订单数 | ≤ 20.0 天 | > 25 天 | > 30 天 |
| **加急插单次数** | 打断在制工单的紧急插单计数 | ≤ 12 次/月 | > 20 次/月 | > 30 次/月 |
| **加班工时占比** | 加班工时 / 标准工时 | ≤ 12% | > 15% | > 20% |
| 加班成本 | 加班工时 × 加班工资率（本案例 45 元/小时） | — | — | — |

**加粗两项是「OTD 支撑指标」**：OTD 达标时必须一并看这两项，否则会把「靠加班堆出来的达标」误判为真健康。

**本案例实测（2026-06）**
- 应交订单数 = 本月新到期 48 + 上月结转 14 = **62 张**
- OTD = 60 / 62 = **96.8%** → 达标（目标 ≥95.0%），上期 54 / 58 = 93.1%
- 逾期 = 62 - 60 = **2 张**（SO-2606-018 逾期 7 天、SO-2606-031 逾期 5 天）→ 健康
- 加急插单 = **23 次**（上期 12）→ **超预警线 20 次**
- 加班工时占比 = 3,180 / 21,200 = **15.0%**（上期 2,270 / 20,600 = 11.0%）→ **超预警线**
- 加班工时环比 = 3,180 / 2,270 - 1 = **+40.1%**
- 加班成本 = 3,180 × 45 / 10,000 = **14.31 万元**（上期 2,270 × 45 / 10,000 = 10.22 万元，+4.09 万元）

**判定**：OTD 本身 🟢，但两项支撑指标超预警线 → 整条线判「🟡 改善但存疑」→ 进矛盾检测 C1。

## 3. 库存线

| 指标 | 计算口径 | 健康区间 | 预警线 | 红线 |
|---|---|---|---|---|
| 库存总额 | 原材料 + 在制品 + 成品 + 备品备件 | — | — | — |
| 库存周转次数（月） | 本月销货成本 / 平均库存 | ≥ 1.00 次/月 | < 0.80 | < 0.60 |
| 平均库存 | (期初库存 + 期末库存) / 2 | — | — | — |
| 年化周转次数 | 月周转次数 × 12 | ≥ 12.0 次/年 | < 9.6 | < 7.2 |
| **呆滞库存占比** | 库龄 > 180 天金额 / 库存总额 | ≤ 13% | > 18% | > 25% |
| 呆滞库存金额 | 库龄 > 180 天物料账面金额 | ≤ 250.0 万元 | > 350.0 | > 500.0 |
| **缺料预警条目** | 齐套检查中影响开工的缺料项计数 | ≤ 8 项 | > 15 项 | > 25 项 |
| 在制品占比 | 在制品金额 / 库存总额 | ≤ 20% | > 28% | > 35% |

**加粗两项是「库存下降的反向指标」**：库存总额下降不等于健康，要看降的是好料还是呆料。

**本案例实测（2026-06）**
- 库存总额 = 742.0 + 396.0 + 528.0 + 194.0 = **1,860.0 万元**（上期 1,940.0，环比 -4.1%）
- 平均库存 = (1,940.0 + 1,860.0) / 2 = **1,900.0 万元**
- 月周转 = 1,958.4 / 1,900.0 = **1.03 次/月** → 达标（上期 1,783.0 / 1,960.0 = 0.91）
- 年化周转 = 1.03 × 12 = **12.4 次/年** → 达标
- 呆滞金额 = 96.5 + 74.8 + 68.0 + 12.4 + 60.3 = **312.0 万元**（上期 286.0，+26.0）
- 呆滞占比 = 312.0 / 1,860.0 = **16.8%**（上期 286.0 / 1,940.0 = 14.7%，+2.1pp）→ **超健康上限 13%**
- 缺料预警 = **14 项**（上期 8）→ **贴近预警线 15 项**
- 在制品占比 = 396.0 / 1,860.0 = **21.3%** → 略超健康上限

**呆滞 Top 4 结构**（合计 251.7 万元，占呆滞 80.7%）：

| 物料 | 金额 | 验算 | 形成原因 |
|---|---|---|---|
| M-CAB-001 v2 旧版 | 96.5 万元 | 1,930 套 × 500 元 | P-CAB-02 切换 v3 版后无需求 |
| M-SPCC-20 超储 | 74.8 万元 | 138.9 吨 × 5,385 元/吨 | 3 月大批量备货，实际耗用低于计划 |
| M-PCB-002 | 68.0 万元 | 850 片 × 800 元 | P-IPC-01 v1.3 取消替代关系后无消耗 |
| M-USBB-01 | 12.4 万元 | 12,400 只 × 10 元 | 已被 M-USBC-01 完全替代 |

**判定**：主指标（总额、周转）🟢，结构指标（呆滞占比、缺料条目）超线 → 整条线判「🟡 持平」→ 进矛盾检测 C2。

**结构性发现**：Top 4 中有 3 项（M-CAB-001 v2 / M-PCB-002 / M-USBB-01，合计 176.9 万元）都由**版本或替代关系切换**形成——属可预见的结构性占压，不是市场波动。这是机制问题，必须在动作里体现（变更前先跑库存影响评估）。

## 4. 质量线

| 指标 | 计算口径 | 健康区间 | 预警线 | 红线 |
|---|---|---|---|---|
| 内部不良率 | 不良件数 / 检验总件数 × 1,000,000 | ≤ 3,000 PPM | > 5,000 PPM | > 8,000 PPM |
| 客诉件数 | 客户正式书面投诉计数 | ≤ 4 件/月 | > 8 件/月 | > 12 件/月 |
| 质量损失金额 | 返工工时 + 报废材料 + 客户索赔 + 检验加严成本 | ≤ 25.0 万元 | > 40.0 万元 | > 60.0 万元 |
| 质量损失率 | 质量损失金额 / 确认收入 | ≤ 1.0% | > 2.0% | > 3.0% |
| NCR 开立数 | 不合格品报告开立份数 | — | — | — |
| NCR 按期关闭率 | 按期关闭份数 / 开立份数 | ≥ 85% | < 70% | < 50% |

**质量损失的会计归集**（决定它是否影响毛利，归因下钻时必须区分）：

| 损失项目 | 归集科目 | 是否影响毛利 |
|---|---|---|
| 返工工时 | 制造成本 | ✅ 影响 |
| 报废材料 | 制造成本 | ✅ 影响 |
| 客户索赔 / 退货 | 销售费用 | ❌ 不影响 |
| 检验加严成本 | 期间费用 | ❌ 不影响 |

**本案例实测（2026-06）**
- 内部不良率 = **3,850 PPM**（上期 3,120，+23.4%）→ 超健康上限
- 客诉 = **7 件**（上期 5）→ 超健康上限
- 质量损失 = 13.8 + 14.2 + 7.4 + 3.2 = **38.6 万元**（上期 26.4，+46.2%）→ 超健康上限，逼近预警线
- 质量损失率 = 38.6 / 2,320.0 = **1.66%** → 超健康上限
- NCR 开立 = **19 份**，按期关闭 14 份 → 关闭率 = 14 / 19 = **73.7%**（上期 84.6%，-10.9pp）→ 超预警线
- **影响毛利的部分** = 返工 13.8 + 报废 14.2 = **28.0 万元**，其中 P-BRK-03 占 5.6 + 6.8 = **12.4 万元**

**按产品线拆分（万元）**

| 损失项目 | P-BRK-03 | P-IPC-01 | P-CAB-02 | 小计 |
|---|---|---|---|---|
| 返工工时 | 5.6 | 5.4 | 2.8 | 13.8 |
| 报废材料 | 6.8 | 5.1 | 2.3 | 14.2 |
| 客户索赔/退货 | 7.4 | 0.0 | 0.0 | 7.4 |
| 检验加严 | 1.5 | 1.0 | 0.7 | 3.2 |
| **合计** | **21.3** | **11.5** | **5.8** | **38.6** |
| 占比 | 55.2% | 29.8% | 15.0% | 100.0% |

验算：行合计 13.8 + 14.2 + 7.4 + 3.2 = 38.6；列合计 21.3 + 11.5 + 5.8 = 38.6 ✅

**判定**：五项指标全部环比恶化，不良率与质量损失双超健康上限 → 🔴 **恶化**。

## 5. 成本线

| 指标 | 计算口径 | 健康区间 | 预警线 | 红线 |
|---|---|---|---|---|
| 整体毛利率 | (确认收入 - 销货成本) / 确认收入 | ≥ 18.0% | < 15.0% | < 12.0% |
| 单产品线毛利率 | 该线(收入 - 成本) / 该线收入 | ≥ 15.0% | < 12.0% | < 10.0% |
| 毛利率环比变动 | 本月毛利率 - 上月毛利率 | ≥ -0.5pp | < -1.5pp | < -2.0pp |
| 材料成本占比 | 直接材料 / 销货成本 | ≤ 62% | > 68% | > 75% |
| 关键物料涨幅 | (本月单价 - 上月单价) / 上月单价 | ≤ 3% | > 8% | > 15% |
| 报价滞后天数 | 今天 - 对客报价最后生效日 | ≤ 90 天 | > 180 天 | > 270 天 |

**「关键物料涨幅」+「报价滞后天数」是毛利率恶化的先行指标**：两项同时超线，几乎必然导致毛利率下跌，可在毛利率恶化前一个月预警。

**本案例实测（2026-06）**

| 产品 | 收入 | 成本 | 毛利 | 毛利率 | 上期毛利率 | 变动 | 判定 |
|---|---|---|---|---|---|---|---|
| P-IPC-01 | 1,180.0 | 971.0 | 209.0 | 17.7% | 19.1% | -1.4pp | 恶化 |
| P-CAB-02 | 680.0 | 566.0 | 114.0 | 16.8% | 17.2% | -0.4pp | 小幅恶化 |
| P-BRK-03 | 460.0 | 421.4 | 38.6 | **8.4%** | 17.5% | **-9.1pp** | **红线** |
| **合计** | **2,320.0** | **1,958.4** | **361.6** | **15.6%** | **18.2%** | **-2.6pp** | **红线** |

验算：
- 2,320.0 - 1,958.4 = 361.6；361.6 / 2,320.0 = 15.586% ≈ **15.6%** ✅
- P-BRK-03：460.0 - 421.4 = 38.6；38.6 / 460.0 = 8.39% ≈ **8.4%** ✅
- 上期：2,180.0 - 1,783.0 = 397.0；397.0 / 2,180.0 = 18.211% ≈ **18.2%** ✅

**先行指标实测**：
- M-SPCC-20 涨幅 = (5,385 - 4,850) / 4,850 = **+11.0%** → 超预警线 8%
- 报价滞后= 2026-06-30 - 2026-01-01 = **181 天** → 刚过预警线 180 天

**判定**：整体毛利率 15.6% 跌破目标 2.4pp、环比 -2.6pp 触红线；P-BRK-03 单线 8.4% 触红线 → 🔴 **恶化**，且是两个红线项，优先级最高 → Q1。

## 7. 阈值覆盖方式

客户有自己的经营目标时，在数据表里放一列「月度目标」，Skill 优先用客户值，本文档阈值仅作为缺省兜底。

覆盖优先级：**数据表中的月度目标列 > 客户预算表> 本文档默认阈值**。

使用默认阈值时，Skill 必须在简报里注明「该指标使用行业默认阈值，建议客户确认」。
