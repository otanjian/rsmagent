# 归因下钻规则

> 经营复盘里最关键的一步。**指标恶化只是现象，归因下钻要一路追到"谁在什么时间做什么"。**
> 停在"毛利率下滑"这种结论上，等于没做复盘。

---

## 1. 四层下钻模型

| 层级 | 追问 | 产出 | 停在这层的后果 |
|---|---|---|---|
| **L1 指标** | 哪个指标恶化了、恶化多少 | 指标缺口金额 | 客户："这我看报表也知道" |
| **L2 结构** | 主要由哪个产品线 / 客户 / 部门造成 | 各单元缺口 + 占比 | 客户："那又能怎么办" |
| **L3 成本项 / 动因** | 这个单元的缺口由哪几项构成 | 成本项拆解 + 各项金额 | 开始有价值，但还不能签字 |
| **L4 订单 / 动作** | 落到哪几张单、哪个客户、该谁在什么时间做什么 | 具体订单 + 敞口金额 + 责任人 + 时限 | **这才是能签字的结论** |

**判定标准**：一份复盘结论如果读完之后不知道"明天该找谁"，就是没下钻到位。

---

## 2. 结构剔除法（L1→ L2 的标准算法）

用来回答"整体指标恶化，主要是谁拖累的"。

```
第一步：按上期各单元的比率，重算本期"应得值"
        应得值ᵢ = 本期规模ᵢ × 上期比率ᵢ
第二步：应得值合计 − 本期实际合计 = 总缺口
第三步：单元缺口ᵢ = 应得值ᵢ − 本期实际ᵢ
第四步：占比ᵢ = 单元缺口ᵢ / 总缺口
```

**为什么不能直接比毛利率变动**：因为各产品线规模不同。一条毛利率掉 9pp 但只占 2 成收入的线，和一条掉 1.4pp 但占 5 成收入的线，谁影响大要算过才知道。**直接看百分比变动会误判责任。**

**验算要求**：各单元缺口加总必须等于总缺口，占比加总必须等于 100%。加不上说明漏了单元或口径不一致。

---

## 3. L3 成本项拆解规则

拿到"某条线缺口 X 万元"后，必须能拆成可归因的成本项。**每一项都要能对应到一个"谁的动作"**，否则拆了也没用。

| 成本项类型 | 归因方向 | 责任部门 | 典型动作 |
|---|---|---|---|
| **原材料涨价** | 价格未传导 | 销售（调价）+ 采购（锁价/寻源） | 涨幅 × 用量 = 敞口，算出建议调价额 |
| **质量返工与报废** | 过程失控 | 品质 + 生产 | 关联到具体 NCR 编号，看根因是否同源 |
| **外协赶工加工费** | 产能失衡 | PMC | 关联到具体逾期订单，看是否插单导致 |
| **直接人工上升** | 加班堆产能 | PMC + 生产 | 与加班工时数据交叉验证 |
| **制造费用上升** | 摊销基数变化 | 财务 | 先确认是量的问题还是率的问题 |

**注意区分"影响毛利"和"不影响毛利"的损失**：
- 影响毛利：返工工时、报废材料（计入制造成本）
- 不影响毛利：客户索赔/退货（销售费用）、检验加严成本（期间费用）

拆解毛利缺口时**只能算影响毛利的部分**，否则数字对不上。这是最容易出错的地方。

---

## 4. L4 落到订单的规则

必须给出三样东西，缺一样都不算完成：

1. **具体单号 + 客户**：不能写"部分订单"，要写 SO-2604-009 / SO-2605-022 / SO-2606-018
2. **敞口金额**：数量 × 单位差额，且要能加总验算
3. **动作 + 责任人 + 时限**：建议调价到多少、谁去谈、什么时候之前谈完

**敞口计算通式**：
```
未调价敞口 = 在执行数量 × (应涨单价 − 现行单价)
应涨单价 = 现行单价 + 单位成本上涨额
单位成本上涨额 = 材料涨幅 × 单件用量
```

---

## 5. 指标间矛盾检测规则

归因不只是"往下追"，还要"横着看"。**主指标达标但支撑指标反向，是最容易被漏掉的经营风险。**

| 好看的指标 | 必须一起看的反向指标 | 若同期反向说明什么 |
|---|---|---|
| OTD 上升 | 加急插单次数、加班工时占比、外协加工费 | 交付是靠加班堆的，不可持续 |
| 库存总额下降 | 呆滞金额/占比、缺料预警条目 | 消耗掉的是好料，留下的是呆料 |
| 产量上升 | 不良率、返工工时、NCR 开立数 | 产量是靠牺牲质量换的 |
| 订单金额上升 | 单一客户集中度、账期、毛利率 | 增长质量差，可能是低价换量 |
| 成本下降 | 质量损失、客诉件数 | 省的是该花的钱 |
| 交付周期缩短 | 首件确认省略次数、换型检查执行率 | 快是靠跳过检查换的 |

**检测规则**：任一主指标达标或改善时，**强制检查对应的支撑指标**。若支撑指标同期恶化或突破预警线，判定为「改善但存疑」，不能判为「改善」。

**这条规则的价值**：管理层最怕的不是看到坏数字，是看到好数字却不知道代价。一份只报喜的复盘会让人做出错误决策。

---

## 6. 常见坑

1. **只对比上期，不对比目标** — 上月93.1%、本月 96.8% 看着在改善，但如果目标是 98%，仍然是未达标。**必须双向对比。**
2. **拿总数除总数算率** — 整体毛利率 15.6% 是加权结果，不等于三条线毛利率的算术平均。汇总口径要用金额加权。
3. **把不影响毛利的损失算进毛利缺口** — 客户索赔计销售费用，算进毛利缺口会导致数字对不上。
4. **归因停在"管理不到位"** — 这不是根因，是评价。根因必须是"某个流程缺了某个步骤"这种可修改的东西。
5. **三个问题给了五个部门** — 责任要唯一主责+ 明确协同，写成"销售、采购、PMC、品质共同负责"等于没人负责。
6. **动作没有衡量口径** — "加强插单管理"无法验收，"加急插单压回≤12 次/月"才能验收。
7. **忽略排除性结论** — 交叉比对里"未命中"的维度同样有价值，能省掉一整轮无用追溯（如三个不同来料批次都出问题 → 排除来料因素）。
