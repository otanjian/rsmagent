# 受控文件版本一致性巡检 · SKILL

## 1. Skill 用途

对比"系统侧受控版本清单"与"现场发放台账"，一次性输出：
- 差异清单（哪些工位/岗位的现场版本≠ 系统受控版本）
- 责任归口（每条差异对应的整改责任岗位）
- 整改建议（换版 / 回收旧版 / 更新台账）
- 综合结论（是否可通过 ISO 审核 / 客户抽检）

**适用岗位**：研发 PE / 工艺 / 品质 / 生产主管
**适用场景**：日常巡检、ISO/IATF 审核前自查、客户抽检前自查、版本发布后 T+3 天验证

## 2. 触发方式

用户说"帮我做一次版本巡检" / "对一下现场版本跟系统一致不一致" / "ISO 审核前自查一下版本" / "版本发布后验证现场是否换到位" 时触发本 Skill。

## 3. 输入格式

两份文件，一致：
1. **系统侧 · 受控版本清单**（PLM/ERP 导出）· 关键字段：文件编号 / 当前受控版本 / 类型 / 责任岗位
2. **现场侧 · 发放台账**（MES/人工维护）· 关键字段：文件编号 / 工位/岗位 / 现场版本 / 备注

**支持格式**：xlsx / csv / md表格

## 4. 核心处理逻辑

按文件编号 join 两份数据 → 对比"当前受控版本 vs 现场版本"，输出：

- **🟢 一致**：现场版本 == 系统受控版本
- **🔴 不一致**：现场版本 != 系统受控版本（暗雷 ·ISO 审核会抓）
- **⚪ 缺失**：系统侧有但现场没有（可能是新发布还没换到工位）
- 每条差异关联备注字段中的现场说明（如"张工留言：SOP-A-06 打印稿还没发下去"）

## 5. 输出格式

见 `references/output_template.md`

## 6. Skill 组合

- 巡检发现差异 → 调用 `企微等IM分部门通知` Skill → 按责任岗位分发整改通知
- 巡检发现新版未同步 → 调用 `ecn-change-management` Skill → 查ECN 审批是否已闭环
