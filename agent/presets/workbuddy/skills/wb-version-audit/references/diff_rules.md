# 差异判定规则

## 版本比对逻辑

按 `文件编号` 做 join，比对 `当前受控版本 (系统侧)` 与 `现场版本 (现场侧)`：

| 判定 | 触发条件 | 严重度 |
|---|---|---|
| 🟢 一致 | 现场版本 == 系统受控版本 | 无风险 |
| 🔴 不一致 | 现场版本 < 系统受控版本（老版仍在用）| 高 · ISO 审核会开不符合项 |
| 🟡 反向不一致 | 现场版本 > 系统受控版本（现场自行改） | 中 · 需追溯审批 |
| ⚪ 缺失 | 系统有该文件、现场台账无 | 中 · 可能未发放 |

## 版本号规范

- SOP / WI 类：VX.Y（如 V1.3）· 主版本升级需重新培训
- 图纸类：D-XXX（如 D-025）· 数字递增
- 规格书：vX（如 v3）

## 严重度加权

- 涉及关键工位（装配一线/ 检验工位） · 严重度 +1 级
- 有客户抽检风险 · 严重度 +1 级
- 备注里有"未换 / 未打印/ 未发放" · 严重度 +1 级
