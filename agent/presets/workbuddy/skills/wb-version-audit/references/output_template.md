# 输出模板

## 巡检报告 · 完整结构

```
📋 版本一致性巡检报告
   巡检时间：{now}
   巡检范围：{product}
   系统侧快照时间：{sys_snapshot_time}
   现场侧快照时间：{site_snapshot_time}
   综合判定：🟢 全部一致 /🟡 局部不一致 / 🔴 严重不一致（不建议接受审核）

📊 差异清单
| 序号 | 文件编号 | 文件名称 | 工位 | 系统版本 | 现场版本 | 判定 | 责任岗位 |
|---|---|---|---|---|---|---|---|
| 1 | SOP-A-06 | ... | 装配一线 | V1.3 | V1.2 | 🔴 不一致 | 工艺 |
| ... |

💬 现场备注解读
- {备注1}
- {备注2}

🔧 整改建议
1. {文件编号}· {动作}· {责任岗位}· {完成时限}
```

## 综合判定规则

- 🟢 全部一致 · 差异 0
- 🟡 局部不一致 · 有 1-2 项差异、且都是低/中严重度
- 🔴 严重不一致 · 有高严重度差异（涉及关键工位）
