# 生产执行偏差追踪与补产判断 Skill

> PMC 岗位场景 5.5 专用 · 唯一按天循环的场景 · 从五份数据 → 数据时点校验 → 三类偏差识别 → 四类根因候选（标明可得性）→ 补产建议 + 可打印早会日报

---

## 1. 用途

PMC 每天早上第一件事就是看昨天的工单。难的不是看数字，是**数字本身不可信，而且解释权不在自己手上**。这个 Skill 一次做完五件事：

1. **数据时点校验**（必须最先做）：报工是事后批量补录的，超 24h 未报工的工单，其"滞后天数"直接标为不可信
2. **三类偏差识别**：欠数、滞后、**返工未补回**（第三类专治"进度 98% 却明天交货"的陷阱）
3. **四类根因候选**：缺料 / 品质 / 设备 / 人手，**逐类标明数据可得性** —— 可定量的给算式与结论，数据不足的只给候选项 + 证据 + 待确认人
4. **补产建议**：是否需补产、建议动作、责任人、时点，**含明确标注"不需补产"的行**
5. **早会日报**：一页可打印签字，只放今日必须处置的工单

**这个 Skill 解决的真实痛点**：工人赶工时不报工，等一批干完对着工单一次性补录，于是系统里的"滞后 4 天"可能有 3 天是没录；而进度 98% 的工单最危险——欠的那点是返工件，返工完成后有没有补回产量，系统里根本没有这个字段。更麻烦的是四类根因的证据分散在四个部门：缺料在 ERP、设备停机在设备科维修单、返工数量在品保部纸质台账、人员缺勤在人事出勤表，而后两份还是残缺的。

## 2. 触发方式

### 2.1 用户一句话触发（推荐）

```
在制工单我导出来了，另外我把设备科的维修单、品保的返工单、人事的出勤表也一起放进来了。
帮我看下今天早会要讲哪几张单 —— 欠数的、滞后的、返工没补回来的。
每张给个根因方向，缺料/品质/设备/人手这四类。
哪一类的数据不全就直接说不全，别硬凑一个原因给我，我拿着错的结论去问车间会很尴尬。
要补产的标出来，别改工单，我自己排。
```

### 2.2 输入材料清单

| # | 材料 | 必需 | 数据质量现实 | 缺失时的降级策略 |
|---|---|---|---|---|
| 1 | 工单进度日报（**必须含报工数据时点**） | **必需** | 事后批量补录 | 无此项无法运行。**若无"报工时点"列，所有滞后天数一律标注"时点未知，可信度无法评估"** |
| 2 | 齐套与缺料状态 | 建议 | ERP 可得，较准 | 缺失时"缺料"类根因标为无法判定 |
| 3 | 设备维修工单 | 建议 | **在设备科，PMC 平时不看** | 缺失时"设备"类根因标为无法判定，并提示向设备科索取 |
| 4 | 品质返工与报废单 | 建议 | **纸质台账，数量常写"少量""几件"，且不追踪是否补回** | 缺失或数量不可用时"品质"类只给候选项 |
| 5 | 出勤与人员安排 | 可选 | **只有缺勤人数，无工位安排维度** | 该类根因基本只能给候选项 |

**关键认知：材料 4、5 即使拿到了也往往用不了。** 这不是数据没准备好，是这两类数据在中小企业本来就不以可计算的形式存在。Skill 必须接受这个现实，而不是要求企业先做数据治理。

## 3. 五步法工作流程

### STEP 1 · 数据时点校验（在所有分析之前）

对每张工单计算：`距今小时数 = 当前时间 − 最后报工时间`

| 距今 | 可信度判定 | 处理方式 |
|---|---|---|
| ≤ 24h | 可信 | 正常参与分析 |
| 24~48h | **可疑** | 滞后天数标注"可能含录入延迟" |
| > 48h | **不可信** | **滞后天数直接标为不可信**，今日第一动作改为"补齐报工" |
| 未开工 | 不适用 | 但要检查是否被其他工单占用工位 |

**硬规则：数据不可信的工单，不得输出根因结论，只能输出"先补齐报工"这一个动作。**

理由：在数据补齐之前任何归因都是在替车间编故事。而一次错误的问责，会让车间下次更不愿意报工——这是个会自我强化的恶性循环。

### STEP 2 · 三类偏差识别

**① 欠数**：`欠数 = 计划数 − 累计完工数`（当前工序非"已完工/未开工"时才算偏差）

**② 滞后**：`滞后天数 = 预计完工日 − 计划完工日`。须结合 STEP 1 的可信度标记。

**③ 返工未补回**（最容易被漏掉的一类）

判定方法：
1. 取欠数较小、完成率≥ 95% 的工单（进度条看起来接近满格的）
2. 到返工单里按工单号匹配
3. 若匹配到返工记录，且**返工数量 ≈ 欠数**，则该欠数实为返工件
4. 检查返工单的"是否已补回"字段——**若为"未记录"，则这批件的状态是未知的**
5. 再看交货日：若剩余时间 ≤ 2 天 → **判为最高优先级**

**为什么必须独立成一类**：它是唯一一类会**伪装成"接近完工"**的偏差。按完成率排序时它排在最前面（看起来最好），按滞后天数排序时它排在很后面（滞后不多），两种排序都会让它被跳过。

### STEP 3 · 四类根因 ·逐类标明数据可得性

| 根因 | 取数来源 | 可得性 | 输出形态 |
|---|---|---|---|
| **① 缺料** | ERP 齐套报表 | **可定量** | 缺口数量 + 在途到货日 vs 工序需料日 → 明确结论（含明确排除） |
| **② 设备** | 设备科维修工单 | **可定量** | 停机时长 → 折算工作日影响。**但要说明"这解释不了全部滞后"** |
| **③ 品质** | 品保部返工/报废单 | **常不可定量** | 数量栏为文字描述（"少量""几件"）时，只给候选项 + 原始描述 |
| **④ 人手** | 人事出勤表 | **基本不可定量** | 有缺勤数但**无工位安排维度**，无法确认是否影响本工单 → 只给候选项 |

**输出格式（固定）**：

```
① 缺料 [可定量]
   证据：…（含具体数字与算式）
   结论：…（或"可明确排除"）

③ 品质 [数据不足]
   证据：返工单 XX（数量栏写"少量"）、返工单 YY（数量栏写"几件"）
   为什么算不了：数量栏为文字描述，无法计算返工工时占用
   待确认：向品保确认两张单的实际件数
```

**硬规则：标为"数据不足"的根因，不得给出百分比或天数贡献。** 宁可写"无法计算"，不可写"约占 30%"。

**顺带发现要报出来**：如果同一缺陷在短期内多次出现（如两天内两次焊缝气孔），即使数量不明，也要提示"可能是工艺或设备的连带表现，建议同步品保"。这类发现的价值在于——**那两张返工单是品保部两张独立的纸质单，没人把它们放在一起看过。**

### STEP 4 · 补产建议

每张需处置的工单给：**是否需补产 / 建议动作 / 责任人 / 时点**。

分层原则：
- **数据不可信的**：第一动作是补齐报工，不是补产
- **返工未补回且临近交货的**：第一动作是确认返工件状态，且要给出"若已完成 / 若未完成"两条分支
- **即将卡料的**：不是补产问题，是防断料，要算出等料窗口天数
- **有报废需补投的**：明确补投数量与下单时点
- **欠数但交期充裕的**：**明确写"不需补产，也不需列入早会"**

**硬规则：不改工单。** 需要重排产能的，明确写"建议转排产调整场景（5.4）"。改排产的权限在生产经理或老板手上。

### STEP 5 · 早会日报

只放**今日必须处置**的工单（通常 2-4 张），不是全量清单。必须含：
- 数据时点异常提示（放最前面）
- 每张工单：偏差类型、关键数字、建议动作、责任人、时点
- 待确认事项（问谁、确认什么）
- **签收栏**：PMC / 生产经理 / 车间主管

按调研结论：这类日报在中小企业是要**打印成纸质件留档**的，不是电子看板。所以排版要考虑 A4 打印。

---

## 4. 输出结构（固定，不可缺项）

```
一、数据可信度说明（哪几张工单的数据不可信、为什么）
二、偏差清单（全量工单 + 三类偏差标记 + 按紧急度排序）
三、逐张根因候选（四类逐一，标明可定量/数据不足 + 证据 + 待确认）
四、补产建议（含明确的"不需补产"行）
五、今日必须处置的 N 张（早会用）
六、待确认事项（问谁 · 确认什么）
七、交付物：偏差清单 xlsx（3 sheet）+ 执行偏差日报 pdf（1 页可签字）
```

---

## 5. 硬规则（不可违反）

1. **数据时点校验必须在最前**。超 48h 未报工的工单不得输出根因结论。
2. **不硬凑归因**。标为"数据不足"的根因不得给百分比或天数贡献。
3. **不改工单**。只出清单与建议，要改排产明确写"转 5.3 排产与插单调整"。
4. **"返工未补回"必须作为独立一类偏差识别**，且要按交货日剩余天数判优先级。
5. **必须明确标出"不需补产也不需列入早会"的工单**。早会时间有限，摘出去和排上来同等重要。
6. **每条结论必须带证据出处**（哪份表、哪个单号、哪一行）。
7. **能明确排除的要明确排除**（如"本工单缺料缺口为 0，可排除缺料因素"）。
8. **不做根因深挖**。本Skill 只做归类，缺陷的根本原因分析属品质异常分析场景（9.1）。
9. **按紧急度排序，不按滞后天数排序**。最红的不一定最急。

## 6. 常见坑

| 坑 | 规避 |
|---|---|
| 直接采信系统里的滞后天数 | 先算报工时点距今多久|
| 按完成率或滞后天数排序 | 按"剩余时间 +偏差性质"排紧急度 |
| 跳过进度 95%+ 的工单 | 专门检查这批是否为"返工未补回" |
| 给品质/人手类根因编一个百分比 | 明说数据不足，给候选项 |
| 把"投入−完工"的差额当成在制 | 差额可能是报废/返工/数错，若备注为"未说明"必须标出 |
| 忘了检查工位占用连带影响 | 未开工的工单也要看是否在等某个工位 |
| 日报做成全量清单 | 只放今日必须处置的 2-4 张 |
| 做成电子看板 | 中小企业早会要打印签字，排版按A4 |
