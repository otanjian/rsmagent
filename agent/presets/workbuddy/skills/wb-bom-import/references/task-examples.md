# 可选任务

## 首推默认

帮我把这几份 BOM 对一下：ERP 里的当前受控基线是 P-IPC-01_基线_v1.2.xlsx，研发刚发来的新版给了 P-IPC-01_新版_v1.3.xlsx、P-IPC-01_新版_v1.3.pdf 和研发邮件_BOM_v1.3.docx 三份。先看几份来源之间对不对得上，再跟基线比差异；顺手把 BOM 本身的脏数据体检一遍（重复料、空用量、缺版本号这类）。差异按新增、删除、替换、用量变化、信息修订分组，每条写清判断依据，拿不准的单独列出来别猜；邮件正文里研发的说明也一起读，看能不能关联到某个具体料号。产出两份：一份 BOM 核对报告 Excel（来源一致性、脏数据体检、差异清单、变更影响、结论五段）、一份待澄清问题清单 Excel（阻塞项汇总，一次问完）。

## 只做来源交叉核对

先别跟基线比，只跑同一版本多来源的交叉核对：把新版 Excel、新版 PDF、研发邮件三份互相对一遍，重点看用量、单位、版本号、替代料、供应商。对不上的标成阻塞项，别替我选一个值。产出用 Excel：字段、三份来源各自的值、是否冲突、处理建议。

## 换成只比基线不比来源

这次不做来源交叉核对，只拿新版 Excel 跟基线 v1.2 比差异，看看差异清单会不会比上次多出被来源冲突掩盖的那些项。产出用 Excel：五类差异分组清单，每条带依据与置信度。

## 一次核三个产品的新版 BOM

演示数据里再加上另外两个产品的新版 BOM（同一批发布），三份一起核，各自出差异清单，最后给我一张三产品横向对照表：新增、删除、替换、用量变化、信息修订各类条数，以及待澄清数。产出用 Excel。

## 给研发的一页追问清单

基于基线 v1.2 与三份新版来源的比对结果，把阻塞项汇总成一页给研发：一条一行写清疑点、我方判断、为什么不能自行决定、建议动作，一次问完，不要发现一个问一次。产出一页纸。

## 让它反驳自己

读新版 Excel、新版 PDF 与研发邮件三份来源：你归成「替换」的那几对料号，依据够吗？描述相似度高但料号不同的，本该标待确认而不是直接归类。把可能归错的挑出来。产出用 Excel：料号、当前归类、依据、是否降为待澄清。

## 专门比历史重复料

专门查疑似重复料这一项：以前有没有同类的一物多码被处理过、当时的处理办法和影响的历史单据有哪些。把本次命中的重复料跟历史对上。产出用 Excel：料号对、可疑点、历史同类处理、影响单据。

## 对照体检清单自查

对照脏数据体检的六类（疑似重复料、单位可疑、用量异常、层级孤儿件、替代料未标、版本号缺失），把基线和新版都扫一遍，把存量问题跟本次变更分开列。产出用 Excel：类别、命中项、为什么可疑、是否属本次变更、建议。

## 折算成旧料金额敞口

读基线 v1.2 与新版 v1.3 的差异清单，把每条差异牵动的旧料算成钱：未完工工单几张、共用多少台，已下达与在途多少，旧料剩余数量乘单价等于多少金额敞口。产出用 Excel，每条差异一行带算式。

## 沉淀成核对模板

把这次的核对动作与判据整理成一份可复用的 BOM 核对模板：角色识别的优先级、五类差异判定、置信度分档、待澄清的触发情形。产出用 Markdown 模板。
