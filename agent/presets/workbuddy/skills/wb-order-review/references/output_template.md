# 输出模板

## 5.1 · 订单可行性分析

```
🎯 订单可行性分析 · {订单编号}
   客户：{客户名称}（等级：战略/A类/B类/C类）
   产品：{产品} × {数量}
   交期：{交期}（剩余 {N} 天）
   综合判定：🟢 可接单 / 🟡 谨慎接单 / 🔴 不建议接

📊 物料齐套
- 缺口料：{料号} · 需求 {N} · 可用 {N} · 缺口 {N}
- 替代料：{可否补齐}
- 冻结批次：{批次} · {qty}

📊 产能评估
- 瓶颈工序：{工序} · 负荷 {N}%
- 在制冲突：{工单列表}

🔧 建议动作
1. {动作} · 责任岗位：{岗位}
2. ...
```

## 5.2 · 交期平衡三色建议

```
🎯 本周 {产线} · {产品} 交期取舍
   冲突订单：{N} 张· 合计 {N} 台
   瓶颈：{工序} · 负荷 {N}%

| 订单 | 客户 | 数量 | 交期 | 客户等级 | 建议 | 原因 |
|---|---|---|---|---|---|---|
| {SO} | {客户} | {N} | {日期} | {等级} | 🟢守/🟡拆/🔴延 | {原因} |

对外口径：{给销售的沟通话术}

分部门待办：
- 销售：{动作}
- 生产：{动作}
- PMC：{动作}
```

## 5.4 · 工单优先级调整通知

```
📋 排产调整通知 · {订单编号} {客户}

• 调整内容：工单 {WO} 优先级 {原} → {新}
• 调整原因：{原因}
• 影响工序：{装配/喷涂/包装}
• 交期评估：{结论}

@相关工序
```
