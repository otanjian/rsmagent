# 销售合同条款风险审查 Skill

> 销售岗位场景 1.5 专用 · **双基线比对**（通用红线清单 + 历史已签合同）· 解决"企业没有标准合同模板"这个前提问题 → 逐条判风险 → 给可直接复制的建议文本 → 三条致命项摘要给老板

---

## 1. 用途

中小制造企业签合同的真实状态：**没有法务、没有标准模板、老板凭经验拍**。这个 Skill 一次做完五件事：

1. **条款归类**：逐条归入七类风险（验收条件 / 技术规格 / 交付责任 / 付款账期 / 违约金 / 质保金 / 管辖送达），识别模糊表述
2. **比基线①通用红线清单**：回答"这条在行业里算不算坑"
3. **比基线② 历史已签合同**：回答"这条相对我们平时签的是松还是紧"，并**翻出同一客户的历史履约情况**
4. **判风险等级 + 给建议文本**：高/ 中 / 低三档 + **可直接复制进反馈邮件的条款原文**
5. **三条致命项摘要**：给老板的一页 + 谈判优先级

**这个 Skill 的设计前提与常规做法不同（关键）**：

常规做法是"与内部标准模板逐条比对"。但调研结论是——**中小制造企业普遍没有内部标准合同模板**，所以这个前提就不成立。

解决办法是拆成两个问题分别回答：
- "这条在行业里算不算坑" → **通用红线清单**（外部经验）
- "这条相对我们平时签的是松还是紧" → **自己历史已签合同**（内部经验）

## 2. 触发方式

### 2.1 用户一句话触发（推荐）

```
客户发来的合同我摘录成表了，帮我看看有没有坑。
我们没有自己的标准合同模板 —— 我把通用的红线清单和我们近两年签过的合同都放进来了，
你对着这两个看。
哪些条款按行业惯例就不合理、哪些是相对我们平时签的被压得更狠，分开告诉我。
能改的给我改好的话术，我直接发给客户。
别一上来把所有条款都标成高危 —— 照那么改客户直接不签了。
也别给我引法条，我要的是能拿去谈的东西。
```

### 2.2 输入材料清单

| # | 材料 | 必需 | 缺失时的降级策略 |
|---|---|---|---|
| 1 | 待签合同条款摘录（或合同原文/扫描件） | **必需** | 无此项无法运行 |
| 2 | **通用条款红线清单** | **必需** | 缺失时用Skill 内置的 13 条通用红线，并提示企业应自行补充行业特有条款 |
| 3 | **历史已签合同条款基线** | 强烈建议 | **缺失时无法回答"相对我方历史是松还是紧"**，也无法翻同一客户旧账，须明确说明这一局限 |

## 3. 五步法工作流程

### STEP 1 · 条款归类与模糊表述识别

七类风险：**验收条件 / 技术规格 / 交付责任 / 付款账期 / 违约金 / 质保金 / 管辖送达**

必须识别的模糊表述（它们本身就是风险）：
- "按需交付""按甲方要求" —— 义务不可预期
- "符合行业标准""符合甲方使用要求" —— 不可执行的技术标准
- "全套单据""相关文件" —— 未列明清单，可成为拖延理由
- "随时""无条件" —— 无期限、无限制

### STEP 2 · 必须做的合并审查（最容易漏的一步）

**风险往往不在某一条里，在两条的组合里。**

必查的组合：

| 组合 | 单看的样子 | 合起来的效果 |
|---|---|---|
| 「签收即完成交付」+「保留质量异议权/可随时提出异议」 | 前者对卖方有利、后者是常规条款 | **交付责任封闭，质量责任无限期敞开** |
| 「按需交付」+「高额逾期违约金」 | 一个是灵活性，一个是违约条款 | **客户改要求导致的延期仍算卖方逾期** |
| 「未附技术协议」+「符合甲方使用要求」 | 都像常规表述 | **质量标准由买方单方解释** |
| 「质保金无返还条件」+「历史质保金未返还」 | 前者是条款、后者是事实 | **同一个地方连续栽两次** |

**输出时必须把需合并审查的条款标注为一组**，不能拆开逐条给意见。

### STEP 3 · 双基线比对

**基线① 通用红线清单**（13 条，见 references）：判"这条在行业里算不算坑"，输出命中的红线编号。

**基线② 历史已签合同**：判"相对我方历史是松还是紧"，输出：
- 我方常见约定 vs 历史最严的一次 vs 本次要求
- 结论：`与最严的N 次相同` / `比历史最严的还严X 倍` / `低于我方所有历史合同`

**同时必须做的一件事：翻同一客户的旧账。** 检查历史合同里是否有该客户的记录，特别是：
- 履约情况备注里的异常（曾被扣违约金、质保金未返还）
- 上一份合同的应收状态

**这条提示的价值在于它是企业自己的记录** —— 不是外部经验、不是法律条文，就是自己签过的合同和现在的应收状态。**只是从来没有人在签新合同前把它调出来看过。**

### STEP 4 · 风险等级 + 建议文本

**风险三档**：

| 等级 | 标准 | 处理 |
|---|---|---|
| **高** | 可能导致无限期责任、无上限赔偿、质量标准由对方单方解释、违约金显著超通常水平 | 必须改，列入致命项 |
| **中** | 影响回款周期、维权成本、担保效力 | 建议改，可谈判让步 |
| **低** | 表述不严谨但实际影响有限 | 提示即可 |

**每条必须给「是否可让」**。这一列很重要——**因为把所有条款都标高危、照改会导致对方直接拒签**。

**建议文本的写法（硬要求）**：

❌ 错误：`建议关注违约金条款，比例偏高`
✅ 正确：把改后的条款原文写出来，销售可以直接复制进反馈邮件：
> 乙方逾期交货的，按**逾期未交付部分货款**的**日万分之五**计付违约金，累计不超过该部分货款的 5%。因甲方变更技术要求、延迟提供图纸或延迟确认样件导致的延期，不计入乙方逾期。

建议文本要尽量**附带对己方的保护**（如上例后半句），而不只是把数字调低。

### STEP 5 · 三条致命项摘要

给老板的一页只放**三条必须改的**，每条要：
- 一句话说清不利后果
- **算成钱**（如"按 42.4 万计，逾期 10 天违约金 4.24 万元，占合同总价 10%"）
- 谈判优先级建议

**加上同一客户的旧账（如有）。** 这往往是最有力的谈判抓手。

## 4. 输出结构（固定，不可缺项）

```
一、基线说明（企业无标准模板，用哪两个基线，以及各自回答什么问题）
二、需合并审查的条款组（不可拆开逐条给意见）
三、高风险条款逐条（原文 / 问题 / 命中红线 / 历史对比 / 商业影响 / 建议文本）
四、中低风险条款（表格形式）
五、相对我方历史合同的松紧对比（含同一客户旧账）
六、三条致命项摘要 + 谈判优先级
七、交付物：条款差异比对表 xlsx + 条款风险提示 pdf（2 页，含免责）
```

## 5. 硬规则（不可违反）

1. **不引法条、不写具体法条号**。红线清单只写"为什么是坑"和"安全表述参考"。**AI 编造法条是这类应用最常见的翻车方式。**
2. **不出法律意见**。所有交付物页脚必须印明"本表为条款风险提示，不构成法律意见；重大合同建议由专业律师审阅"。
3. **不一刀切标高危**。必须分三档并给"是否可让"—— 把所有条款都标高危会导致对方拒签。
4. **必须做合并审查**，不可把需组合看的条款拆开逐条给意见。
5. **建议文本必须是可直接替换的条款原文**，不是"建议关注 XX"。
6. **无历史合同基线时，必须明确说明无法判断松紧**，不得凭感觉说"这条比一般的严"。
7. **不承诺能发现合同外文件的矛盾**。图纸、技术协议、会议纪要之间的冲突 AI 看不到，只能提示"应作为附件签认"。
8. **必须提示商业机密风险**：上传合同涉及机密，演示应用脱敏文本。
9. **不替老板决定签不签**。只做风险提示与谈判建议，商业取舍留给人。

## 6. 常见坑

| 坑 | 规避 |
|---|---|
| 假设企业有标准合同模板 | 用双基线（通用红线 + 历史合同）替代 |
| 逐条看，漏掉条款组合的风险 | 强制做合并审查（见STEP 2 表） |
| 把所有条款标成高危 | 分三档 + 给"是否可让" |
| 给"建议关注 XX"这类无法执行的意见 | 给可直接复制的条款原文 |
| 引法条壮胆 | 不引法条，只写为什么是坑 |
| 忘了翻同一客户的旧账 | 历史合同基线里必查该客户履约记录 |
| 违约金只说"偏高" | 算成钱 + 对比通常水平 + 对比自己历史 |
| 声称能审出图纸与合同的矛盾 | 明确说明看不到合同外文件 |
