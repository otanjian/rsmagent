# 5 份跨部门报表的字段规范

> 让 Skill 能"并行读多份报表"的关键：**每份报表都有标准字段**。如果客户实际报表字段不一致，可以做个映射层。

---

## 1. BOM 基线.xlsx

### 数据源

从ERP-BOM 主数据导出（或 PLM 系统）

### 关键字段

| 字段 | 说明 |
|---|---|
| **料号** | 主键，用于其他表关联 |
| **物料名称** | — |
| **用量** | 单台产品的使用量 |
| **版本** | 物料版本号 |
| **替代料号** | 若为空，Skill 会将其视为无替代方案 |
| **备注** | 关键件、共用料等标记 |

### 元数据

- 产品编号 · 版本 · 受控状态 ·ECN 关联

---

## 2. 齐套报表.xlsx

### 数据源

PMC / 仓库每日早晚导出

### 关键字段

| 字段 | 说明 |
|---|---|
| **料号** | 与 BOM 基线关联 |
| **需求量** | 试产目标数量 × 单台用量 |
| **可用量** | 现场可用（不含冻结） |
| **缺口** | 需求量- 可用量（负数为盈余，可为空） |
| **替代料号** | 若有，来自 BOM 基线 |
| **替代可用** | 替代料的可用量 |
| **冻结原因** | 说明为何有库存不能用（如"质检中"、"客户扣留"） |

### 齐套判据

`需求量 ≤ 可用量 + 替代可用量` → 齐套

---

## 3. SOP 发放台账.xlsx

### 数据源

工艺文件受控管理系统（或人工台账）

### 关键字段

| 字段 | 说明 |
|---|---|
| **文件编号** | 如 SOP-A-06、WI-ASSY-01 |
| **文件名称** | — |
| **当前版本** | — |
| **状态** | 已发放 / 待发放 / 待受控 |
| **覆盖工序** | 装配 / 喷涂 / 测试 / 包装 / 检验 等 |
| **已发放工位** | 具体工位（装配一线、检验工位） |
| **发放日期** | — |

---

## 4. 产能负荷表.xlsx

### 数据源

MES / APS 系统导出（或人工排程）

### 关键字段

| 字段 | 说明 |
|---|---|
| **工作中心编号** | 如 WC-CUT、WC-ASSY1、WC-PAINT |
| **工作中心名称** | — |
| **类别** | 通用/ 装配/ 表面处理等 |
| **本周总产能（小时）** | — |
| **已排产（小时）** | — |
| **负荷率** | 已排产 ÷ 总产能 |

### 状态判据

- < 60% → 有余量
- 60-89% → 紧张
- 90-99% → 接近饱和
- 100% → 满载

## 6. 字段映射（客户实际报表字段不一致时）

如果客户的实际报表字段名跟规范不同，可以做个字段映射表 · Skill 会按映射读取：

| 标准字段 | 客户可能叫法 |
|---|---|
| 料号 | 料号 / 物料号 / 物料编码 / 物料编号 / 件号 / Part No / P/N |
| 物料名称 | 物料名称 / 品名 / 描述 / Description |
| 需求量 | 需求量 / 需求 / 应领 / QTY |
| 可用量 | 可用 / 现场可用 / 良品 / 良品数量 / Available |
| 工作中心 | 工作中心 / 工作中心编号 / WC / WorkCenter |
| 负荷率 | 负荷率 / 稼动率 / Utilization |
