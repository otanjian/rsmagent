# 输出模板

> 五项红黄绿 + 综合判定 + 卡点补齐建议 · 3 种模板可选

---

## 模板 A · 完整版（推荐）

```markdown
## {产品编号} 试产 {数量} 台 · 开工核查结果

**综合结论**：⚠ 黄灯 · 可开工，{N} 项需补
**扫描时间**：{yyyy-MM-dd HH:mm}

### 五项红黄绿

| # | 检查项 | 状态 | 关键结论 |
|---|---|---|---|
| ① | BOM 版本 | 🟢/⚠/🔴 |... |
| ② | 物料齐套 | 🟢/⚠/🔴 | ... |
| ③ | 工艺 SOP | 🟢/⚠/🔴 | ... |
| ④ | 产能位 | 🟢/⚠/🔴 | ... |
| ⑤ | 工装治具 | 🟢/⚠/🔴 | ... |

### 卡点补齐建议

**② {检查项名称}**
- {具体动作}
- 责任：{岗位}
- 预计完成：{时间}

**④ {检查项名称}**
- {具体动作}
- 责任：{岗位}
- 预计完成：{时间}

**达成上述条件后 → 可开工🟢**
```

## 模板 B · 简化版（管理层快速看）

```markdown
## {产品编号} × {数量} · 一句话开工核查

- ① BOM {🟢/⚠/🔴} · ② 齐套 {🟢/⚠/🔴} · ③ SOP {🟢/⚠/🔴} · ④ 产能 {🟢/⚠/🔴} · ⑤ 工装 {🟢/⚠/🔴}

**结论**：{绿灯 / 黄灯 / 红灯} · {一句话说明}

**关键补齐动作**：{1-2 条}
```
