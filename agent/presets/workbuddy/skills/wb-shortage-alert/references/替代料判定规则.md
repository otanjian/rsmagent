# 替代料判定规则

> 本文件是「齐套与缺料预警」Skill 的核心规则文档。
> 解决两件事：
> **① 技术上明明能替，为什么这个客户不能替；**
> **② 规格不同的呆滞料，为什么在某个产品上能顶。**

---

## 一、为什么替代料判不准

ERP 里有"替代料主数据"这张表，但它只解决了四分之一的问题。

|盲区 | 具体表现 |
|---|---|
| **只维护技术等效** | 表里写着 M-PCB-001 可替 M-PCB-002，但没有一列告诉你"某主机厂不接受" |
| **按物料建行，不按客户** | 一个替代关系一行。同一个料号卖给三个客户，其中一个有 PPAP，这张表表达不出来 |
| **客户约束不在系统里** | PPAP PSW、客户技术规格书、图纸会签记录都是文档，不是字段 |
| **规格不同就没关系** | M-SPCC-18 和 M-SPCC-20 是两个独立物料编码，主数据里没有任何关联，但某个产品的图纸公差可能把两者都包住 |

结果就是：**要么不敢替（怕客户审核出问题），要么乱替（客户审核真出问题）。**

---

## 二、四道校验

### 2.1 四道，缺一即不可用

| 道 | 校验项 | 判据来源 | 不过的后果 |
|---|---|---|---|
| ② | **技术是否等效** | 图纸公差 / 技术规格书 / 老化与 EMC 报告 / 材质证明书 | 淘汰，**不必再问客户** |
| ① | **客户是否认可** | PPAP PSW / 客户技术规格书 / 图纸会签记录 / 客户书面批复 | 淘汰。**硬门槛** |
| ③ | **是否需重新首件** | 变更点性质 | 不淘汰，决定前置工作量与时限 |
| ④ | **成本差异** | 替代单价 − 原单价 | 不淘汰，决定要不要报批 |

### 2.2 执行顺序：先技术，后客户

编号是①②③④（按重要性），但**执行顺序是 ② → ① → ③ → ④**。

理由：技术上已经否决的，没必要去问客户，省一轮沟通。技术过了但客户不认的，才是真正需要摆到桌面上的取舍。

```
候选替代料
  ↓ ② 技术等效性
  ├─ 不通过 → 淘汰（不问客户）
  └─ 通过
      ↓ ① 客户是否认可（按客户逐个判）
      ├─ 否 → 淘汰（记录为"技术可行、商务不可行"，这是重要结论）
      ├─ 待确认 → 列为待办，输出"技术可行，客户认可待确认"
      └─ 是
          ↓ ③ 是否需重新首件 → 决定前置动作与时限
          ↓ ④ 成本差异 → 决定要不要报批
          → 采纳
```

### 2.3 第 ② 道：技术等效性

三种结论：

| 结论 | 含义 | 例子 |
|---|---|---|
| **等效** | 关键参数一致或优于原料 | M-PCB-002：Pin-to-Pin 兼容，外形/接口/固件接口一致，MCU 换国产型号但已做 1000h 高温老化 + EMC 复测 |
| **非等效但落在公差内** | 参数不同，但落在图纸公差区间内 | M-SPCC-18 1.8mm 用于图纸公差 1.8~2.2mm 的P-BRK-03 |
| **不等效** | 关键参数超出要求 | M-USBC-02 插拔寿命 3000 次，客户规格书要求≥5000 次 |

**"非等效但落在公差内"是最容易被漏掉的一类。** 它在物料主数据里看不出来，只在图纸里。这一类是呆滞料反查的主战场（见第四节）。

**判定必须挂具体判据**：哪份图纸、哪个版本、哪一条公差、实测值多少。写"技术上应该没问题"不算判定。

### 2.4 第 ① 道：客户是否认可（硬门槛）

**这是最容易被跳过的一道。**

| 客户类型 | 认可机制 | 替代难度 |
|---|---|---|
| **有 PPAP 的客户**（汽车零部件一级供应商体系等） | PSW 已锁定料号、材料规格、供应商。任一项变更都是变更点 | 高。须PPAP 重提交（Level 3 含 PSW 重签，周期数周）或材料偏差申请书面批复 |
| **有技术规格书约束的客户** | 规格书里的硬指标（如插拔寿命 ≥5000 次） | 中。指标满足即可，不满足则免谈 |
| **通用工业客户** | 按我方图纸与技术标准验收，无指定料号约束 | 低。内部工艺确认即可 |

**PPAP 锁定的三项**（容易只记住料号）：

```
① 料号     → 换料号 = 变更点
② 材料规格 → 板材厚度从 2.0 改 1.8 = 变更点（即使落在图纸公差内！）
③ 供应商→ 换供应商 = 变更点（即使料号和规格都不变）
```

**第 ③ 项和第 ② 项最容易被忽略**。图纸公差允许 1.8~2.2mm，不代表可以随便用1.8mm —— 因为 PPAP 提交时报的是 2.0mm，客户批准的是"用 2.0mm 生产出来的零件"。改厚度属于材料变更点，须走材料偏差申请。

**同一批料、同一份图纸，换个客户结论可以完全相反。** 这不是数据矛盾，是 PPAP 机制的必然结果。

### 2.5 第 ③道：是否需重新首件

| 变更点性质 | 是否需重新首件 | 典型内容 |
|---|---|---|
| 料号变更（不同物料编码） | ✅ 需要 | 功能测试 + 老化；电子件通常还要 EMC |
| 材料规格变更（厚度、材质） | ✅ 需要 | 尺寸测量 + 载荷/强度测试 |
| 供应商变更（同料号） | ✅ 需要 | 首批全检 + 关键尺寸/性能抽测 |
| 同图号版本内变更（如线束长度在允差内） | ❌ 不需要 | —— |

首件要求决定**前置动作的时限**：首件签不出来，工单就开不了工。这一条直接决定三色结论是黄还是红。

### 2.6 第 ④ 道：成本差异

```
成本差异 = 替代物料单价 − 原物料单价
成本影响 = 成本差异 × 启用数量
```

- 为正（贵了）→ 判断是否超采购授权，超了要报批
- 为负（便宜了）→ 不必报批，但要在输出里写明（这是采购的可见贡献）
- 呆滞料替代还有一层附加收益：**消化呆滞库存金额 = 启用数量 × 呆滞料单价**，这是月度呆滞考核项

**成本不是决策的主导因素。** 替代料的首要目的是保交付，成本差异只用于判断报批路径。不要因为贵了几百块就否掉一条能救整张工单的路径。

## 三、替代料关系表必须按「物料 × 客户」建行

### 3.1 为什么

按「物料」建行的表：

| 原物料 | 替代物料 | 技术等效 | 是否可替 |
|---|---|---|---|
| M-PCB-001 | M-PCB-002 | 等效 | 是 |

这张表会导致某主机厂的工单被误判为可替，客户审核直接开不合格项。

按「物料 × 客户」建行的表：

| 原物料 | 替代物料 | 适用范围（产品/客户） | 技术等效 | **客户是否认可** | 有效状态 | 认可依据 |
|---|---|---|---|---|---|---|
| M-PCB-001 | M-PCB-002 | P-IPC-01 / 某主机厂 HX-2041 | 等效 | **否** | 受限 | PPAP PSW 锁定料号，切换须重走Level 3 |
| M-PCB-001 | M-PCB-002 | P-IPC-01 / 华东电气 | 等效 | **是** | 有效 | 按我方图纸与技术标准验收，无指定料号约束 |

同一个替代关系，两行，两个相反结论。

### 3.2 有效状态的四种取值

| 状态 | 含义 | 能不能用 |
|---|---|---|
| **有效** | 四道全过 | ✅ 可用 |
| **受限** | 技术过了，客户认可未过（或需额外审批） | ⛔ 本次不可用，但记录路径（如"须客户书面偏差申请"） |
| **禁用** | 技术等效性已否决 | ⛔ 任何客户均不可用 |
| **待评审** | 技术等效性未结论 | ⛔ 不可用，列为待办 |

**"受限"和"禁用"必须区分开**。受限的意思是"有条件可用"，条件写清楚了以后可能用得上；禁用是技术层面永久否决。混成一个状态会丢掉信息。

## 四、呆滞料按图纸公差区间反查

### 4.1 核心原则

**判据是「实测值是否落在图纸公差区间内」，不是「规格是否相同」。**

大多数人和大多数系统的做法：需要 2.0mm，库里是 1.8mm，规格不同 → 放弃。
正确做法：查每个在产产品的图纸公差，看1.8mm 落不落在某个产品的公差区间内。

### 4.2 三层判定

```
第 1 层 实测值
  读呆滞料清单的备注列取实测值（如厚度实测 1.78 / 1.81 / 1.83mm）
  ⚠ 无实测值 → 不得下"可用"结论，只能输出"疑似可用，需实测复核"
      ↓
第 2 层 图纸公差区间
  读BOM 明细备注列 / 图纸的公差要求，逐产品比
  实测值落在该产品公差区间内 → 技术通过
  超出区间 → 技术否决，不必再问客户
      ↓
第 3 层 客户认可
  技术通过的组合，过四道校验第 ① 道
  无PPAP 约束 → 按图纸公差自动认可
  有 PPAP 约束且涉及材料规格变更 → 须客户书面认可（材料偏差申请）
```

### 4.3 完整案例

```
需要：M-SPCC-20 冷轧板 2.0mm，缺 532 kg
库里：M-SPCC-18 冷轧板 1.8mm，批号 RM-SPCC-2512-08，460 kg，单价 6.15 元，呆滞 8 个月
      备注：实测厚度 1.78 / 1.81 / 1.83 mm（3 点抽测，卡尺 CL-07，2026-07-30 复测）
            表面无锈蚀，材质证明书与炉批号齐全
```

**第 1 层**：有实测值 ✅ → 可以进入判定

**第 2 层**：逐产品比图纸公差

| 产品 | 图纸 | 板材厚度公差 | 1.8mm 是否落在区间 | 技术结论 |
|---|---|---|---|---|
| P-BRK-03 精密支架 | DWG-BRK-03 RevB | **1.8 ~ 2.2 mm** | ✅ 落在下限| **通过** |
| P-IPC-01 智能控制柜 | DWG-IPC-01 RevD | 1.90 ~ 2.10 mm | ❌ 超下限 0.10mm | 否决 |
| P-CAB-02 户外机柜 | DWG-CAB-02 RevC | 1.95 ~ 2.05 mm | ❌ 超下限 0.15mm | 否决 |

P-CAB-02 还有一层理由：户外机柜承受风载与雪载，减薄影响结构强度。**有物理理由的否决要写出来**，比只写"超公差"更有说服力。

**第 3 层**：P-BRK-03 通过技术，再按客户判

| 工单 | 客户 | 客户认可 | 结论 |
|---|---|---|---|
| WO-2026-0804 | 华东电气 | ✅ 是—— 按图纸公差自动认可，无指定料号约束 | **可用** |
| WO-2026-0806 | 某主机厂 HX-3155 | ⛔ 否 —— 原材料 2.0mm 已随 PPAP 提交获PSW 批准，厚度变更属材料变更点 | 不可用 |

**最终结论**：这批呆滞料只能用在 WO-2026-0804 上，320 kg，解 320 kg 缺口+ 消化呆滞库存 320 × 6.15 = 1968元。

### 4.4 为什么 MRP 永远给不出这个结论

| 信息 | 在哪里 | 在 ERP 里吗 |
|---|---|---|
| 实测厚度 1.78~1.83mm | 盘点复测记录 | ❌（最多在备注文本里） |
| 图纸公差 1.8~2.2mm | 图纸 DWG-BRK-03 RevB | ❌ |
| 客户 PPAP 锁定材料规格 | PPAP 提交包 / PSW | ❌ |
| M-SPCC-18 与 M-SPCC-20 的关系 | —— | ❌ 主数据里是两个独立物料编码，无任何关联 |

**物料主数据只能表达"这是两个不同的物料"，表达不了"其中一个在某个产品的某个客户上可以顶另一个"。** 这个判断需要把图纸、盘点记录、PPAP 文件三处信息交叉起来，这正是 Agent 的用处。

### 4.5 下限侧无余量的坑

实测值刚好压在公差边界时**不能整批放行**。

```
公差下限 1.80mm，实测 1.78 / 1.81 / 1.83mm
→ 1.78mm 这张已经低于下限，不合格
→ 必须逐张复测，只挑 ≥1.80mm 的板
```

**这一条必须写进动作清单**（责任人：工艺；时限：开工日前 1 天；验收标准：出公差符合性确认单，逐张实测值记录留档）。

忽略这一点会导致"用了呆滞料反而出批量不良"，把一条好路径变成品质事故 —— 这也是很多企业不敢碰呆滞料的真实原因。

### 4.6 库位与标识管理

呆滞料动用后必须做防错，否则现场会误领：

```
① 从呆滞库位转生产备料区（做库位调拨单，账实一致）
② 物料标识必须写全：批号 + 实测厚度 + 限用产品 + 限用客户
   例："RM-SPCC-2512-08 · 实测 1.80~1.83mm · 限用 P-BRK-03 · 限华东电气"
```

**没有限用标识，这批 1.8mm 板材很可能被领去做 P-CAB-02（公差 1.95~2.05mm），批量报废。** 这条动作看起来琐碎，但它是这条路径能不能安全落地的关键。

### 4.7 无路径呆滞料的处置

反查完要把"本次完全无路径"的呆滞料单独列出，附金额，提月度呆滞处置会。

| 无路径原因 | 例子 | 处置建议 |
|---|---|---|
| 无任何产品公差覆盖 | M-SPCC-15 1.5mm，低于三个产品公差下限 | 报废 / 退供折价 / 转其他项目 |
| 功能不兼容（非公差问题） | M-PCB-004 V1.2 主板，固件协议不兼容 | 报废 / 退供折价 |
| 无公差重叠区间 | M-LOCK-07 孔距 62mm vs 现行 68mm | 报废 |
| 当前无适用机型 | M-USBC-03 IP20，当前无室内机型工单 | 长期保留（等室内机型订单） |

**"长期保留"要给条件**（等什么订单），否则就是拖延。

## 五、可用库存的分配顺序（判定完替代料后要做的事）

### 5.1 规则

```
可用库存优先分配给：无替代路径的工单 > 有替代路径的工单
```

### 5.2 为什么

若先给了有替代路径的工单，缺口就落在无替代路径的工单上 —— **那是死结**。

```
M-PCB-001 可用 120 pcs，需求 180 pcs
  WO-2026-0801 某主机厂 100 台（PPAP 锁定料号，无替代路径）
  WO-2026-0802 华东电气   80 台（可用 M-PCB-002 替代）

✅ 正确：120 优先给 0801 → 剩 20 给 0802 → 0802 缺 60 → 替代料补齐 → 两张单都能做

❌ 错误：按工单号/ 开工日自动分配
        若 0802 先拿到 80 pcs → 0801 只剩 40 pcs → 缺 60 pcs → 无替代路径 → 死结
```

### 5.3 MRP 不会这么分配

MRP 按工单号顺序、开工日先后或优先级字段自动分配，**不看有无替代路径**。

**分配顺序本身就是一个判断，不是算术。** 这是本Skill 与 MRP 分工的又一个具体落点。

## 六、替代料判定的输出检查清单

1. ☐ 是否按「物料 × 客户」逐组合建行（不是按物料）
2. ☐ 四道校验是否每道都有结论，不能有空白
3. ☐ 淘汰的候选是否写明卡在第几道
4. ☐ 技术等效性判定是否挂了具体判据（图纸号+ 版本 + 公差 + 实测值）
5. ☐ 客户认可判定是否挂了依据（PSW /技术规格书 / 图纸会签）
6. ☐ 是否区分了"受限"（有条件可用）与"禁用"（技术永久否决）
7. ☐ 呆滞料反查是否有实测值支撑，无实测值是否已降级为"需复核"
8. ☐ 实测值压在公差边界时，是否已生成"逐张复测挑选"动作
9. ☐ 呆滞料动用是否有库位调拨 + 限用标识动作
10. ☐ 成本差异是否算出金额，是否判断了报批路径
11. ☐ 呆滞料消化金额是否算出
12. ☐ 可用库存分配顺序是否已按"无替代路径优先"重排
13. ☐ 无路径呆滞料是否单独列出并附金额
14. ☐ 采纳的替代关系是否已生成备案动作（避免"临时替代用成常态却没走流程"）

---

## 七、一句话总结

替代料的难点从来不是技术等效 —— 那是工艺能判的事。
难点在**客户认可这道门槛不在任何一张表的字段里**，它散落在 PPAP 提交包、技术规格书、图纸会签记录里；
以及**规格不同的呆滞料能不能顶，判据在图纸公差里，不在物料主数据里**。

把这两处信息捞出来摆到桌面上，替代料判定才算做完。
