# 可选任务

## 首推默认

无锡片区投诉说市面上有低于他们进货价的同型号货，批号看着是苏州久盛的。下周渠道会要给处理意见。材料在这儿：各级价格体系表、各家的经销商进货台账（带批号）、窜货举报材料整理、终端零售价抽查记录、年度经销协议里的价格与区域条款，还有历史渠道处罚与判例口径摘录。

帮我先逐级算价差，看哪里倒挂了、倒挂多少。然后按批号把这批货追一下，是从哪家出去的、什么时候出的、多少量，出货到上市到投诉的时间线对不对得上，说不通的环节标出来。每一笔举报的证据齐不齐、能不能支撑认定，一条一条核。另外看一下合同里窜货是怎么定义的、有没有写取证标准、由谁认定、经销商有没有申辩期。以前常州片区那次凭一张照片扣款最后全额退回的教训，也对照着看。

交三份：渠道价格与窜货核查报告.xlsx（正式件本体，带签批栏）、批号流向证据链清单.xlsx（逐笔标证据齐备性）、合同条款缺口清单.xlsx（窜货定义、取证标准、认定流程逐项）。判不判窜货我们走流程定，你别下结论，也别给经销商发任何通知。

## 只追批号流向

先只追批号这一条线：拿举报材料里的批号对进货台账，逐笔追出货对象、时间、数量，其他都先不动。产出用 Excel 一张表：举报编号、照片批号、批号可辨识度、对应出货单号、出货对象、出货日期、数量、开单单价、流向链是否成立，追溯不上的写清卡在哪一步。

## 换成只核证据三要件

换个口径再跑一遍：这次不做价格也不追全链，只按证据三要件逐笔核——批号可辨识、有出货记录、时间线成立，其余线索一律不计。产出用 Excel 一张表：举报编号、批号可辨识、有出货记录、时间线成立、投诉方书面陈述、现场照片与小票、三要件是否齐备、对应扣款金额、结论。

## 一次核五个片区

演示数据里再加另外四个片区的举报材料和终端抽查记录，五个片区一起过，最后给我一张横向对照表：片区、举报笔数、证据齐备笔数、涉及金额、倒挂最严重的产品档。产出用 Excel，对照表单独一张 sheet。

## 给渠道会看的一页

把核查报告压成渠道会上用的一页纸：只留价格倒挂最严重的一档、证据齐备的 2 笔和证据不足的 3 笔、以及合同缺的那三条。产出用一份 Markdown 一页纸，价格表与流向链明细都不要。

## 让它反驳自己

你判「3 笔证据不足以支撑认定」，自己挑一下哪一笔其实可能够用：对着窜货举报材料整理和经销商进货台账，看有没有时间和型号对得上的线索。逐条说明现有证据、你的疑问、还需要补什么。产出用 Excel 一张表：举报编号、原结论、现有证据、你的疑问、建议改为。

## 比对常州片区那次

专门比 2023 年常州片区那次：凭一张手机照片和口头指认扣了 3.5 万元保证金，后来因为合同没写认定口径全额退回还赔了两个月账期宽限。把这次五笔举报和当时的结构对起来。产出用 Excel 一张表：对比项、常州那次、本次各笔、差异，取证结构相同的标出来。

## 对照协议条款自查

对照年度经销协议的价格与区域条款，把这份处理建议自查一遍：扣款依据的条款号有没有引对、有没有超出合同约定的处罚范围、有没有替谁做了认定、有没有该留证没留的。产出用 Excel 一张清单：条款条目、本次是否已对照、结论、越界或缺失项。

## 折算成返还与让步成本

拿年度经销协议的价格与区域条款和历史渠道处罚与判例口径摘录，把证据不齐的那 4.1 万元折算成钱：参照已有判决被主张返还的风险金额；再参照常州那次两个月账期宽限，按该经销商月均进货 62 万元算宽限的资金成本；同时说明先修订条款的成本是多少。产出用 Excel 一张表，算式与判例出处写清。

## 沉淀成条款补齐要点

把这次该补的条款要点整理成清单：窜货定义要具体到什么、取证需要哪几类材料、由谁认定、经销商有多长申辩期、认定后多久执行。产出用 Markdown 一份《窜货认定与取证条款补齐要点清单》，只出要点不出条款文本。
