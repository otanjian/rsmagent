# 输出骨架与渲染脚本

## 文件清单

- `CH-02_渠道价格与窜货核查报告.xlsx` —— 正式件本体 · 5 sheet · 含签批栏
- `CH-02_批号流向证据链清单.xlsx` —— 可派发 · 逐笔标证据齐备性
- `CH-02_合同条款缺口清单.xlsx` —— 窜货定义、取证标准、认定流程逐项

## sheet 结构

1. `结论摘要` —— 本次结论 / 关键指标 / 输入依据 / 人工边界 / 签批栏
2. `1.价格体系核对` —— 列头：价格层级 / 参照价 | XT-160(元/台) | GL-75(元/台) | 对上一级价差率 | 依据 | 倒挂判定
3. `2.批号流向` —— 列头：举报编号 | 照片批号 | 批号可辨识度 | 对应出货单号 | 出货对象 | 出货日期 | 数量(台) | 开单单价(元) | 流向链是否成立
4. `3.证据链齐备性` —— 列头：举报编号 | 批号可辨识 | 有出货记录 | 时间线成立 | 投诉方书面陈述 | 现场照片/小票 | 三要件是否齐备 | 对应扣款(元) | 结论
5. `4.条款缺口` —— 列头：缺口项 | 协议现状 | 条款出处 | 已造成的后果 | 补齐要点 | 责任人 | 完成时点 | 验收标准

## 视觉规范

正式件本体用**风格 A**（浅灰表头 `F6F8FB` + 深字 `1A2332`）；
清单类用**风格 B**（蓝底白字 `2D6CDF`）。同一个包里不要混用。

```python
INK, MUTED, GREY = "1A2332", "5A6675", "8A94A3"
HEAD_A, HEAD_B   = "F6F8FB", "2D6CDF"
RED, AMBER, GREEN = "C62F2F", "B9770A", "1E8E5A"
FONT = "微软雅黑"
```

必做三件事：

```python
ws.freeze_panes = "A4"                          # 冻结表头
ws.auto_filter.ref = f"A3:{last_col}{last_row}"   # 开筛选
ws.sheet_view.showGridLines = False              # 关网格线，更像正式件
```

编制 / 审核 / 会签 / 批准四栏 + 日期列。
**推荐意见、完成质量、责任认定三栏留空。**

## 渲染脚本自检

```python
# 分项加总必须等于合计
assert abs(sum(items) - total) < 0.01, f"分项 {sum(items)} != 合计 {total}"
# 占比合计必须等于 100%
assert abs(sum(pcts) - 100) < 0.1
# 行数守恒
assert len(out_rows) == len(in_rows), "行数不守恒"
```

跑不过就不出文件 —— 从根上杜绝「合计对不上」这种一眼被看穿的错。
