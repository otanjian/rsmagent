# 输出骨架与渲染脚本

## 文件清单

- `CH-01_年度返利核算单.xlsx` —— 正式件本体 · 6 sheet · 含签批栏
- `CH-01_政策口径矛盾清单.xlsx` —— 可派发 · 矛盾处双向标注与出处
- `CH-01_扣款依据与取证核查表.xlsx` —— 逐笔扣款核取证齐备性

## sheet 结构

1. `结论摘要` —— 本次结论 / 关键指标 / 输入依据 / 人工边界 / 签批栏
2. `1.政策梳理` —— 列头：政策文件 | 形式与编号 | 生效期间 | 覆盖产品 | 是否与年度返利叠加 | 对返利基数的表述 | 矛盾点
3. `2.基数归一` —— 列头：基数构成项 | 我方口径 | 久盛口径 | 差异(元) | 第三方凭证 | 验证结果
4. `3.扣款核查` —— 列头：处罚单号 | 发生月份 | 举报来源 | 涉及批号 | 扣款金额(元) | 批号可追 | 出货记录 | 时间线 | 取证结论
5. `4.差额归因` —— 列头：归因项 | 我方核算 | 久盛主张 | 差额(元) | 占差额比 | 依据与出处 | 处理路径
6. `5.留证与签批` —— 列头：优先级 | 事项 | 现状 | 整改内容 | 改哪份文件 | 责任人 | 完成时点 | 验收标准

## 视觉规范

正式件本体用**风格 A**（浅灰表头 `F6F8FB` + 深字 `1A2332`）；
清单类用**风格 B**（蓝底白字 `2D6CDF`）。同一个包里不要混用。

```python
INK, MUTED, GREY = "1A2332", "5A6675", "8A94A3"
HEAD_A, HEAD_B   = "F6F8FB", "2D6CDF"
RED, AMBER, GREEN = "C62F2F", "B9770A", "1E8E5A"
FONT = "微软雅黑"
```

必做三件事：

```python
ws.freeze_panes = "A4"                          # 冻结表头
ws.auto_filter.ref = f"A3:{last_col}{last_row}"   # 开筛选
ws.sheet_view.showGridLines = False              # 关网格线，更像正式件
```

## 签批栏（正式件必备）

编制 / 审核 / 会签 / 批准四栏 + 日期列。
**推荐意见、完成质量、责任认定三栏留空。**

## 渲染脚本自检

```python
# 分项加总必须等于合计
assert abs(sum(items) - total) < 0.01, f"分项 {sum(items)} != 合计 {total}"
# 占比合计必须等于 100%
assert abs(sum(pcts) - 100) < 0.1
# 行数守恒
assert len(out_rows) == len(in_rows), "行数不守恒"
```

跑不过就不出文件 —— 从根上杜绝「合计对不上」这种一眼被看穿的错。
