# 输出骨架与渲染脚本

## 文件清单

- `BD-02_废标风险自查表.xlsx` —— 正式件本体 · 5 sheet · 含签批栏
- `BD-02_缺件与补正清单.xlsx` —— 可派发 · 每条带责任人与今日可否补正
- `BD-02_金额一致性核对表.xlsx` —— 三处总价与大小写逐处比对

## sheet 结构

1. `结论摘要` —— 本次结论 / 关键指标 / 输入依据 / 人工边界 / 签批栏
2. `1.清单生成` —— 列头：核查项类别 | 本次要求项数 | 去年清册覆盖 | 本次新增或变更 | 条款出处
3. `2.材料齐套` —— 列头：核查项 | 要求 | 实际 | 结论 | 后果等级
4. `3.有效期覆盖` —— 列头：证照/证书 | 持证人 | 有效期至 | 须覆盖至 | 缺口(天) | 结论
5. `4.时间与格式细节` —— 列头：查询平台 | 查询日期 | 公告发布日 | 时序判定 | 勾选时间区间 | 结论
6. `5.金额一致性` —— 列头：序号 | 分项名称 | 单位 | 数量 | 单价(元) | 金额(元)
7. `6.留证与签批` —— 列头：优先级 | 风险项 | 条款出处 | 后果 | 处理动作 | 责任人 | 今日可否完成

## 视觉规范

正式件本体用**风格 A**（浅灰表头 `F6F8FB` + 深字 `1A2332`）；
清单类用**风格 B**（蓝底白字 `2D6CDF`）。同一个包里不要混用。

```python
INK, MUTED, GREY = "1A2332", "5A6675", "8A94A3"
HEAD_A, HEAD_B   = "F6F8FB", "2D6CDF"
RED, AMBER, GREEN = "C62F2F", "B9770A", "1E8E5A"
FONT = "微软雅黑"
```

必做三件事：

```python
ws.freeze_panes = "A4"                          # 冻结表头
ws.auto_filter.ref = f"A3:{last_col}{last_row}"   # 开筛选
ws.sheet_view.showGridLines = False              # 关网格线，更像正式件
```

## 渲染脚本自检

# 分项加总必须等于合计
assert abs(sum(items) - total) < 0.01, f"分项 {sum(items)} != 合计 {total}"

assert abs(sum(pcts) - 100) < 0.1
