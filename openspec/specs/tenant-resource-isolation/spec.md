# tenant-resource-isolation Specification

## Purpose
规定最小身份管理版本的租户资源隔离、个人数据归属和迁移契约，在复用现有 Agent 存储的同时阻止跨租户路径及默认回退，并明确首期未适配运行消费者的关闭边界，避免以管理页面完成代替业务隔离验收。
## Requirements
### Requirement: Agent 租户绑定与现有标识保持稳定

系统 SHALL 保持 Agent ID 全局唯一并为每个可访问 Agent 建立唯一租户绑定；读取 Agent 或业务存储前 SHALL 校验该绑定。租户列表和默认 Agent 选择 SHALL 只在当前租户内进行，无 Agent 时返回空列表。既有业务 session/run ID 和每 Agent 存储 SHALL 保持兼容，未绑定或绑定读取失败时 MUST 拒绝访问而不是使用全局默认 Agent。

该「只在当前租户内」的约束 SHALL 同样约束平台管理员在租户业务控制台中的读取：其可见 Agent 集合由**当前所选租户**的绑定决定，MUST NOT 因平台资格扩大为实例全量名单；未选租户时 SHALL 为无可见 Agent。跨租户的智能体管理 SHALL 经明确目标租户的专用平台入口独立验证并记录审计，MUST NOT 以业务控制台的租户选择代替该入口，也 MUST NOT 借此建立 Membership 或改变操作者的业务租户。

#### Scenario: 读取本租户安全概览
- **WHEN** 有权成员请求本租户的 Agent 列表
- **THEN** 仅返回已绑定且获准查看的 Agent 名称等安全字段，不返回 workspace、模型凭据或其他租户记录

#### Scenario: 相同会话标识属于不同 Agent
- **WHEN** 两租户的不同全局 Agent 使用相同业务 session 字符串
- **THEN** 请求仅能访问所选租户合法 Agent 下的记录，不能靠 session 字符串控制另一租户资源

#### Scenario: 缺失或损坏绑定
- **WHEN** 新租户没有 Agent，或绑定/配置读取失败
- **THEN** 无 Agent 时返回空列表，读取失败时拒绝操作，均不选取其他租户或平台默认 Agent

#### Scenario: 平台管理员读取当前租户
- **WHEN** 平台管理员在业务控制台选中租户 A 并请求 Agent 列表或相关汇总
- **THEN** 结果只包含绑定 A 的 Agent，绑定其他租户的 Agent 不出现，也不被计入汇总

#### Scenario: 平台管理员未选租户
- **WHEN** 平台管理员在业务控制台没有有效租户选择
- **THEN** 可见 Agent 为空，系统不返回实例全量 Agent，也不借用全局默认 Agent

#### Scenario: 跨租户管理经平台入口
- **WHEN** 平台管理员管理未加入租户的 Agent
- **THEN** 该操作经专用平台入口以明确目标租户执行并记录审计，不改变其业务租户，不建立虚假成员关系

### Requirement: 个人与共享资源有明确边界

系统 SHALL 在租户和 Agent 校验之后继续检查实际资源所有者与当前动作授权。本人会话、执行记录、个人记忆与私有 Agent 资产 SHALL 仅由对应 owner 访问；tenant_admin 与平台管理员的业务读取资格 MUST NOT 绕过该边界，其治理投影不包含成员私有正文。历史 Agent 资产 SHALL 默认归初始管理员私有，只有明确登记共享的 Agent 资产才可由具备读取权限的本租户成员访问。列表、文本搜索和总数 SHALL 先过滤后分页，组织部门或岗位 MUST NOT 自动扩大范围。

共享回退 SHALL 继续校验实际资产来源的私有/共享归属，不能只凭消费 Agent 的共享属性开放另一 Agent 的私有资产；来源归属缺失 MUST 拒绝读取。

归属校验 SHALL 同样覆盖**文件服务数据面**，与列表、文本搜索和记忆读取使用同一规则：以绝对路径、相对路径（含租户共享根之下的目录嵌套）或服务端签发 URL 请求文件时，系统 SHALL 解析该被寻址资源**所属 Agent** 并校验其私有/共享归属（仅属主本人放行；管理员资格不形成私有读取旁路），MUST NOT 仅凭调用者对租户的成员资格、或仅凭「路径位于调用者租户共享根内」放行同租户其他成员的私有 Agent 资产；目录列举与搜索 SHALL 同样过滤。请求自报的 Agent 标识 MUST NOT 作为授权来源。归属 MUST 取最具体的命中根；归属无法唯一确定时 MUST 失败关闭并按不可见拒绝。

#### Scenario: 同租户读取他人历史
- **WHEN** 普通成员使用同租户另一个人的会话或记忆标识请求内容
- **THEN** 系统拒绝访问，不因该成员有基础读取权限或属于相同部门而放行

#### Scenario: 历史资产不默认公开
- **WHEN** 旧工作空间登记到默认租户后新增一个普通成员
- **THEN** 该成员不能读取初始管理员私有的历史 Agent 资产，只有显式共享且满足权限的内容可见

#### Scenario: 汇总与搜索一致过滤
- **WHEN** 成员查询历史、知识或个人记忆的列表、总数及文本搜索
- **THEN** 结果和总数仅包含其获准范围，搜索不得绕过归属或隐式触发尚未开放的模型调用

#### Scenario: 共享 Agent 引用了私有共享根
- **WHEN** 普通成员从租户共享 Agent 请求的内容实际来自默认 Agent 的私有资产
- **THEN** 系统按实际来源拒绝读取，不因消费 Agent 的共享标识或同租户目录嵌套公开私有内容

#### Scenario: 管理员经共享根访问成员私有文件

- **WHEN** 非 owner 管理员经共享根、平台父目录或另一共享 Agent 定位到成员私有资产
- **THEN** 按实际资产 owner 拒绝读取，不因管理资格、目录包含关系或客户端 agent 参数放行

#### Scenario: 同租户成员以绝对路径读取他人私有 Agent 文件

- **WHEN** 普通成员（非该 Agent 属主）以绝对路径请求同租户内他人私有 Agent workspace 中的文件，无论请求声明的 Agent 参数是否为共享 Agent
- **THEN** 系统按不可见拒绝（403 或 404），不返回文件内容或路径存在性

#### Scenario: 目录嵌套不公开私有 Agent 内容

- **WHEN** 普通成员（非该 Agent 属主）以相对路径请求、或列举一个位于本租户共享根之下的他人私有 Agent workspace
- **THEN** 系统拒绝读取并在列举中省略该 Agent，不因「嵌套在共享根内」公开其内容或路径存在性

#### Scenario: 私有 Agent 仅属主可读正文

- **WHEN** 私有 Agent 的属主本人，或同租户的 `tenant_admin`，以绝对路径请求该私有 Agent workspace 中的文件
- **THEN** 属主本人返回内容、归属校验不阻止合法读取；`tenant_admin` 不因管理资格取得正文，仅经治理接口获得归属与用量元数据

#### Scenario: 归属无法唯一确定时失败关闭

- **WHEN** 被请求路径同时落在同租户两个不同 Agent 的 workspace 之下，或无法解析出唯一归属
- **THEN** 系统按不可见拒绝，不任选其一的 Agent 归属放行

### Requirement: 路径解析不回退全局存储

database 模式 SHALL 使用可信租户、Agent 绑定和已登记目录解析业务路径；缺租户、未知 Agent、非法 base 或配置损坏时 SHALL 拒绝。跨租户的规范化目录 MUST 不相等或互相包含，身份数据库和新租户目录不得处于旧租户可读根内；同租户历史父子目录关系可以保留。路径穿越、软链接逃逸和用户提供的任意目录 MUST 不能扩大访问范围。

home/global 逃逸校验的可信根 SHALL 为三个**已验证**来源的并集：部署实例根（`agent_workspace`，缺省 `~/cow`）、默认智能体工作区、operator 配置的租户数据基目录（`tenant_shared_base` / `COW_TENANT_BASE`）。当默认智能体被赋予位于实例根之下的私有工作区时，实例根 SHALL 仍作为可信根，默认租户以实例根为 `shared_root` 的解析 MUST NOT 被判为 home/global 逃逸。三个来源以外的路径（含用户家目录下未配置为租户基目录的任意目录）MUST 继续被拒绝。

#### Scenario: 跨租户回退尝试
- **WHEN** 当前租户缺少知识/记忆资产或发生存储解析错误
- **THEN** 系统返回缺失或服务错误，不读取全局默认 Agent、home、其他租户资产或共享凭据

#### Scenario: 新租户目录位于旧租户根内
- **WHEN** 创建或迁移预检发现新租户根或身份数据库会落入另一租户可访问目录
- **THEN** 系统阻止创建或切换，要求配置独立目录，不依赖前端隐藏目录解决冲突

#### Scenario: 合法根下的越界引用
- **WHEN** 内容读取经 base 参数、相对路径或软链接实际指向租户外
- **THEN** 系统在实际读取前拒绝该引用，不能把已登记根当作所有子路径均安全的证明

#### Scenario: 默认智能体拥有私有工作区时的实例根
- **WHEN** 默认智能体被赋予位于实例根之下的私有工作区（例如 `<实例根>/agents/<id>`），且默认租户的 `shared_root` 为实例根
- **THEN** 该租户的共享根解析成功并返回实例根，不产生 home/global 逃逸拒绝

#### Scenario: 家目录下的任意目录仍被拒绝
- **WHEN** 租户共享根被指向未配置为租户基目录的用户家目录子目录（例如 `~/Documents`）
- **THEN** 系统拒绝解析并返回 home/global 逃逸错误，不因实例根可信而放宽

### Requirement: 首期消费者按明确入口允许或关闭

database 模式 SHALL 仅开放已校验的身份管理、受限审计、安全 Agent 概览、获准历史和知识/个人记忆，以及分别验收的个人控制台维护、渠道配置、外部身份绑定和业务运行消费者。个人配置、目录读取与实际执行 SHALL 分别验收；模型/工具执行、文件服务、调度、SSE/poll/cancel/steer、项目、OpenAI API 和 Desktop 等入口只在各自真实切片通过后开放，未适配部分 SHALL 在服务器端关闭。

个人渠道接入与入站执行 SHALL 在凭据落点、身份验证、同租户跨用户与跨租户隔离、配额、审计及运行依赖通过后开放；个人记忆与私有工作区写入 SHALL 具备真实 owner 和路径隔离证据。启动、构造、重启及间接调用 SHALL 遵守相同条件；未知路由默认拒绝，不以 GET、菜单隐藏、接口占位或任务勾选代替授权和验收。

#### Scenario: 直接调用未开放业务接口
- **WHEN** 用户绕过页面调用尚未验收开放的预览、文件上传、旧流接口或模型执行
- **THEN** 系统返回明确不可用结果，不接受 URL 旧 token，也不因用户是租户管理员而开启未适配能力

#### Scenario: 构造或重启触发后台任务
- **WHEN** database 模式初始化 Bridge、重启通道或触发 scheduler/evolution 的启动入口
- **THEN** 已验收的渠道实例按启用状态启动，未适配消费者不会开始消费，模式切换前的旧线程已随维护重启退出

#### Scenario: 渠道接入在启用门槛未满足时
- **WHEN** 渠道接入能力所需的实际依赖切片或启用门槛未满足
- **THEN** 交付表述不声明该能力已可用，且不以页面可达代替隔离验收

#### Scenario: 渠道入站不得回退全局默认
- **WHEN** 经某渠道实例进入的消息在该实例所属租户内无法解析到有效的成员或默认智能体
- **THEN** 系统拒绝该消息并返回固定提示，MUST NOT 回退到全局默认 Agent 或另一租户的资源

#### Scenario: 外部身份绑定维护的边界
- **WHEN** 调用方访问外部身份绑定接口
- **THEN** 平台管理侧仅平台管理员可达，租户成员管理侧仅租户管理员可达，本人自助侧只接受已验证当前成员及受验证流程；三者均需逐方法登记路由策略，未登记的相邻路由 MUST 默认拒绝，不得因前缀匹配或自助资格取得管理权限

#### Scenario: 品牌和原始配置边界
- **WHEN** 客户端读取已发布的最小品牌内容，或尝试原始配置、全局日志、品牌管理写入
- **THEN** 最小公开品牌可读取，其余未适配管理入口拒绝，不将身份库审计误用为品牌文件的跨存储事务保证

### Requirement: 迁移优先登记既有数据

系统 SHALL 提供只读预检、一致备份和受信引导，将既有工作空间明确登记给默认租户及初始管理员，只补必要归属元数据，保持目录、业务 ID 和索引内容。归属或目录有歧义 SHALL 阻止切换，不自动共享、全量复制或忽略异常。迁移重复执行 SHALL 依据版本和唯一约束保持幂等。

#### Scenario: 单实例原地迁移
- **WHEN** 预检无异常且运维完成一致备份和默认租户/管理员指定
- **THEN** 原有 Agent、会话及内容路径保持不变，身份和个人归属明确，旧凭据失效且未适配消费者关闭

#### Scenario: 迁移中断或归属异常
- **WHEN** 迁移遇到未知归属、非法根，或在提交前中断
- **THEN** 系统不启用 database，保留源数据与备份；修复后重试不重复建立租户、成员或归属

### Requirement: 验收后整体启用且不静默降级

系统 SHALL 在双租户与同租户多用户隔离、关闭入口、真实身份审计及恢复演练通过后才启用运行面。高风险消费者只有通过对应的凭据、审批、配额、审计与执行隔离切片验证后才能开放。系统 MUST NOT 提供回退旧身份模式的启动路径；身份库故障时 SHALL 拒绝不安全启动或访问，按相容版本恢复或维护窗口一致快照恢复处理，MUST NOT 使用共享密码或免登录开放数据。

#### Scenario: 只有管理页完成
- **WHEN** 四页功能完成但存在可访问的越租户或未分类业务入口
- **THEN** 运行启用验收失败，不能通过关闭部分菜单宣称多租户隔离已完成

#### Scenario: 新模式发生故障
- **WHEN** 已迁移实例身份库故障
- **THEN** 系统拒绝不安全启动或访问，按相容版本恢复或维护窗口一致快照恢复处理，不自动使用共享密码开放数据

#### Scenario: 后续开放业务消费者
- **WHEN** change 请求开放模型调用、外部凭据动作或任意代码
- **THEN** 必须验证相应配额、凭据、审批或执行隔离切片并补齐消费者授权，不能凭身份管理验收直接放行

### Requirement: 业务存储在租户维度有第二道过滤

会话、消息与记忆索引的写入路径 SHALL 固化为其所属租户，检索路径 SHALL 把该租户维度纳入过滤条件，使租户隔离不再仅依赖「一个 Agent 只属一个租户」的隐式推论。该维度 SHALL 作为纵深防御的第二道门：当 Agent 归属被错误重绑、工作区被跨租户复用或索引被跨租户访问时，检索仍 MUST NOT 返回其他租户的行。

租户维度 SHALL 与既有的所有者维度（逐用户）区分登记，二者语义不重叠：所有者维度标识行的用户归属，租户维度标识行的租户归属，可同时作为过滤条件使用。

既有行在迁移时 SHALL 以其**所有者**对应用户的租户成员关系作为权威归属来源回填；MUST NOT 仅按 Agent 的当前归属回填，因为 Agent 与租户的绑定可被重绑且可能为多对多，按 Agent 回填会产生错误的隔离归属。无法确定归属的旧行 MUST 保持不可跨租户读出，且 MUST NOT 因回填失败丢失或改写原始内容。回滚 SHALL 只需停用第二道过滤，不要求恢复已回填的列值。

#### Scenario: 跨租户读取他人会话行

- **WHEN** 在工作区或索引被跨租户访问的情形下，检索带某租户维度的会话或消息
- **THEN** 结果不包含其他租户的行，且该拒绝由存储层过滤保证，不依赖调用方是否正确校验

#### Scenario: 旧行按所有者回填

- **WHEN** 迁移既有业务库并回填租户维度
- **THEN** 归属按其所有者的租户成员关系确定，与 Agent 当前绑定无关；可确定归属的行被正确回填

#### Scenario: 未启用第二道过滤时的兼容

- **WHEN** 第二道过滤被停用（回滚）
- **THEN** 读写沿用原语义不报错，且不影响既有会话、消息与记忆的可见性

### Requirement: 默认智能体解析校验绑定存在且启用

租户默认智能体的解析 SHALL 校验目标 Agent 的绑定存在且处于启用状态；当配置的默认 Agent 不存在、已解绑或已停用时，系统 SHALL 按确定性顺序在本租户内回退到合法 Agent，MUST NOT 回退到进程全局默认或其他租户的 Agent。回退 SHALL 记录可诊断原因。

#### Scenario: 默认 Agent 指向已解绑对象

- **WHEN** 租户配置的 `default_agent_id` 指向不存在或已解绑的 Agent
- **THEN** 解析在本租户内按确定性顺序回退到合法 Agent，不落到进程全局默认或其他租户的 Agent

#### Scenario: 本租户无任何合法 Agent

- **WHEN** 租户内不存在任何绑定且启用的 Agent
- **THEN** 解析失败并拒绝相关操作，不借用其他租户或平台默认 Agent

#### Scenario: 默认 Agent 被停用

- **WHEN** 租户默认 Agent 被停用后发起需要默认 Agent 的操作
- **THEN** 解析回退到本租户内的合法 Agent，或明确拒绝，均不产生跨租户执行

### Requirement: 入站渠道附件按渠道实例绑定 Agent 解析落点

渠道入站消息的附件（文件、图片、语音、视频等媒体）在解析与下载时 SHALL 以**该渠道实例已登记的绑定 Agent** 解析工作区路径，与回复处理路径使用同一归属来源。解析 MUST NOT 依赖调用时刻的 ambient 身份，也 MUST NOT 在该身份缺失时回退到进程全局默认智能体的工作区。

承载媒体下载的渠道实例 SHALL 在进入下载前把自身登记的 Agent 归属与租户归属施加为本次解析的身份作用域。该作用域 SHALL 覆盖长连接与回调两类接收路径，二者 MUST 得到同一落点。

渠道实例未登记绑定 Agent 时（传统单实例部署）SHALL 保持既有解析语义不变，MUST NOT 因此产生新的失败模式或拒绝既有可用渠道。

该归属无法解析、或绑定 Agent 不可用时，系统 SHALL 失败关闭并记录可诊断原因，MUST NOT 以全局默认智能体、其他租户或平台默认 Agent 的工作区代替。

#### Scenario: 租户渠道实例的文件落在绑定 Agent 工作区

- **WHEN** 一个绑定租户智能体 A 的渠道实例收到用户上传的文件，且该实例身份作用域已生效
- **THEN** 文件被保存到 Agent A 的 workspace 之下的临时目录，且不落在进程全局默认智能体的 workspace

#### Scenario: 图片与文件使用同一归属规则

- **WHEN** 同一渠道实例先后收到图片与文件两类媒体
- **THEN** 两类媒体落在同一个绑定 Agent 的 workspace 之下，不出现一类落对、另一类落到全局默认智能体的分歧

#### Scenario: 长连接与回调路径落点一致

- **WHEN** 同一渠道实例分别经长连接接收路径与回调接收路径收到同一份文件
- **THEN** 两条路径都把文件保存到该实例绑定 Agent 的 workspace 之下，落点相同

#### Scenario: 传统单实例渠道保持既有语义

- **WHEN** 一个未登记绑定 Agent 的渠道实例收到媒体附件
- **THEN** 解析沿用既有语义并正常完成下载，不因本次变更被拒绝或改落到其他 Agent

#### Scenario: 归属缺失时失败关闭

- **WHEN** 渠道实例登记的绑定 Agent 不存在、不可用或归属无法唯一确定
- **THEN** 系统拒绝该次媒体落盘并记录可诊断原因，不把附件写入全局默认智能体或其他租户的 workspace

#### Scenario: 租户智能体可读到自己收到的附件

- **WHEN** 租户智能体随后在其自身执行隔离边界内读取该附件路径
- **THEN** 读取成功，不产生跨租户或越界拒绝
