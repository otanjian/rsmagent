## ADDED Requirements

### Requirement: 入站渠道附件按渠道实例绑定 Agent 解析落点

渠道入站消息的附件（文件、图片、语音、视频等媒体）在解析与下载时 SHALL 以**该渠道实例已登记的绑定 Agent** 解析工作区路径，与回复处理路径使用同一归属来源。解析 MUST NOT 依赖调用时刻的 ambient 身份，也 MUST NOT 在该身份缺失时回退到进程全局默认智能体的工作区。

承载媒体下载的渠道实例 SHALL 在进入下载前把自身登记的 Agent 归属与租户归属施加为本次解析的身份作用域。该作用域 SHALL 覆盖长连接与回调两类接收路径，二者 MUST 得到同一落点。

渠道实例未登记绑定 Agent 时（传统单实例部署）SHALL 保持既有解析语义不变，MUST NOT 因此产生新的失败模式或拒绝既有可用渠道。

该归属无法解析、或绑定 Agent 不可用时，系统 SHALL 失败关闭并记录可诊断原因，MUST NOT 以全局默认智能体、其他租户或平台默认 Agent 的工作区代替。

#### Scenario: 租户渠道实例的文件落在绑定 Agent 工作区

- **WHEN** 一个绑定租户智能体 A 的渠道实例收到用户上传的文件，且该实例身份作用域已生效
- **THEN** 文件被保存到 Agent A 的 workspace 之下的临时目录，且不落在进程全局默认智能体的 workspace

#### Scenario: 图片与文件使用同一归属规则

- **WHEN** 同一渠道实例先后收到图片与文件两类媒体
- **THEN** 两类媒体落在同一个绑定 Agent 的 workspace 之下，不出现一类落对、另一类落到全局默认智能体的分歧

#### Scenario: 长连接与回调路径落点一致

- **WHEN** 同一渠道实例分别经长连接接收路径与回调接收路径收到同一份文件
- **THEN** 两条路径都把文件保存到该实例绑定 Agent 的 workspace 之下，落点相同

#### Scenario: 传统单实例渠道保持既有语义

- **WHEN** 一个未登记绑定 Agent 的渠道实例收到媒体附件
- **THEN** 解析沿用既有语义并正常完成下载，不因本次变更被拒绝或改落到其他 Agent

#### Scenario: 归属缺失时失败关闭

- **WHEN** 渠道实例登记的绑定 Agent 不存在、不可用或归属无法唯一确定
- **THEN** 系统拒绝该次媒体落盘并记录可诊断原因，不把附件写入全局默认智能体或其他租户的 workspace

#### Scenario: 租户智能体可读到自己收到的附件

- **WHEN** 租户智能体随后在其自身执行隔离边界内读取该附件路径
- **THEN** 读取成功，不产生跨租户或越界拒绝
