# 首批表格视口滚动

2026-10-03。本轮实现和验证均为隔离方式，没有操作真实 Chrome、OpenCode 或 SAP；完整分页和真实控件兼容性仍由任务 5.3/5.7 验收。

模型读取返回最多四个表格的观察 ID、角色、视口位置/尺寸、有限行列索引及方向能力，不复制行正文。`sap_page_scroll(revision, table, direction)` 只接受最新快照中的表格；direction 为 up/down/left/right，不接受额外参数、任意坐标、像素量、selector 或脚本。

当前自动范围仅限无模态的 ME21N 创建页面、带稳定 native ID 的可见 grid/treegrid。纵向固定 320px，横向固定 240px。模型不能扩大步长或替换浏览器。固定 DOM 适配器在派发前核对标题、表格身份/标签、视口及行列窗口，检查最多九个候选点；只选同一表格内未被遮挡的点，避开输入、选择、可编辑单元格和其他交互控件。嵌套 frame 的可见性、遮挡及缩放不满足时拒绝，不为寻找目标随意 focus/scrollIntoView。

成功回读要求同一表格在请求方向上的 scrollTop/scrollLeft 或可见行列索引窗口移动，连续两次表格状态一致。通知、业务文本 hash、其他轴或任意页面 revision 变化都不能充当成功；未观察到效果时返回 `scroll_not_observed`，不自动重试。结果登记为 display_change，仍为 `business_validated: false`。取消/未确认效果沿用 bridge 的 unknown 状态和暂停规则。

48,000 字符快照预算先裁表格行正文，并优先保留少量可滚动表格的身份和视口，避免大页面丢失后续行的入口。模型摘要仍有数量上限和 omitted 标记；此机制不表示已支持 SAP 全部虚拟表格、隐藏滚动组件或下一页按钮。

隔离验证：新增 `test_sap_workbench_scroll.py` **69 项通过**；effects/controls/runtime/scroll 合计 **168 项通过**；固定 DOM Node **17 项通过**，其中九项为新增滚动与预算检查。测试覆盖非法方向/参数、旧快照、未知表格、模态、身份/视口变化、人工接管、错误方向与无关变化、输入/覆盖层避让、frame 变换及具体稳定回读。数量与最终全套重叠，不相加。

待真实验收的范围包括 SAP 特定虚拟表格的滚轮响应、完整分页和在当前 OpenCode 来源下的工具显示。本轮不将这些项目勾选完成，也不开放保存或过账。
