## 本轮实际修复

- 画面 handler 被取消时，先停止并等待它拥有的帧、输入和状态子任务，再释放连接。
- Chrome 启动线程不能被协程取消；节点保留启动 Future，启动线程结束后关闭进程。关闭任务归节点所有，重复取消调用者不会切断回收。
- 并发进入工作台时，gateway 的多个请求等待同一个启动线程，不再建立相互覆盖状态的事件循环。
- Manager 拥有启动任务直到部分节点清理完成，关闭时等待启动中的节点；尚未执行首步就取消也释放容量。分配成功但响应未交付时释放 attached 占用，按原 grace 保留重连或立即回收。
- 配置、刷新或关闭后的旧会话响应不能重新挂载双栏；旧请求的 finally 和结束失败不能改写后续会话状态。恢复列表请求已放弃时不继续创建/恢复会话。
- 填写前的固定脚本在 focus 前后检查页面、可见字段、原值、类型和完整 frame 焦点链；普通字段序号及 SAP CBS 行列语义必须一致。选择项需当前实际可用，原生输入不得静默归一化。
- 表格点击激活同样核对原页面和 CBS 单元格语义及坐标命中。填写回读不能仅凭复用的字段 ID 与相同值报成功，要求页面、字段类型、标签和行列一致。
- 自动填写最多 300 个 UTF-16 单元，与完整可观察值范围一致。长文本在任何激活/写入前拒绝，模型指引明确不得截断用户文本，用户可人工录入。
- 桌面独立数据根此前缺少 OpenCode Web 静态文件，现已补齐同一份既有构建并逐文件核对，五项离线检查通过，见 [桌面资源记录](desktop-assets.md)。没有复制配置、数据库、凭据或 Chrome profile。
