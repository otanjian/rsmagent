# 提交审批摘要的截断边界

2026-10-04，本轮仅修复场景私有审批消费者；没有调用真实 SAP、创建模型请求或注册保存执行器。

## 问题与修复

`browser_service/dom.py` 的固定观察器最多保留字段值 300 个 UTF-16 单元、字段标签 200 个单元，以及每张可见表格 20 行、每行 16 格、每格 160 个单元。页面级 `truncated` 不覆盖全部嵌套内容截断。两个不同业务值若只有被省略的后缀不同，现有摘要可能相同。

`backend/commit.py` 现在在正式审批登记前拒绝上述边界及更长值、达到行/列上限的表格、显式截断表格和非法行/单元结构。长度按 JavaScript 的 UTF-16 单元计算，涵盖补充字符。低于上限的值仍参与摘要；变更仍使审批失效。达到上限也可能是完整原值，此时保守拒绝，不能根据截断快照猜测完整内容。

这一修复不把可见快照认作完整业务单据。完整采购订单及必要只读核对仍需专用适配器，当前 `submission_adapter=None`；6.3 和 6.6 保留未完成，自动保存/过账关闭。读取到单据号、MCP 返回一般表查询结果或已有审批都不能替代完整业务匹配。

## 验证

`tests/test_sap_workbench_commit_bounds.py`：13 passed（6.81 秒）。真实临时平台 IAM 用于验证拒绝发生在审批创建前，SAP 回调未派发。覆盖普通字符和补充字符的字段/标签/表格截断边界、行列上限、结构错误、低于上限的摘要变化，以及不同原值具有相同可见前缀的情况。

新增测试与后续完整套件结果见 [本轮合同收尾](next-contract-closeout.md)。该证据只证明消费者边界，不证明真实提交或恢复验收。
