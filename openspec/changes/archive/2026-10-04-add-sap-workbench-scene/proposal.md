## Why

当前 SAP 数据分析场景和 OpenCode 编码会话尚未组成可共同操作同一 SAP Web GUI 会话的工作台。需要新增一个以可交互 SAP Web GUI 为主界面、通过右下角按钮展开嵌入式 OpenCode Web 的场景应用，使用户通过对话完成页面跳转、单据输入和结果核对，同时将改动集中在新场景及必要接入口，尽量不修改其他程序。该展示方式按用户 2026-10-04 的最新要求替换原双栏方案，会话与工具链路保留。

## What Changes

- 新增 `sap_workbench` 场景，产品名称为「SAP智能工作台」，工作台会话默认显示 SAP 主界面及右下角「AI 对话」按钮；点击展开页内对话，收起保留原 iframe、输入及回复。Web 为首个交付面，桌面端通过既有 Web 工作台复用，不新增原生桌面浏览器驱动。
- 点击 SAP 工作台卡片除「配置」按钮以外的区域直接新建场景会话；「配置」只打开表单。配置/能力不可用时显示原因，重复点击不重复分配，打开不自动调用模型；历史恢复仍通过独立入口。
- 页面内的对话区域复用 OpenCode 原生监听器、嵌入协议与既有全局/项目配置；保留全部原生模型、智能体、工具、技能、命令及 MCP，OpenSpec 使用项目已有四项技能与 `/opsx-*` 命令，不复制技能或覆盖项目文件。对话面板支持全屏/还原且不重载 iframe；场景绑定经授权的 coding 智能体配置，由 OpenCode 承担模型、对话、技能和工具执行。不新增智能体类型，不进入普通智能体场景激活/模型执行路径。
- 当前主界面直接嵌入 SAP Web GUI，由使用者原生操作；不创建独立 Chrome。远程浏览器同页自动控制保留为后续目标，两个跨域 iframe 不自动互相控制。
- 新增场景会话与 OpenCode 会话、SAP 浏览器会话的持久关联，覆盖身份校验、幂等创建、重连、暂停/恢复、分叉后的重新绑定、撤权与资源回收。
- 新增场景专属连接配置入口：维护 SAP Web GUI 地址及登录方式，选择既有 coding 配置并展示其 OpenCode 服务地址和项目绝对目录，提供分项连接检测。按用户后续要求，两个 MCP 端点固定，SAP 账号密码先由场景配置维护并加密保存，Web GUI 单独登录；统一登录留待后续。平台连接 OpenCode 的服务凭据保持独立，项目文件、工具正文和前端响应不保存明文 SAP 密码。
- 新增场景专属 SAP 页面工具适配与业务指引，实现读屏、交易跳转、输入、表格与弹窗操作、结果核验；保存等有副作用动作按现行风险和审批规则执行，超时后的不确定结果不得自动重做。
- 先验证实际 OpenCode 前后端构建、会话 API 与工具执行路径。优先将适配包保存在新场景目录并经已有扩展入口加载；不把旧 MCP 接口的存在当成 V2 可用证明。如确需修改 `rsmcode` 核心，须先形成具体改动清单与配套 change，经用户确认后另行实施。
- 新能力默认关闭；按依赖切片和真实联调证据开放，故障不回退普通智能体。保持其他场景、普通聊天和既有编码会话行为。

## Capabilities

### New Capabilities

- `sap-workbench-scene`：SAP 主界面与页内对话场景、SAP/OpenCode/MCP 连接配置与凭据引用、就绪状态、Web/Desktop 入口、最小改动边界和渐进启用。
- `sap-workbench-session-binding`：平台身份、场景会话、OpenCode 会话与浏览器实例的唯一关联、授权、恢复和工具上下文传递。
- `sap-webgui-browser-control`：同一浏览器的可视交互与工具操作、SAP 控件适配、人工接管、副作用结果核验和执行资源生命周期。

### Modified Capabilities

- `scene-workbenches`：为无子场景的 `sap_workbench` 增加专用工作台分发例外，保留其他场景现行分发。
- `scene-application-console`：场景卡片和选择器选择 SAP 工作台时打开专属场景会话，不创建普通对话、不调用通用场景激活或自动发送 greeting。

## Impact

- **代码边界**：新增业务、前端、服务、工具适配、部署说明集中在 `Scene/sap_workbench/`；允许场景目录、分发、静态资源清单、HTTP 路由及其既有鉴权注册的必要增量。仅当复用现有 OpenCode 组件需要时允许窄范围挂载接缝，不能重写现有编码视图。具体允许与禁止修改范围见 design。
- **明确不纳入**：普通 Agent Registry/Bridge/执行循环改造、第三种智能体类型、其他场景重构、通用浏览器工具改造、渠道/调度改造、重建 OpenCode MCP/插件体系、全业务交易覆盖；不复制 SAP 凭据、客户资料或现有 OpenCode 工作目录数据。
- **数据唯一归属**：现有身份系统拥有平台身份、权限及正式审计；既有 coding 配置/关联拥有默认项目、平台编码会话及摘要；OpenCode 拥有对话正文与工具记录；SAP 拥有业务单据；新场景拥有连接配置与版本、关联扩展、控制状态及操作证据索引。SAP 密码密文存在场景专属凭据表，复用已有加密实现，不修改身份库。场景持久表遵守 `cj-sap_workbench-*` 命名，浏览器服务不另建身份系统。
- **依赖**：沿用 `opencode-coding-agents`、`opencode-embedded-chat`、`opencode-session-sync`、`scene-activation`、`rbac-authorization`、`credential-management`、`audit-log`、`action-approval`、`resource-quota` 的现行契约。普通执行器的 `execution-isolation` 与既有外部共享 OpenCode 例外保持原范围，旧受管工具的限制仍适用于旧画面模式。按用户明确要求，当前本机原生 iframe 模式直接沿用 OpenCode 权限及模型调用路径；平台仍校验专属实例所有者，但不能宣称原生工具受场景提交开关、场景配额或审批桥约束，生产授权/计量验收仍保留。
- **跨 change/仓库协调**：`rsmcode/opencode` 是外部构建与适配验证依赖，不在本 change 默认编辑范围；进行中的 `harden-production-readiness` 仅按实际所需的身份、凭据、隔离和部署切片复用证据，不等待整份 change 或代替它完成任务。未具备切片时保持相应能力关闭。
- **交付边界**：提案已进入 apply。本机双栏、原生 OpenCode 对话、SAP 页面读取与交易跳转、MCP 只读调用已有分项现场记录，字段填写以对应记录的版本和范围为准。按用户已确认的后续选择，两个固定 MCP 使用场景配置中的加密凭据，Web GUI 独立登录；仅 `https://sap.goodsap.cn:44300` 的后台 SAP 连接适用已授权的定向 TLS 例外，不改变 Chrome 信任或其他来源的证书校验。统一登录、完整业务提交、生产权限/审批及远程部署属于后续完整目标，不作为本轮本机交付前置。SAP/OpenCode 实际操作检查继续暂缓，普通“继续”请求不恢复这些检查；历史记录不冒充后续代码已经现场重测。自动保存/过账未开放，未实现或未验收能力不标作完成；进度及实际证据见 tasks.md 与 evidence/。
