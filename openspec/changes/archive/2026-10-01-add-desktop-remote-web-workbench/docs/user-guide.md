# 桌面远程工作台 — 用户指南（草稿）

Change: `add-desktop-remote-web-workbench` · task 17.4

> 能力开关默认关闭。下列步骤描述**开关打开后**的预期行为；当前部署若未见
> 「本地目录」入口，属于正确不可用，而非故障。

## 配置服务器与登录

1. 打开桌面客户端 → **远程连接**（或设置中的服务器配置）。
2. 填写精确的 **HTTPS** 源（不可带路径/查询；不可用 HTTP）。
3. 探测通过后登录；客户端会引导原生会话并为内嵌 Web 引导子会话。
4. 同时只允许一个活动远程服务器与账号；切换前会销毁旧作用域。

## 切换租户

在 Web 壳内使用既有租户切换。切换前宿主会 `suspendLocalContext`，旧目录授权失效，需重新选择目录。

## 目录授权 / 撤销

1. 在本地文件面板选择目录（只读、按需传输说明会出现在系统对话框中）。
2. 取消选择不会产生授权。
3. **断开**只停止本机读取；服务器上已物化的副本不会因此删除。
4. 退出登录或完全退出客户端会清除内存中的活动授权；候选目录可保留在本机。

## 本机目录的可用条件（`fix-desktop-local-context-and-tool-calls`）

- **入口**：仅当宿主已打开本机文件能力时，文件夹菜单才出现「选择本机目录」；普通浏览器没有该入口。
- **确认后才生效**：选中的目录要经服务端登记设备、注册 workspace 并创建绑定（含授权版本）后才显示为可用。
  取消、或绑定未完成时，界面保留原状态并说明原因，不会只凭新目录名宣称成功。
- **每次请求重验**：聊天/重新生成请求只携带非秘密引用（binding、workspace、授权版本），不含绝对路径；
  服务端按当前身份、Agent 与业务会话重验。引用无效或已撤销时该轮**明确报错**，不会改用服务器默认目录。
- **刷新与重启**：本机目录不会被自动恢复，需要重新选择；记住的候选目录也不会自动成为授权。
  切换会话、Agent、租户或退出登录会清除当前引用。
- **等待与失败**：读取会等待已配对的客户端返回真实结果（读取等待至多 60 秒；客户端当前离线时至多 30 秒）。
  失败码含义：`device_offline`（客户端未连接）、`deadline_exceeded`（客户端未在期限内完成）、
  `cancelled`（本轮取消）、`stale_context` / `grant_revoked`（目录已撤销或被替换，需重新选择）。
  结果被截断或分页时会如实标注，不会显示成"已全部扫描"。
- **模型把工具调用写成文本时**：本轮以工具协议错误结束，**没有任何工具被执行**，界面显示失败原因；
  用既有入口重新生成即可，系统不会自动重放或改写历史。

## 按需传输

- 不会在授权时上传整个目录。
- Agent / 工具需要文件时才会分块上传；传输可取消。
- 源文件在传输中被修改会报版本变化，不会交付混合内容。

## 另存为

页面只能请求保存服务器产物；落点由原生对话框决定。取消或未确认覆盖时，已有文件不变。

## 本地解析（CSV/XLSX）

阶段三 B 能力，默认关闭。开启后摘要/样本会发往服务器；失败不会自动改为全量上传。

## 退出与托盘

- 默认关闭窗口为**驻留**（可在设置改为关闭即退出）。
- **开机启动默认关闭**，需用户显式开启。
- 完全退出会释放远程视图、设备连接与内存目录授权。

## 故障恢复

1. 设置 → 导出诊断（不含 token / Cookie / 绝对路径 / 文件正文）。
2. 休眠/唤醒后客户端会要求重验会话；未知结果的业务写入不会自动重发。
3. 若提示 `feature_unavailable`，表示部署开关或依赖未开放。
