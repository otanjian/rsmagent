| 三 A：桌面体验与发布 | 13–14 | 托盘、恢复、系统通知、签名升级与诊断 | 阶段一；涉及文件时还需阶段二；L01–L08 |
| 三 B：固定本地解析 | 15–16 | 有限 CSV/XLSX 处理器及受限执行环境 | 阶段二＋L09–L12；默认关闭，部署可选，实现包含 |
| 交付与恢复 | 17 | 迁移演练、用户/运维文档、实际证据索引 | 随各阶段执行，全部完成后才归档 |

## 核心实现边界

- 远程模式复用服务器当前发布的 Web，现有本地 React/Python 模式保留；不迁移已有本地业务数据。
- 原生 PKCE Bearer 只在主进程内存；内嵌 Web 使用独立关联的 HttpOnly Cookie，逐请求检查配对撤销。
- 客户端目录根绝对路径只在本机；服务器使用结构化文件引用，按需取得本人任务副本。
- 只读授权不含自动改写本地文件；另存为由用户选择目标并确认覆盖。
- V1 不含任意本地代码、双向同步、全盘索引、完整离线 Web 或多主机 SQLite HA。

## 开始实施

在仓库根目录使用：

```text
/openspec-apply add-desktop-remote-web-workbench
```

规划校验命令：

```bash
openspec validate add-desktop-remote-web-workbench --strict
openspec status --change add-desktop-remote-web-workbench
```

OpenSpec 产物齐备表示可以开始实施，不表示任务、测试或生产开关已完成。任务中的 `evidence/` 文件由执行实际测试后创建，本设计包不预填通过结果。
