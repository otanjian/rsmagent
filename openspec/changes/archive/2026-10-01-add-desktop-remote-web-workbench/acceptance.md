# 验收与交付矩阵

本文件是程序员与测试人员的执行清单，不是验收结果。每项实施证据记录提交 SHA、服务器/客户端版本、OS/架构、配置、测试身份、命令、实际结果与脱敏附件。当前全部待执行。

## 1. 验收身份与测试环境

准备 A/B 两个真实测试租户，U1 同属 A/B、U2 仅属 A；两人在 A 共享 Agent 但有不同用户文件目录，另外各有一个私有 Agent。准备租户管理员 TA、无任何 Membership 的平台管理员 PA、无租户普通用户 U0、强制改密账号 UP。所有数据为合成数据，不使用生产客户文件。

准备 Windows 10/11 x64 与 macOS arm64/x64 实际发行包。每个承诺 OS/架构至少一份安装和关键链路证据；UI 自动化用 Playwright Electron 驱动新建独立测试配置目录，浏览器测试使用与桌面同一服务器/账号。测试不复用操作者个人登录状态。完整功能矩阵在 Windows 11 x64 与 macOS arm64 必跑，其余目标平台跑认证、上传下载、路径 helper、生命周期、安装升级，差异明确记录。

生产环境启用需要可信 HTTPS；测试可使用安装到测试机信任库的测试 CA，不得启用忽略证书选项。身份库、应用和 gateway 故障注入使用专用测试副本。

## 3. 阶段一认证与容器门槛

| ID | 故障/攻击/兼容场景 | 通过条件 |
|---|---|---|
| A01 | 原生 PKCE code 重放、错误 verifier/state、过期、撤销 | 不签发额外会话，loopback 监听释放，无秘密日志 |
| A02 | 普通 Cookie 值放入 Authorization 请求 Web 引导 | 无 native 来源记录则拒绝 |
| A03 | 两个 worker 同 bootstrap ID；引导响应丢失后新 ID | 只交付一次旧秘密，新引导撤销旧子会话，不出现多活动 link |
| A04 | 父会话撤销，旧子 Cookie 尚未过期 | 所有业务/文件请求拒绝；不只是 auth/check 拒绝 |
| A05 | Web 退出、壳退出、密码变化、退出时断网 | 配对双向失效；离线立即封锁且不谎称完成服务端撤销 |
| A06 | U1(A)→U1(B)→U1(A)，旧响应迟到 | generation 阻断旧数据；独立浏览器标签不切换 |
| A07 | U1→U2、服务器 S1→S2、重启应用 | 不复用 Cookie/Bearer/grant，内存分区销毁，本地候选不自动授权 |
| A08 | iframe、弹窗、预览 HTML、同源非 shell、外站导航调用桥 | 每种均无原生读盘/进程/凭据能力，不能仅用同源判定放行 |
| A09 | TLS 错误、HTTP 地址、含用户信息/前缀路径地址 | 明确拒绝，无降级，无认证重定向泄漏 |
| A10 | 缺少协议、旧 Electron、未知 bridge major | 明确不兼容或单项关闭，本地模式可用 |
| A11 | 秘密扫描 | 源码测试输出、日志、IPC、URL、诊断、renderer storage 不含测试 token/code/Cookie；用已知哨兵值检查 |
| A12 | 本地模式回归 | 原 React、Python 启动/退出、原生导入校验、原资产代理可用；用户数据未迁移 |

阶段一开启门槛：W01–W20 全行有真实结果，A01–A12 通过，目标平台安装运行证据齐备；能力关闭必须有真实服务端依据，不允许为了矩阵通过临时隐藏坏页面。

## 4. 阶段二文件与传输门槛

| ID | 场景 | 通过条件 |
|---|---|---|
| F01 | 原生选择目录、拒绝/取消、再次连接历史候选 | 只有明确授权才读取，服务器不出现根绝对路径 |
| F02 | U2/TA/PA 猜测 U1 device/workspace/binding/transfer | 各接口、WS 与工具均拒绝，无目录存在性泄漏 |
| F03 | Mac symlink、Windows junction/reparse、UNC、硬链接、设备文件 | helper 实际拒绝，不只字符串单测 |
| F04 | 校验后替换根/中间组件/目标文件，循环竞争测试 | 不读出逃逸哨兵文件；行为为固定原句柄或拒绝 |
| F05 | 中文、空格、长名、大小写与 Unicode 差异 | 合法名正确处理，不折叠两个不同实际文件或产生逃逸 |
| F06 | 目录超过 10,000 项、文本搜索超时 | 分页/限额/truncated 可见；UI 不阻塞 |
| F07 | 网关断开、双网关抢占租约、旧 epoch 结果 | 同 ID 去重；旧连接 fenced，不重跑业务任务 |
| F08 | 读取、分块、commit 前撤销 Membership/工具授权/本地 grant | 下一动作与最终交付拒绝，未发布字节不可预览 |
| F09 | 文件传输中修改、替换、删除；最终摘要不符 | 报版本/完整性错误，不发布混合或损坏副本 |
| F10 | 同 offset 重传/异内容、取消与完成竞争 | 同块幂等、冲突拒绝，DB 只有一个终态 |
| F11 | 多 worker 并发抢占额度、quota 存储故障 | 额度不透支，故障不 fail-open，取消释放预留 |
| F12 | 改名后 DB 提交前崩溃、审计失败、reconciler 重跑 | 未 committed 不可见；恢复不丢已确认副本、不重复计量 |
| F13 | 服务器读取客户端 Excel/PDF | 真文件按需物化，现有技能消费本人服务器路径，运行记录含源版本 |
| F14 | 原生另存为取消/同名/非法文件名/目标目录替换 | 源文件不变，无静默覆盖、路径逃逸或半文件成功 |
| F15 | 暂存清理、运行中引用、手动删除已发布输入 | 回收正确范围与额度，不删本地源文件、不打断有效引用 |
| F16 | 定时任务引用离线客户端文件 | 明确不可用，已物化获权副本可按原任务执行 |
| F17 | 审批适用性 | 普通另存为留下不适用依据；任意本地写回/脚本请求拒绝，不能把用户对话框当企业审批 |

性能基线在测试机配置一并记录：100 个在线空闲设备连接；20 个同时列目录请求；2 个并行 512 MiB 文件传输。新增文件通道的桌面 RSS 增量目标低于 128 MiB（不含 Chromium 页面基线）；服务端每传输缓冲随窗口有界。记录同机业务健康请求 p95 相对无设备基线退化不超过 20%，若环境噪声不可判定需重测，不直接标通过。传输过程 UI 输入/取消操作响应目标 200ms 内。

## 5. 阶段三门槛

| ID | 场景 | 通过条件 |
|---|---|---|
| L01 | 关闭窗口驻留/退出、开机启动偏好 | 用户选择生效，不默认开启自启动，完全退出设备离线 |
| L02 | 休眠 5 分钟后恢复、网络切换 | 重验身份、源版本和租约，未知写入结果不重发 |
| L03 | 通知去重、点击旧账号/租户/服务器通知 | 不泄漏正文，只在正确身份进入获准会话 |
| L04 | 原生通知权限拒绝与恢复 | 功能可解释降级，站内任务状态不丢失 |
| L05 | 新服务器/旧客户端、旧服务器/新客户端 | 必需协议拒绝；可选动作独立关闭 |

| L07 | 未保存编辑和传输期间安装更新 | 先处理未保存状态与连接，不静默破坏输入 |
| L08 | 真实签名安装、升级、回退 | 每承诺平台都有记录，升级不迁移业务数据或复活 grant |
| L09 | CSV 正常/编码错误、XLSX 多表/公式缓存 | 输出 schema、source hash 与实际内容一致，缓存值语义清楚 |
| L10 | 宏伪装、外部连接、压缩炸弹、超量行列/输出 | 固定 worker 拒绝或有界终止，不执行宏/网络/任意代码 |
| L11 | Worker 网络访问/文件越界探针、资源超限、取消 | 实际平台约束生效，进程终止和快照清理可靠 |
| L12 | 本地解析被撤权、失败回退、诊断导出 | 不交付旧上下文结果，不自动上传原文件，诊断无秘密/路径/正文 |

阶段三 A 的 L01–L08 可先验收发布。三 B 的 L09–L12 与真实处理器依赖证据缺失时必须保持本地解析关闭，其实现任务不能勾选；整个 change 不能以三 B“部署可选”为理由宣称全部任务完成。

## 7. 数据迁移、恢复与开关矩阵

测试空库、已有用户和任务的数据库、迁移中断后重跑、客户端旧配置升级、服务器回退及备份恢复。恢复后所有关联父子会话/连接租约失效，源文件和既有业务数据保持。旧服务端不认识父子语义时，回退脚本必须先撤销配对。

逐一测试所有新开关关闭、仅阶段一打开、阶段一二打开、三 A 打开、三 B 打开、只打开三 B 但前置关闭。前置缺失时实际 API/WS/工具都拒绝，不能只隐藏按钮。对审计/配额/身份依赖实施故障注入并记录不同错误码。

## 8. 交付完成定义

每个编号任务需能对应代码、测试或真实证据；不能把文档勾选当实现。阶段证据汇总所有矩阵行的通过/失败/不可用及原因；存在权限泄漏、旧上下文复活、数据损坏、假成功或未解释的功能缺失即不开放该阶段。最终交付包含用户操作说明、运维网关/反向代理说明、签名发布说明、开关回退步骤及已知兼容范围。
