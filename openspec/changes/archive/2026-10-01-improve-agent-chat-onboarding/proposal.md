## Why

用户从智能体卡片进入对话后，虽然能看到名称和问候语，但不容易知道如何开始；建议入口是通用内容，位于大输入框下方，点击也只填入草稿。本次只解决首次使用引导：说明智能体能做什么、如何使用，并提供可直接提问的示例。

## What Changes

本 change 仅面向 Web 端普通单智能体。Desktop 客户端和 OpenCode 类智能体（`agent_type=coding`）完全不在范围内，不安排其功能、适配、兼容验证或回归验收。

- Web 普通单智能体空会话显示头像、名称、简短自我介绍、使用说明及最多四个专属建议问题。
- 自我介绍继续使用现有 `greeting`；仅新增可选 `usage_hint` 和 `suggested_questions` 两个档案字段，在现有 Web 概况表单中编辑。
- 建议问题放到输入框上方并标明「点击即发送」。输入框为空、无附件且当前会话空闲时，点击后直接调用现有发送流程；已有草稿或附件时禁用问题入口并提示先发送或清空，避免覆盖用户输入。
- 缩小标题、留白和输入框默认高度，Web 宽屏问题双列、窄屏单列。复用原输入框、工具栏和菜单，保留主题及品牌行为。
- 欢迎内容静态展示，不自动调用模型或写入历史；首问后沿用原消息页。有历史的会话不重复展示介绍。
- 保留六组文案示例，按已确认智能体通过现有编辑页面或 API 配置，不开发预设安装、批量迁移或恢复工具。

本期不包含欢迎页实时预览、独立使用说明面板、工具栏重排、发送管道重构、专用重试/对账状态机、动态推荐或模型生成文案。已有草稿时仍能点击问题并独立发送的行为也不纳入本期。

## Capabilities

### New Capabilities

- `agent-chat-onboarding`: 普通智能体的静态介绍、使用说明、专属建议问题与直接提问。

### Modified Capabilities

- `agent-digital-employee-profile`: 两个可选展示字段的读写、Web 编辑和旧载荷兼容。
- `workbench-appearance-preferences`: 普通智能体首页的内容顺序、问题数量、点击语义与紧凑布局。

## Impact

- **数据归属**：沿用 Agent Registry 档案及原智能体 ID、tenant/owner 绑定；不增加配置表、欢迎消息或独立缓存。省略新字段的旧请求不得清空已有值。
- **后端**：`agent/registry.py`、`agent/admin.py` 与 `channel/web/fork/handlers/agents.py`，补齐现有创建、更新、复制及使用投影中的两个字段；复用原校验、revision 和权限。
- **Web**：在实际装载的欢迎渲染、建议问题点击、概况表单、CSS 和文案位置做局部修改，不将前端模块迁移或聊天基础设施改造作为本 change 的任务。
- **兼容**：仅保留 Web 普通智能体旧档案和现有管理 API 的省略字段语义。场景应用、多智能体及 Channel 不扩展功能；不新增跨客户端兼容工作。
- **依赖**：沿用已存在的智能体启动、授权、发送、历史及后台运行能力，验证本次接入不回归即可；不依赖其他进行中的 change，也不重新建设其责任域。
- **交付边界**：当前只修正规划；业务实现及验收由后续 apply 完成。
