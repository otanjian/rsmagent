## ADDED Requirements

### Requirement: Desktop 容器退出后回到原生登录入口

Desktop 容器 SHALL 在确认当前 Web 会话退出后，由受信宿主完成原生退出、容器及本地资源清理，并让本地壳呈现已有登录或连接入口。重新进入 SHALL 复用现有原生授权及 Web 配对，保留本能力规定的凭据隔离、改密和租户 gate；容器 MUST NOT 使用普通 Web 密码登录作为原生重新登录的替代。

退出 SHALL 保持单次提交，Web 与宿主退出串行完成。失败 SHALL 明确提示重试，服务端撤销未确认时 MUST NOT 宣称已退出或允许新账号继续桌面业务。宿主 SHALL 让本地壳感知退出开始和结束，最终状态不依赖已销毁文档的回调。

#### Scenario: 同账号在同一进程重新登录
- **WHEN** 用户从桌面工作台退出，随后以同一账号重新进入
- **THEN** 旧会话结束，经原生授权和新 Web 配对恢复工作台，无需重启；具有相应工具权限时可重新选择目录并读取文件

#### Scenario: 换账号不继承本地授权
- **WHEN** 账号 A 退出后，用户在原生授权流程中登录账号 B
- **THEN** 界面以 B 的权威身份为准，A 的目录 grant、设备连接、项目绑定和预览不可复用，B 需重新选择目录

#### Scenario: 退出失败并重试
- **WHEN** Web logout 未确认，或宿主无法确认原生会话撤销
- **THEN** 对应页面或本地壳显示退出未完成并允许重试，旧目录访问停止；不能显示普通 Web 登录成功或允许新授权绕过未完成的退出

#### Scenario: 容器销毁后本地壳接续
- **WHEN** 宿主接受退出并销毁了发起调用的 Web 文档
- **THEN** 本地壳仍能显示退出结果；成功后本地模式显示原登录入口，远程模式显示可重新连接的入口，均不保留旧连接成功状态

#### Scenario: 授权取消或配对失败
- **WHEN** 用户取消重新授权，或原生授权后 Web 配对/挂载失败
- **THEN** 显示可重试状态，配对成功前不宣称工作台连接成功，不自动重放之前的目录或工具操作

#### Scenario: 重复退出和迟到回调
- **WHEN** 用户重复发起退出，或旧容器/请求回调在清理后到达
- **THEN** 同一退出操作合并执行，退出期间及失败阻断期间不能重连，旧回调不能恢复旧身份或影响后来建立的会话

#### Scenario: 非受信文档调用退出桥接
- **WHEN** 子 frame、预览、未登记来源或旧文档调用宿主退出动作
- **THEN** 宿主按既有 sender、来源及文档代际规则拒绝，动作及其结果不传递可复用凭据

### Requirement: Desktop 目录身份错误具有可执行恢复入口

Desktop SHALL 在打开目录对话框前拒绝已知原生会话缺失或退出阻断；后续绑定仍 SHALL 接受既有服务端身份与权限验证。确定的会话失效 SHALL 显示本地化重新登录入口，沿用容器退出及原生重新登录流程，MUST NOT 只暴露 `not signed in` 或要求重启应用。

目录操作 SHALL 继续使用既有文档/选择代际校验；退出或换账号后，旧选择及绑定结果 MUST NOT 成为新身份的目录。登录恢复 MUST NOT 修改角色/工具授权，也不能将权限不足、租户资格、网络或设备错误统一解释为未登录。

#### Scenario: 普通 Web 已登录但原生会话缺失
- **WHEN** 历史故障状态中的用户选择本地目录，页面有普通 Web 登录但主进程无原生会话
- **THEN** 不打开目录对话框，提示桌面登录连接已失效；用户可结束该 Web 会话并通过已有原生入口在同一进程恢复

#### Scenario: 绑定时服务端确认会话失效
- **WHEN** 原生内存状态通过检查，但绑定请求确认当前会话已失效
- **THEN** 不显示目录选择成功，释放本次临时授权并呈现重新登录入口，不自动重试原工具操作

#### Scenario: 目录对话框中退出
- **WHEN** 目录对话框或绑定仍在进行时用户退出，之后旧操作返回
- **THEN** 旧结果被丢弃且临时 grant 失效，新账号界面不能显示或使用该目录

#### Scenario: 身份恢复但缺少工具授权
- **WHEN** 原生授权和 Web 配对有效，但当前成员没有 `builtin:client_files` 执行授权
- **THEN** 工具调用仍得到具体权限拒绝，不能通过重新登录扩大权限，也不能把该拒绝误报为未登录

### Requirement: 所选桌面输入进入本轮模型上下文

服务端验证后的本地目录引用 SHALL 同时用于本轮工具与模型上下文。只读输入 SHALL 指引模型通过 `client_files` 列举及读取，二进制文件通过既有 materialize 取得服务器分析路径；MUST NOT 把服务器工作区的空结果解释为所选本地目录没有文件。该上下文 MUST NOT 修改 cwd、扩大工具权限或覆盖已有本地执行项目路由。

#### Scenario: 自然语言查询所选目录
- **WHEN** 用户选择客户端目录后询问当前项目文件或数据
- **THEN** 模型请求包含当前来源说明，读取结果来自该目录的实际工具结果；不能只扫描服务器后要求用户再次提供已选文件

#### Scenario: 切换或清除选择
- **WHEN** 下一轮切换到其他目录、服务器项目或不再携带本地引用
- **THEN** 工具和模型上下文同步更新或清除旧引用；提示词重建失败也不能丢失当前有效来源说明

#### Scenario: 本地读取工具不可用
- **WHEN** 当前目录已选中但本轮没有可用的 `client_files`
- **THEN** 模型明确说明当前无法读取，不宣称目录为空，不绕过权限访问其他目录

### Requirement: 本地桌面后台接通现有设备命令网关

本地桌面后台 SHALL 随 Web 服务启动及停止既有设备网关，共用身份服务和命令队列。网关 SHALL 仅监听回环地址，并通过现有 metadata 返回实际端口。宿主 SHALL 只信任已登记本地后台的端口信息，MUST NOT 从远程页面指定任意连接目标、跟随发现重定向或免除 Bearer、目录和工具授权。

#### Scenario: 桌面自然语言请求下发读取命令
- **WHEN** 已授权用户在本地模式选择目录后，通过对话发起文件读取
- **THEN** 命令经真实网关到达当前桌面设备，设备回传结果并形成命令终态；仅目录 UI 显示成功不足以证明读取成功

#### Scenario: 本地后台重启或远程模式
- **WHEN** 本地后台重启导致网关端口改变，或当前连接为远程来源
- **THEN** 本地连接重试时重新发现实际端口；远程连接继续使用已配置来源的同源网关，不使用该本机端口

#### Scenario: 握手或重连不撤销目录选择
- **WHEN** 同一有效目录授权下设备连接 epoch 因握手或重连而改变
- **THEN** 只读文件面板继续保留当前目录；实际绑定、grant 或选择代际改变才结束该 watch，设备命令仍按自身 epoch 校验

#### Scenario: 二进制文件按当前租户传输
- **WHEN** 模型要求 materialize 所选目录中的 Word、Excel 或 PDF 文件
- **THEN** 既有 reserve、chunk、commit 请求均携带 broker 当前租户头；缺少租户时不发送，服务端继续核对命令和传输归属，不接受模型覆盖租户；传输成功后同一次工具调用返回该用户、租户、智能体及命令对应的实际服务器分析路径
