## Context

动机见 `proposal.md`。对齐基线为 master `48c0d79c36146950667f8d1884ab823deae62305`。源码已确认：上游面板通过现有列表函数读取、分组和分页；没有保存展开偏好时默认收起，新建对话会打开面板并插入前端临时行。

rdai 已经有完整列表、项目操作、类型标识、行内编辑、统一新建菜单以及 `_addOptimisticSessionItem()`。当前差异集中在可见入口和渲染：面板未装载，主导航只取 5／10 条，完整页采用宽双行列表。原方案将这些现成能力重新规划成模块迁移、双状态同步和归档修复，扩大了本次范围。

## Goals / Non-Goals

**Goals:**

- 复用 master 列表呈现和菜单密度，将列表放入主导航，聊天时全部授权历史可滚动访问。
- 复用 rdai 现有业务路径，保留搜索、归档、coding、刷新与权限，避免界面改变造成回退。

**Non-Goals:**

- 除统一「历史会话」名称外，不改业务分区、后端接口、存储、聊天时间线或独立 Desktop renderer。
- 不修归档弹窗超过 50 条的问题，不实现多页锚点回填、双列表缓存、草稿管理或新的偏好系统。
- 不建立通用覆盖解析器、缺包降级系统、全站迁移工具或新的 feature flag；不将其他 change 的归档作为前置。

## Decisions

### 1. 历史内嵌在主导航菜单下

`session-panel` 挂在主导航「历史会话」按钮下，菜单本身承担标题和展开／收起，不再占用中间一栏，也没有独立关闭按钮或历史遮罩。底部保留「已归档」「查看全部」，聊天新建统一使用主导航。原聊天顶部历史按钮展开同一主导航及历史列表，不产生第二份列表。

聊天时展示内嵌列表；从其他页面点击历史入口，走既有离页保护返回聊天。进入完整历史页或管理页面时临时隐藏，回到聊天恢复偏好。桌面折叠导航时隐藏列表，历史入口会先展开导航。手机及窄屏只使用现有主导航抽屉，选择／新建会话后关闭主导航，保留历史展开偏好。

复用账号／租户作用域偏好，无偏好默认收起。恢复历史展开偏好不自动打开手机主导航抽屉；关闭抽屉或折叠主导航时不读取不可见历史。没有历史权限时不显示或读取。

### 2. 一份活动列表，切换展示位置

完整历史页与聊天面板互斥，因此共用既有 `session-list` DOM、`_sessionItems`、分页、请求序号和操作函数。在两处放置挂载位置，导航通过正常离页／编辑保护后移动同一个列表节点及加载／错误／重试状态区，并切换内嵌／完整页展示类；不能把错误提示留在已隐藏的完整页。完整历史页的新对话控件及菜单固定留在该页；聊天时使用主导航的新建入口。两处沿用 `NEW_CHAT_SURFACES`，不移动控件、不制造重复 ID 或第三套候选逻辑。

仅增加当前展示位置标记。完整页搜索词保留在其原搜索控件；切到面板时使用空查询并失效旧请求，回到完整页时读取保留的搜索词，从第一页刷新。进入面板时不得误读隐藏搜索框。允许切换视图或普通刷新回到第一页；普通列表重命名成功只更新该行及缓存，保留分页和滚动，搜索结果或有延后刷新时仍重新读取；不维护两套结果／滚动缓存，不追踪多页锚点。

`loadSessionList()`、`_fetchSessionPage()`、`_sessionGroups()`、`_refreshHistoryList()` 继续提供唯一业务实现。仅把可见性判断扩展为“完整页可见或聊天面板打开”，保留原身份和编辑／拖动保护。渲染函数按展示位置使用 master 紧凑行或现有完整页双行布局；标题、owner、类型标识和操作处理共用。

### 3. 本次只增加面板展示代码和必要接线

内嵌模板及样式从 master 列表取基线，放入 `templates/fork/layout/session-panel.html`、`static/css/fork/sessions.css`；新增的开关／挂载展示逻辑可放入 `static/js/fork/views/sessions.js`，不复制现有全部 sessions 实现。现有列表、搜索、重命名、删除、coding 和流处理继续留在当前唯一实现处，只作必要调用修改。

按 `web-console-frontend-modules` 保留本切片来源指纹与逐处差异记录；单体剩余部分仍为已存在的显式基线，不以本次 UI 对齐完成整站拆分。复用当前页面装配与版本戳，只接入本组件所需引用／单项覆盖，不构建全站可选覆盖回退。不得同时加载上游和 fork 同名符号；未迁移业务不得在新文件中再声明一份。

| 对齐区 | 处理 |
| --- | --- |
| 列表紧凑行、分组和头像布局 | 采用 master 来源并适配主导航宽度，复用 rdai 已有数据与分组函数 |
| 主导航／新对话菜单密度 | 采用 master 间距与字号，保留 rdai 内容与配色 |
| 搜索、归档、coding、owner、生命周期刷新 | 保留现行实现，仅连接新展示位置 |
| 当前单体与其他在途模块 | 不作整体迁移，不覆盖无关改动 |

### 4. 密度对齐保留明确参照，取消像素验收工程

使用 master 模板工具类和 `sessions.css` 作为样式来源，清理会覆盖它们的现有宽松规则；完整页样式限定在完整页，避免重新放大面板行或隐藏图标。主要参照如下，字体导致的最终行框差异以实际浏览器对照为准，不强制改写上游行高以迎合推算值。

| 区域 | master 参照 |
| --- | --- |
| 主导航 | 展开宽 208px，品牌区高 56px；普通菜单字 14px、上下 padding 8px／左右 12px、图文 gap 12px |
| 分组与导航留白 | 分组字 12px、组间距 4px、子项缩进 8px；导航内边距来自原模板 |
| 内嵌历史 | 跟随 208px 主导航宽度，无独立头部；行字 13px、padding 7px 6px、上下 margin 1px、头像 20px；更多按钮占独立位置 |
| 新对话下拉 | 字 13px、padding 7px 9px、gap 9px，菜单 padding 6px |

密度适用于工作台、控制台对应导航项及新对话菜单；菜单名称、业务分区、品牌配色及折叠宽度保持。继续沿用已有键盘和触摸可达性，长名称可省略但能查看全名。不新增 ±2px 门禁、独立密度偏好、全配色／字号／设备排列组合。

### 5. 新建、操作与刷新使用现有机制

复用现有新建流程及 `_addOptimisticSessionItem()` 接回 master 即时新对话行，不新增草稿注册表或持久化。仅当前刚新建的未发送会话显示临时项，成功保存后列表同键替换，不写后端空记录；依赖已保存行的管理操作不对临时项发送请求。删除最后会话后自动准备的新空对话仍不插入临时项。

分组遵循现有服务端 `group_mode`，项目数量按 master 显示已加载记录数；置顶、项目管理、成员头像、coding 标识及所有权沿用当前功能。归档入口位于内嵌历史底部，但归档弹窗逻辑和其既有 50 条限制不在本次修改。恢复后记录按正常完整列表排序可达，不再按前 5 条预览判断。

保存确认、后台完成、标题更新及重新打开面板继续走既有刷新；原 owner、一次性标题消费、身份 epoch、编辑／拖动保护和归档不复活行为不重做。这些现成保护通过既有回归确认，无需先交付其他 change。

## Risks / Trade-offs

- [共用节点时查询串到面板] → 展示切换失效旧请求；面板空查询，完整页读自己的搜索框。聚焦测试覆盖两者切换。
- [样式与初始化接线错误] → 样式按容器限定，检查实际装载、唯一 ID／声明和真实首屏，不只检查仓库中未装载文件。
- [紧凑行影响操作] → 保留键盘／触摸入口，实际检查长标题、成员头像及行操作；必要时修正局部样式。
- [重命名导致分页回退] → 普通列表成功后原地更新；搜索或已有延后刷新才重查，不引入多页锚点系统。
- [窄栏操作遮挡] → 会话操作复用唯一更多菜单，按钮与标题处于正常布局，不增加悬浮按钮层。
- [语言切换漏掉内嵌列表] → 可见性刷新同时覆盖内嵌列表和完整页，编辑中延后重绘。

## Migration Plan

1. 核对固定 master 来源与实施时实际装载，只修改本切片；保留其他任务正在修改的菜单、memory 模块和身份保护。
2. 完成面板与菜单密度接线后，运行受影响的现有回归，新增测试只覆盖展示切换、超过一页及新建接线等改变的行为。
3. 在实际 rdai 页面检查桌面内嵌位置／滚动以及手机主导航抽屉；检查主要行操作、搜索来回、长标题、深浅主题与既有布局开关。不建立新的截图／像素比较基础设施。
4. 沿用静态资源版本机制发布；回退本次模板、样式与接线即可，无数据库迁移或额外回退演练。归档前校对重叠规范及 Purpose；其他 change 的归档顺序不是实施阻塞条件。

## Scope Review

| 原方案扩大项 | 审核后修正 |
| --- | --- |
| 归档超过 50 条的分页与恢复补位 | 移出本次；只保留归档入口与既有操作 |
| 通用资源覆盖、缺包回退、装载工具升级、全历史模块拆迁 | 收敛为面板组件装配与必要调用，来源记录和唯一实现要求保留 |
| 面板和历史页两套缓存／分页／同步 | 共用一个活动列表，切换时重新查询，完整页保留搜索词 |
| 多页锚点、刷新回填 | 普通刷新仍读首屏；重命名仅更新已加载行 |
| 新草稿管理与跨 change 归档前置 | 复用既有临时行函数，其他 change 不构成实施前置 |
| ±2px 门禁、多视口及全组合验收 | 来源样式对照＋必要桌面／手机抽查，保留业务回归 |
| 未保存偏好时桌面默认打开 | 修正为 master 默认收起，新建或显式展开后打开 |

实施与实际验收记录见 `evidence/verification.md`；业务代码继续保留唯一实现，面板只负责展示接线。
