## Context

当前 SAP 是现有 Electron 容器中的跨域 iframe，OpenCode 是嵌入的同一 Web 会话。普通页面脚本不能直接读取 SAP，宿主可以对自己管理的确定 frame 执行固定提取器。本 change 只补这条只读链路，首版只支持 macOS。

`runtime.py` 的 `dispatch` 已提供授权、动作账本、额度和审计；`navigation.py` 已提供单 pending 请求及超时回执；`workbench.js` 已有 heartbeat、挂载状态和 OpenCode 会话 attach；`host-bridge.ts` 已校验主 frame、来源与文档代次。本变更沿用这些机制，只补读取请求、宿主提取和结果回执。

## Goals / Non-Goals

**Goals:**
- 在当前 OpenCode 会话调用一次工具，读到左侧 SAP 的标题、字段当前值、表格、选中项、活动页签和消息，包括未保存输入。
- 普通获授权成员可用，目标始终来自现有场景绑定；返回有界内容和真实限制。
- 保留现有 SAP 人工操作、OpenCode 体验和数据归属。

**Non-Goals:**
- 本 change 不包含 Windows、截图/OCR、独立可访问性树或通用浏览器自动化。
- 不新建读取租约/续租服务、动态工具协商系统、浏览器、对话库、快照库或模型偏好存储。
- 不做自动点击、填写、滚动、翻页、提交及 SAP 登录/证书策略改造。

## Decisions

### 1. 一个工具、一条现有通道、一个宿主方法

`sap_page_read → 现有场景桥/dispatch → heartbeat 下发读取请求 → 当前工作台 → Electron 固定提取 → read_result 回执 → 原 OpenCode 工具调用`。

项目插件的 `sap_page_read` 使用空参数对象，按现有方式从 `context.sessionID` 解析调用所属会话；模型不能传目标、URL、选择器或脚本。工具权限沿用项目默认 deny、场景会话 allow 的现有配置方式，执行时仍由后端校验所有权。无需修改 OpenCode 的通用工具注册机制或模型设置。

在原生 iframe 的 `dispatch` 分支仅增加页面读取的只读入口，保留同一授权、动作账本、配额和审计。调用标识须区分每次工具调用；心跳重复投递同一请求不重采集，用户之后的新一次读取不能命中旧快照。读取失败按只读失败记录，不进入提交审批或不确定写入流程。

复用 heartbeat，下发字段至少包含请求 ID、场景 generation、当前挂载标识及截止时间，回执携带同一关联和结果。后端沿用单个 pending Future 的模式：同时只有一次读取，其他请求返回忙碌；超时/取消后立即清理，不做任务队列或结果缓存。前端仅为回执重试在本次请求期间暂存结果，结束即丢弃。

### 2. 复用现有绑定，补足当前视图检查

平台复用现有服务/会话到场景的归属检查。工作台在原有 heartbeat 携带当前挂载标识和宿主是否支持读取的布尔状态，宿主支持条件为 macOS 且存在固定方法。新旧版本按方法有无降级，不建设多方版本协商框架。

宿主沿用 `checkSender` 核验当前容器、主 frame、来源及文档代次，再核对 SAP frame 的实际父子关系、场景标识和允许来源；frame 名称只用于定位。SAP/OpenCode 子 frame 和弹窗没有宿主桥权限，`webSecurity` 等现有设置不变。

后端只需在现有 runtime 内存中保留当前活跃挂载信息及 pending 请求，不新增凭据、租约 token、表或续租 API。若同一绑定出现两个活跃视图，明确返回视图冲突并提示关闭多余视图，不能按最近焦点或第一个响应选目标；挂载存活沿用 heartbeat 生命周期。不同绑定独立工作。

派发与交付复用现有权限重检；返回首页、关闭/刷新、绑定变化、注销和撤权使在途请求失效。OpenCode 正常新建/切换沿用现有经服务端校验的 attach 流程，关联成功后即可读取，无需再点击“绑定读取”；没有合法关联的独立或分叉会话不能借用旧目标。回执永远对应原调用。

### 3. 先把当前 SAP 的 DOM 读清楚

宿主定位当前 SAP 内容 frame，执行一次固定、无副作用的提取。复用 `browser_service/dom.py` 的标签、控件值和表格逻辑，移除 DOM 标记写入；不派发事件、不聚焦、不滚动、不执行来自页面或模型的代码。只适配目标 SAP 页面实际使用的内容 frame；未覆盖的嵌套内容报告缺口，不扩展为通用跨站 frame 爬取器。

读取当前显示的页面/页签中已渲染的 DOM，排除隐藏页签、隐藏控件及认证秘密。表格保持表头与行列关系；难以结构化的区域可返回经过同样过滤和限长的可读文本。无法读到的自绘内容明确说明，不在本 change 加第二套 AX 或视觉提取管线。

范围标记为 `rendered_dom`：允许包含当前已渲染但在滚动视口之外的行和输入框完整值，必须说明这不是截图逐像素转录；未渲染的虚拟行和其他页不在结果内。没有可靠总数时不猜测完整行数，也不将可读 DOM 行数当作整个订单行数。

每个目标文档在一次同步提取中形成结果；采集前后检查 frame 是否被替换或导航。普通同页 DOM 更新不做全页指纹、MutationObserver 稳定等待或“任意变化即失败”。返回实际采集时间；如需多个 SAP 文档则保留各自来源，不能宣称跨文档原子快照。无法确认目标仍是原文档时拒绝交付。

### 4. 最小结果和资源边界

工具结果包含 `capturedAt`、`source: sap_page_dom`、`scope: rendered_dom`、`title`、`fields`、`tables`、`selection`、`activeTabs`、`messages`（含弹窗文本）及 `limitations`。缺失项留空并说明，超限明确标记截断；内部请求/文档标识用于校验，无须全部暴露给模型，也不新建 snapshot ID 生命周期。

初始约束采用一次 15 秒端到端超时、每绑定 1 个 pending、结果 JSON 最多 128 KiB，另设提取器内部遍历上限以防大 DOM 阻塞。宿主限制生成规模，后端校验回执大小和类型；参数在现有部署配置/常量中维护，不开放给模型。测试后可调数值，无需扩建额度系统。

沿用既有错误格式，新增当前路径缺少的语义即可：不支持、未绑定/视图冲突、需要 SAP 登录、页面已替换、忙碌、超时或提取失败。离线通过 heartbeat 状态及超时反映。读取失败不返回旧快照，不阻断人工 SAP 操作或后台业务查询。

平台/桌面仅短期持有结果，交付正文仍由同一 OpenCode 会话保存。动作账本和审计仅记请求、状态、大小等元数据；不得落字段正文、密码、cookie、令牌或页面 URL 中的秘密。识别为认证页面时直接返回需要登录。页面文本是不受信业务数据，不能变成工具指令。

### 5. 一个开关，先验收 macOS

增加默认关闭的 `desktop_sap_page_read_enabled` 开关，使用现有配置机制，无需新建配置表或迁移数据。开关开启且 macOS 宿主方法可用时，当前工作台报告可读；Windows、普通 Web 和旧客户端返回不支持，现有其他功能照常。

测试必须贯通真实 macOS 桌面、项目插件、平台和 SAP 页面，不能只用模拟回执证明可用。保留必要的隔离、撤权、超时和旧结果测试；不把截图链路、Windows 现场验证或整份企业运行时改造作为本次前置。

## Risks / Trade-offs

- DOM 读取不能覆盖所有 SAP 自绘控件，也不能给出完整业务单据 → 明确缺口；只有真实使用需要时再提截图/OCR change。
- 动态页面读取代表采集时刻，不保证后台状态或跨文档原子一致性 → 返回时间和来源，文档替换时丢弃，后台数据查询继续单独使用。
- 共享项目工具与多个视图可能读错目标 → 保留服务端所有权、当前挂载、宿主发送方及 frame 检查，冲突时拒绝猜测。
- 当前 Electron 构建对 SAP 嵌套 frame 的支持需要实测 → 先验证当前 macOS 和采购订单页面，不声称 Windows 已通过。

## Migration Plan

1. 核对当前 macOS 上实际 frame 和真实插件通道；确认复用的授权/审计/配额路径，不重建这些基础能力。
2. 在开关关闭状态接通 pending 请求、宿主提取及插件工具，补关键测试。
3. 用当前 SAP 采购订单验证订单号、供应商、行项目、未保存输入、页签和消息，普通成员完成真实端到端读取后开启 macOS 功能。
4. 回退只需关闭开关、取消 pending 并清理临时结果；保留原会话、SAP 页面和历史。重新开启后新调用重新采集。

不迁移数据库、聊天正文或模型设置，不重建浏览器。Windows 后续在环境具备时单独适配/验证，不影响本 change 完成。归档按新增 requirement 合并，避免覆盖相关活动 change 的其他规范修改。

## Open Questions

没有待用户决策的产品问题。实施前只需确认当前 macOS 构建的 SAP 内容 frame 和工具通道；这决定具体提取位置，不改变本 change 范围。DOM 覆盖不足应如实列为已知限制，不静默扩展截图、OCR 或通用自动化。

### 当前用户字段补充（2026-10-06）

沿用固定 DOM 读取与单次回执，增加 `currentUser: {account, client, systemId, source: sap_session_ui, sourceDocument} | null`。只在明确会话状态区域识别标签/只读字段，或采用 SAP WebGUI 明确标注当前用户/Client 的 ABAP 字段提示；系统状态窗口只采用使用数据区，排除数据库用户。沿用认证过滤；不读取 cookie、钥匙串、全局 SAP 私有对象或 URL 身份参数。嵌套文档必须与 SAP 根文档同源；冲突返回 null，同账号的多个文档选信息最完整的一份，保留来源，不拼接不同文档字段。后端只增加可选字段的定长校验，保持旧客户端兼容。
