## Context

动机见 `proposal.md`。现有卡片、弹窗、连接服务、身份库、审计与工具派发均可复用；以下为待实施设计。

- `channel/web/static/js/external-connections.js` 已有卡片、弹窗和未保存退出处理，保留在途 change 的测试状态投影。
- `integrations/external/service.py` 管理连接归属、版本与审计；`auth/object_scope.py` 区分可见与可管理，私有 owner 检查先于管理员例外。
- `integrations/external/tools.py` 与 `ConnectionRuntime.invoke` 是工具投影和最终派发的共同接入点。
- 平台模板和覆盖的 `id/effective_id` 不同；空工具白名单表示“不额外限制”，不能表达空分配。

## Goals / Non-Goals

**Goals:**

- 默认已分配列表、搜索添加、逐项移除、统一保存，支持数千智能体。
- 复用现有权限，按增删差量保存，运行时兑现分配。
- 按连接渐进配置，给一个连接分配无需先迁移整个租户。

**Non-Goals:**

- 个人邮箱分配、智能体详情反查页、远程知识库/文档级授权及内容同步。
- 租户级模式、映射导入与维护窗口流程、版本绑定游标、响应重放协议。
- 重建角色/凭据/审计机制，或开启尚未开放的 MCP 等业务执行切片。

## Decisions

### D1. 弹窗与权限

弹窗默认只加载当前可见已分配项，行内提供「移除」。输入名称或 ID 后按需显示候选及「添加／已添加」；已分配列表也可按名称/ID 筛选。两类列表默认每页 20、最多 100，内容区滚动、加载更多，不下载全集。

增删暂存在草稿中，搜索/翻页不丢失，相反操作抵消。后端返回 `assigned`，尚未加载页中的已分配对象不能重复添加。显示信息仅含获准名称、类别/可见性和短 ID。复用取消、Esc、切换租户时的未保存处理及焦点管理，保存成功只局部更新本卡片。

读取要求连接可读及智能体可见；变更同时要求连接管理资格和目标智能体管理资格。不可见对象不进入列表、数量或错误详情；可见但不可管理的对象动作禁用并说明原因。身份从认证上下文解析，保存时重验全部目标，任一非法目标整笔拒绝。停用智能体沿用现有管理资格，配置分配不会启用它。

首期只提供 tenant 路由，包括租户 MCP/ERP/OA 和获准继承的平台 MCP。平台模板的分配归消费租户，无租户平台目录不提供跨租户分配。个人邮箱保留原行为和入口。

### D2. 关系表和连接级状态

在 `identity.db` 增加以下数据，由外部连接服务统一维护：

- `external_connection_agent_assignments`：主键 `(tenant_id, logical_connection_id, agent_id)`，带必要创建审计信息及查询索引。
- `external_connection_agent_assignment_sets`：同一租户/逻辑连接键，仅保存 `configured` 和独立 `revision`。

不增加租户模式或迁移批次。租户自建连接用自身 ID；平台模板和覆盖用基础模板 ID，各租户集合独立。独立 revision 避免分配变更增加连接配置 version、使测试状态过期。关系不写入 AgentProfile、工具白黑名单或秘密。

复制智能体不复制分配；删除智能体成功后清理关联并更新相关分配版本，复用已有删除事务和保护。

### D3. 按连接首次配置，不阻塞弹窗

| 状态 | 页面与运行行为 |
| --- | --- |
| 存量连接 configured=false | 显示「沿用原权限」，弹窗可配置；运行沿用原授权 |
| configured=true，有分配 | 显示当前可见数量；仅已分配且原授权允许的智能体可用 |
| configured=true，实际分配为空 | 无智能体可用，不能回退为原权限 |

“当前可见 0 个”只表达操作者视角，不能据此推断实际集合为空。未配置连接的空列表也不表示无人能用。首次配置显示提示：“当前沿用原权限；保存后仅已分配智能体可使用，可能影响其他正在使用本连接的智能体。”保存本身表达该配置意图，不增加确认流程。

首次保存即使增删均为空，也允许明确配置为空；关系变更、configured=true 和 revision 同事务提交。新建受管连接、平台模板首次新授予某租户时初始化为已配置且空分配。配置修改、停用/启用、撤销后重新授予同一模板保留原分配状态；普通接口不能恢复 configured=false。

常规数据库迁移只为已有连接及已有平台消费关系初始化未配置状态，不推测任何 Agent 分配。运行中缺失应有状态行或查询失败属于异常，拒绝调用，不能动态创建“沿用原权限”的旁路。

### D4. 普通分页与三个接口

| 方法与路径 | 输入／输出 |
| --- | --- |
| `GET /api/external-connections/tenant/{id}/agent-assignments` | q、page、page_size；返回列表、可见数量、分页信息、configured、revision |
| `GET /api/external-connections/tenant/{id}/agent-candidates` | 非空 q、page、page_size；返回候选及 assigned、动作资格 |
| `POST /api/external-connections/tenant/{id}/agent-assignments` | expected_revision、add_agent_ids、remove_agent_ids |

服务端每次先按身份过滤，再搜索、按规范化名称＋ID 排序和分页。空搜索不返回候选全集。不保证跨页快照，也不因无关目录变化强制重翻第一页；并发变更时支持刷新，前端按 ID 去重，保存检查 revision。

复用请求内批量身份查询和 roster；不预建额外搜索索引，测量发现瓶颈再优化。禁止逐行鉴权查询或全量下载前端过滤，卡片计数也按批量解析。搜索约 300ms 防抖，忽略旧查询、旧弹窗与旧租户响应。

### D5. 差量、事务和版本校验

前端维护 pendingAdd/pendingRemove，只提交明确增删，不能用当前可见列表全量替换。一次最多 100 项变更；非法 ID、同一 ID 同时增删或超限整笔拒绝。未加载/不可见关联不受普通保存影响。

事务核验 expected_revision 及当前连接/目标资格，修改关系与 configured，增加分配 revision，并复用现有脱敏审计。版本不符返回 409，写入或审计失败回滚；已经配置且无实际变更时可返回当前状态。

不要求幂等键、负载摘要或重放原响应。请求中禁用保存按钮。响应丢失时显示“结果待确认”，重新读取当前获准状态供用户核对，不自动重发、不以重读结果断言原请求必然成功。冲突或失败保留草稿，刷新后由用户决定是否重试，不静默覆盖。

### D6. 复用共同运行时入口

首期范围的受管连接先确认状态行：未配置存量连接沿用原授权，已配置连接要求受信上下文的当前 Agent 在关系中。该判断同时接入工具枚举和最终派发，与原调用者权限、租户开放范围、连接状态、工具白黑名单及风险/配额取交集。

模型不能用参数换 Agent，缺失身份或查询异常拒绝。移除后的旧会话、重连、排队调用在下次派发前重验，不重建会话系统。独立配置/测试及真正的非 Agent 消费者保留原规则。

按连接分配不记录工具快照；新增工具继续由原执行授权及 Agent 工具范围决定，不引入新工具确认流程。未开放的 MCP `tools.call` 等动作继续关闭，分配成功不替代执行验收。

### D7. 合法删除连接时清理附属分配

停用保留关系，启用仍检查当前权限；平台撤销租户可用性继续阻止模板及覆盖执行。

删除先走原连接删除权限和真实活动引用检查（如默认连接、运行依赖等）。合法删除逻辑连接时同事务清理其分配和状态、记录审计；不逐项要求隐藏 Agent 管理权，也不返回其名称/ID/数量。分配本身不新增删除阻塞。删除确认文案说明会解除该连接全部智能体关联，智能体及其数据保持不变。

这是连接所有者终止该资源使用的动作；普通“移除某个分配”仍要求目标管理资格。删除覆盖而恢复继承仅切换有效配置，逻辑连接仍在，分配保留。

## Risks / Trade-offs

- 存量首次配置会收窄使用范围：弹窗明确说明，只影响当前连接，取消不改变行为。
- 普通分页不提供快照：每页重验权限、按 ID 去重，保存时校验版本，支持刷新。
- 网络结果不确定需用户核对：保留草稿后重新读取，避免持久响应重放设施。
- 分配成功可能仍不能搜索：分别表达原执行可用状态，本 change 不放开业务调用。

## Migration Plan

1. 常规 schema 迁移增加两张表，为现有逻辑连接及消费租户填入未配置状态；新连接/新消费关系创建时原子初始化已配置状态。无全租户切换、映射导入或专项维护窗口。
2. 在现有备份/恢复机制中纳入两张新表，验证恢复不丢失配置状态；向已支持分配的数据库导入缺少状态的旧备份时，不能静默覆盖已配置限制，沿用现有不兼容恢复拒绝方式。不另建备份流程。
3. 上线前完成新增权限、保存、运行时和页面验证；复用原审计/凭据/消费者证据，不重复整体验收。UI feature flag 如需关闭仅隐藏入口，已保存限制继续生效；回退不支持分配的运行时前停用受影响连接。使用与升级说明见 `evidence-5/usage-and-upgrade.md`。
4. 本期不改变个人邮箱、内置工具、本地知识及未迁移旧 MCP 配置路径。已迁移受管连接仍不得回退旧文件绕过分配。
