## Purpose

定义本次生产修复的功能保持、目标平台验收、固定候选产物和发布回滚证据要求，使本地检查与实际交付分支采用同一准入规则，明确真实通过、失败和暂缓项目，防止通过关闭能力或缩减验证范围获得形式上的通过。

## ADDED Requirements

### Requirement: 修复同时通过功能保持与安全验收

发布候选 SHALL 固定修复前已启用且实际有权使用的能力清单，并针对受影响功能同时完成真实正向运行和关键负向安全验证。用户、角色、资源分配、feature flag 和已有合法网络/凭据依赖 MUST NOT 为使测试通过而被关闭、收紧或替换为更高权限主体。已有未启用能力不要求借本次扩大开放；原本无权或故障时拒绝仍须正确。

#### Scenario: 普通成员完整执行链路
- **WHEN** 原有获权普通成员运行代表性脚本技能、前后台命令、文件输出、授权外部访问和取消操作
- **THEN** 正向结果与安全边界同时通过，不以平台管理员结果替代普通成员验收

#### Scenario: 通过关闭能力消除失败
- **WHEN** 候选通过隐藏入口、撤权、关闭开关、禁网或跳过原有正向用例消除失败
- **THEN** 发布准入仍判定未通过，并保留该功能缺口为未完成任务

### Requirement: 统一检查入口覆盖实际交付候选

系统 SHALL 提供可本地执行并可接入实际交付仓库的统一检查入口，覆盖受影响后端回归、路由/模块接缝、前端行为、renderer 类型检查和构建、生产镜像启动与关键业务冒烟。检查 SHALL 保留真实退出状态，失败或必需依赖缺失不得伪装为通过；已知夹具或契约错误 SHALL 修正其原因并保留原安全属性。实际发布必须对应同一源码候选和产物记录。

#### Scenario: 构建成功但类型检查失败
- **WHEN** 桌面打包成功但 renderer 类型检查报错
- **THEN** 对应 macOS 发布检查失败，不以打包成功覆盖类型错误

#### Scenario: 权限夹具已不符合测试前提
- **WHEN** 权限拒绝测试的账号因默认角色变化实际已获权
- **THEN** 使用明确缺少目标权限的主体重建负向前提，同时验证获权主体可用，不通过删除拒绝断言收尾

#### Scenario: 验收期间镜像标签被改指
- **WHEN** 构建结束后或镜像检查过程中同名标签指向了另一镜像
- **THEN** 构建输出、逐层及历史扫描、容器启动和验收记录使用同一不可变 image ID，不重新通过标签选择产物

#### Scenario: 镜像配置使用用户组写法或用户别名
- **WHEN** 镜像配置使用 `root:group`、`0:group` 或实际解析为 UID 0 的用户名
- **THEN** 非 root 检查失败；已创建的测试容器及匿名卷被清理，不报告镜像验收成功

### Requirement: 平台证据准确且 Windows 测试暂缓

本次必需平台范围 SHALL 包含实际生产服务端/容器、Web 与 macOS 桌面端。Windows 桌面测试 SHALL 明确记录为环境不满足而暂缓，MUST NOT 计为通过或作为本轮上述目标发布的阻断项，也不得借此关闭或移除已有 Windows 功能。macOS 回环验证 MUST NOT 替代 Linux 隔离、真实远程服务或最终安装包证据；未完成的本轮必需场景 SHALL 保持未完成状态。

#### Scenario: Windows 环境不可用
- **WHEN** 当前没有 Windows 桌面测试环境
- **THEN** 报告列出暂缓范围和原因，仅声明已验证平台；保留原 Windows 实现，其他目标按自身门槛验收

#### Scenario: 本机验证冒充远程验收
- **WHEN** 仅完成 localhost 或 mock 执行测试
- **THEN** 不标记真实远程登录、文件执行、断线重连、服务重启或撤权时序通过

### Requirement: 单机容量与发布恢复证据可追溯

发布记录 SHALL 包含候选提交、依赖清单、镜像/安装包摘要、各检查结果、目标并发下延迟/排队/内存观测、完整恢复演练和回滚步骤。容量结论 SHALL 限定实测单机条件；发现持续排队或资源增长时先修正局部容量边界，不以未经验证的多 worker 作为扩容结论。回滚 SHALL 校验数据版本兼容；旧产物不能安全读取新数据时必须使用兼容快照，不自动降级运行已知越权路径。

#### Scenario: 发布前核对产物
- **WHEN** 操作者准备替换生产版本
- **THEN** 能核对已验收候选与将部署产物一致、恢复演练完成、回滚所需版本和快照可用，所有未执行项明确列出
