## ADDED Requirements

### Requirement: 编码会话参与统一历史并按来源管理

历史页 SHALL 在现有列表中展示有权访问的已关联编码会话，并保持分组、分页、标题搜索、置顶、归档及身份展示。打开编码会话 SHALL 在对话视图恢复对应 OpenCode 历史；重命名/删除 SHALL 按 `opencode-session-sync` 操作远端后刷新缓存。置顶与平台归档只改变平台展示，不删除远端会话或代码。普通会话原有语义保持不变。

#### Scenario: 从普通历史打开编码历史
- **WHEN** 用户选择列表中 coding 智能体的一条记录
- **THEN** 当前身份和对话视图切换到该编码会话，普通消息历史不被清空或重写

#### Scenario: 归档与恢复编码会话
- **WHEN** 用户在平台归档并随后恢复一条编码会话
- **THEN** 平台列表按既有规则隐藏及恢复该项，OpenCode 会话和项目文件保持存在

#### Scenario: 失联与空列表不同
- **WHEN** 编码服务暂不可达但已有缓存历史
- **THEN** 列表保留记录并提示不可用，不能把失联显示为无会话；普通历史仍可操作
