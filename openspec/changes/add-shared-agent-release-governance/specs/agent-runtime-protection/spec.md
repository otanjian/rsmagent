## Purpose

在现有授权、凭据和执行隔离基础上，保护普通智能体的发布定义、管理草稿与控制数据，覆盖实际启用的文件、脚本、连接及后台运行路径，并以合法业务与越界拒绝共同验证核心不可改。

## ADDED Requirements

### Requirement: 核心写入只经独立管理请求

聊天及其派生操作 SHALL 无权修改核心定义、草稿管理数据、活动指针、权限/角色、渠道路由或管理凭据。只有独立认证且具有相应资格的管理请求可修改草稿或发布；owner、管理员、工具自行鉴权或审批通过均不能跳过此边界。旧管理/文件/技能入口 SHALL 转入同一草稿规则或拒绝，后台进化只能输出建议，不能自动改草稿或发布定义。提示模板须与该行为一致，移除自动修改 AGENT.md/RULE.md/技能、原始 USER.md 写入与删除 BOOTSTRAP.md 的指令，不能把提示词拒绝当作执行保护。本人资料和引导状态按既有个人域受限服务处理，只接受可信主体与已登记数据字段；这不授予聊天或脚本任意核心文件写权。

#### Scenario: 管理员从渠道改规则
- **WHEN** 管理员或 owner 经钉钉、企微、Web 聊天或直接工具派发要求更新规则/运行权限
- **THEN** 实际核心写入被拒绝，不能把聊天身份提升为管理请求，定义、草稿和控制数据不变

#### Scenario: 自动学习更新规则
- **WHEN** 后台进化或模型依据旧提示尝试改 AGENT.md、RULE.md、技能、删除 BOOTSTRAP.md 或执行进化回滚
- **THEN** 核心修改被拒绝，建议只能由获权维护者纳入草稿；本人动态记忆仍按原专用服务规则维护

### Requirement: 文件与进程使用一致核心边界

文件工具、Bash/解释器、前后台进程及后代 SHALL 仅通用写入本次获权业务根和临时区；定义只读，控制数据库、管理凭据和管理登录态不可向运行暴露，业务状态与记忆由原专用服务维护。父目录替换、权限修改、链接、解压和并发路径变化不得绕过边界。任意代码不能在具有管理能力的服务进程中直接执行。隔离失败 MUST NOT 降级到普通进程；各平台分别验证并启用。正常文件处理、合法业务网络、输出、超时和取消必须通过正向验证。

#### Scenario: 动态路径与父目录替换
- **WHEN** Python、派生进程或文件接口动态构造核心路径、通过链接或替换父级尝试写入
- **THEN** 实际访问被阻断且核心摘要不变，不依赖命令字符串扫描

#### Scenario: 合法业务与平台隔离失败
- **WHEN** 获权脚本读取业务文件并生成报告，另一平台的隔离后端不可用
- **THEN** 已验收平台正常产出和取消任务，未通过平台拒绝相应受保护执行，不静默改派或回退无隔离进程

### Requirement: 连接与工具受固定上限和当前授权约束

运行 SHALL 使用固定版本能力上限，并逐次叠加当前主体权限、连接分配、数据范围、审批、配额及部署限制，空清单不得恢复默认能力。连接/浏览器/脚本不得获得可改写本系统核心或控制数据的管理凭据、登录态或可信调用能力；无法约束的路径不得启用。合法业务连接须仍可用，不能以全关网络代替验收。

连接校验 SHALL 对可观测 schema、声明版本、目标身份或可取得摘要的变化重新校验，超出固定清单时拒绝；MUST NOT 声称能检测未暴露的远端内部语义变化。实际控制边界以可信连接身份和目标端权限为依据，首期不要求建设通用出口代理或任意工具副作用分类平台。

#### Scenario: 业务凭据与管理旁路
- **WHEN** 运行使用已允许 HTTP/MCP/数据库/浏览器能力请求本系统管理修改
- **THEN** 独立管理认证及凭据/目标权限边界拒绝该修改；不能约束这种写入的连接不得开放

#### Scenario: 撤权与可观测漂移
- **WHEN** 运行中连接授权撤销，或连接声明发生超出固定清单的变化
- **THEN** 后续调用拒绝，不用旧缓存或发布时权限继续执行；不把同 schema 的远端行为变化宣称为已检测

### Requirement: 派生和调度保留真实主体与运行边界

派生任务 SHALL 继承可信目的、原始主体、固定版本关系与父能力上限，不能扩权。跨 Agent 委派须额外检查真实主体对目标的 owner/共享资格及目标有效版本；独立调度在触发与恢复时重验授权和活动版本，机器主体使用自身资格不得伪造 owner。缺失上下文、版本无效或执行器不能落实保护时 SHALL 拒绝，不借外部 coding、旧队列或自动切换身份绕过。

#### Scenario: 委派给高权限对象
- **WHEN** 普通运行请求更高权限 Agent 或非 owner 私有 Agent 执行任务
- **THEN** 目标无访问资格时拒绝，有资格时也不能超过父上限，不借目标作者或管理身份扩权

#### Scenario: 旧队列恢复
- **WHEN** 队列恢复时权限已撤销、对象停用或可信主体/用途缺失
- **THEN** 拒绝执行并保留诊断，不回退旧工作区、机器账号或其他 Agent
