## MODIFIED Requirements

### Requirement: 列表来自现有智能体配置
系统 SHALL 展示现有配置中已保存、启用且在当前访问范围内可读的智能体，并包含符合条件的默认智能体。系统 SHALL 直接使用原智能体标识，不维护独立上架记录。受治理普通智能体还 MUST 具有可运行的有效发布版本，卡片名称、说明及能力采用线上投影；首次未发布的对象不得出现在普通使用目录，即使调用者拥有其 read/use。私有普通智能体采用同一发布门槛，已发布投影仍仅本人可见；首次未发布仅在本人管理/预览入口显示。管理目录和获授权草稿预览目录可以展示未发布对象，但 MUST NOT 伪装成正式可用入口。

#### Scenario: 多个已配置智能体
- **WHEN** 配置中包含两个满足使用目录条件的启用智能体和一个已归档或停用的智能体
- **THEN** 使用页显示两个启用项，不显示已归档或停用项，默认项排在首位，其余保持稳定顺序

#### Scenario: 默认单智能体
- **WHEN** 系统以现有单智能体配置运行，且该默认项满足当前访问及统一发布条件
- **THEN** 使用页显示该默认智能体，不要求用户先创建第二个智能体

#### Scenario: 首次未发布与线上草稿分别展示
- **WHEN** A 从未发布，B 已发布 v1 且保存了新名称草稿
- **THEN** 普通使用目录不展示 A，B 继续展示 v1 名称；管理详情分别显示未发布及有未发布修改

#### Scenario: 私有草稿与正式目录分离
- **WHEN** owner 拥有首次未发布 A，以及线上 v1 带未发布修改的私有 B
- **THEN** 本人普通使用目录只展示 B 的 v1 投影；管理目录可展示 A 和 B，其他用户目录均不出现这两个私有对象
