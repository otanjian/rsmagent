
## ADDED Requirements

### Requirement: 正式渠道仅运行普通对象的有效发布版本

钉钉、企业微信等正式渠道绑定受治理普通智能体时 SHALL 验证其已有有效发布版本；渠道连接配置本身不等于智能体发布。每次正式消息运行 SHALL 在既有认证、外部身份映射、有效租户成员/机器主体、模型、资源授权、配额和审批条件之后校验启用与版本完整性。渠道只携带可信目标标识，MUST NOT 接受消息正文或客户端字段选择草稿、预览用途、其他主体或任意版本。私有目标还 SHALL 满足原个人渠道资格，发送者必须是真实 owner；仅因发布不能成为群组或其他成员可用的共享机器人，向群组开放必须先转换并重新发布。入站传输模式不得改变这些边界；外部身份/访问授权失效、目标停用或发布包无效时不回退其他身份、Agent 或草稿。

#### Scenario: 把未发布共享对象接到正式渠道
- **WHEN** 管理员尝试保存指向从未发布共享对象的钉钉或企业微信正式绑定
- **THEN** 保存被拒绝并说明需先发布；历史无效绑定收到消息时同样拒绝执行，连接成功不能豁免此条件

#### Scenario: 渠道对象存在未发布修改
- **WHEN** 钉钉或企业微信用户对已有线上 v1 的共享对象发送消息，同时编辑者保存了新草稿
- **THEN** 使用 v1 并记录真实主体和版本，草稿内容和管理操作不因群消息进入执行

#### Scenario: 身份或版本失效
- **WHEN** 当前发送者身份映射被撤销、对象被停用，或固定版本包缺失/完整性无效
- **THEN** 后续执行按对应边界拒绝并留下不含敏感内容的诊断，不转到默认 Agent、旧账号或未发布草稿

#### Scenario: 私有发布不向群成员开放
- **WHEN** 已发布私有对象被请求绑定到面向其他成员的群组渠道，或收到非 owner 消息
- **THEN** 绑定或执行被拒绝；owner 在原获准个人渠道运行时也只使用有效发布版本
