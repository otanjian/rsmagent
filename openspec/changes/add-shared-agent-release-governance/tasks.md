## 1. 基线与首期门槛

既有共享发布切片的任务和证据见 [历史方案说明](evidence/legacy-shared-release/README.md)。其任务编号及完成状态只适用于旧范围；以下任务按当前私有/共享统一方案独立验收，不因合并既有代码自动勾选。

- [ ] 1.1 按十二个 capability 建立场景验收映射，盘点实际管理写入口、运行/后台入口和支持平台；依据现行个人目录 specs 保留 cwd、owner、历史附件语义，记录未启用路径，不等待已归档 change 再合并。
- [ ] 1.2 核验所用审计、凭据、审批、配额、身份/连接授权与执行隔离切片的真实证据；完成核心定义/USER.md 个人资料/引导状态与 BOOTSTRAP/动态 MEMORY/会话/索引/业务文件分类清单，禁止照搬 CORE_FILES，缺失依赖不得以接口占位通过。
- [ ] 1.3 确定最低兼容构建/schema、各平台支持范围、控制存储事务边界与有界保留参数；记录第 2–3 阶段管理测试及第 4–6 阶段运行启用条件，只使用临时租户/测试实例。
