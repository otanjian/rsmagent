## ADDED Requirements

### Requirement: 发布治理启用时成员运行以已发布快照为唯一来源

当共享智能体发布治理启用时，成员会话的员工上下文、工具白名单与黑名单、技能与知识绑定，以及外部连接分配 SHALL 以该智能体的**已发布版本快照**为唯一来源，而非当前 roster 草稿。快照未包含的工具、连接、技能与知识 MUST NOT 对成员运行注册、枚举或派发；快照中已移除的能力 MUST NOT 因缓存或既有会话继续生效。运行前对发布状态与快照的复核失败 SHALL 拒绝（fail-closed），MUST NOT 回退到草稿配置、进程级默认或其他智能体。运行时使用的来源 SHALL 与服务端授权读取的发布状态一致，MUST NOT 以客户端提交字段替代。

#### Scenario: 草稿能力不进入成员运行
- **WHEN** 一个已发布智能体的草稿加入工具或外部连接，成员发起新运行
- **THEN** 运行时注册与派发的有效集合仍等于已发布快照

#### Scenario: 新发布移除能力
- **WHEN** 某次发布移除了一个工具、技能或外部连接
- **THEN** 成员后续运行的该能力不可用，旧会话不继续沿用

#### Scenario: 发布状态复核失败
- **WHEN** 运行时无法解析该智能体的已发布状态或快照
- **THEN** 拒绝本次运行，不回退到草稿或全局默认
