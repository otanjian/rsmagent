## ADDED Requirements

### Requirement: 智能体发布治理动作纳入单动作审批

共享智能体的发布（`agent.release`）、回滚（`agent.release.rollback`）与停用（`agent.release.suspend`）SHALL 作为可声明的动作类接入既有单动作审批：适用性由服务端根据部署声明与动作类决定，客户端字段 MUST NOT 使动作免于审批。批准 SHALL 绑定目标租户、发起人、动作身份、目标智能体与该次发布候选的规范摘要，并在状态变更前**一次性消费**。审批资格 SHALL 独立于对资源的授权，且 MUST NOT 允许发起人审批自己的请求。

#### Scenario: 发布动作已声明且未提供批准
- **WHEN** 发布动作被部署声明为需要审批，而请求未携带有效批准
- **THEN** 拒绝执行，返回可区分的"需要审批"结果，且不产生任何发布副作用

#### Scenario: 批准与候选摘要绑定
- **WHEN** 为候选版本 A 取得的批准被用于候选版本 B
- **THEN** 因摘要不匹配拒绝，候选 B 不发布

#### Scenario: 未声明的回退
- **WHEN** 部署未把发布动作声明为需要审批
- **THEN** 按既有"未声明即不适用"语义处理，但仍保留资格、审计、配额与企业启用门槛
