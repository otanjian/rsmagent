## ADDED Requirements

### Requirement: 发布治理启用时默认解析与列表只采用已发布绑定

当共享智能体发布治理启用时，租户智能体列表与默认智能体解析（租户默认、成员默认）SHALL 只采用 `release_state=released` 且 `enabled` 的绑定。草稿、停用或从未发布的绑定 MUST NOT 出现在租户智能体可见集合中，也 MUST NOT 被解析为租户或成员默认。解析在可选集合为空时 SHALL 按既有规则确定性地拒绝或回落，MUST NOT 回退到进程级默认、其他租户或某条未发布绑定。

#### Scenario: 默认解析跳过未发布绑定
- **WHEN** 租户默认指针因发布停用而不可用
- **THEN** 解析确定性回落或拒绝，不采用未发布租户共享绑定

#### Scenario: 列表只含已发布
- **WHEN** 成员读取租户智能体列表
- **THEN** 返回集合只含已发布且启用的绑定，草稿与停用不出现
