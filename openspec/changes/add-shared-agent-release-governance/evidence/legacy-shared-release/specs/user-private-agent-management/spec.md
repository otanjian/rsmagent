## ADDED Requirements

### Requirement: 私有与租户共享转换衔接发布状态

当共享智能体发布治理启用时，`私有 → 租户共享` 转换 SHALL 使该智能体进入**未发布（draft）**状态；在成功发布前，该智能体 MUST NOT 对成员可见或可运行。`租户共享 → 私有` 转换 SHALL 立即使该智能体对成员不可用，且 MUST NOT 删除其发布历史。转换 SHALL 继续遵守既有转换资格（所有者或租户管理员 / 租户管理员 + 明确有效成员所有者）、默认智能体保护（目标不得为租户默认）与审计要求；转换为发布状态的变化 MUST NOT 改变租户绑定、工作区、会话或记忆归属。

#### Scenario: 转为共享后需发布
- **WHEN** 所有者把一个私有智能体转为租户共享
- **THEN** 该智能体处于草稿状态，发布前成员不可见

#### Scenario: 转回私有即不可用
- **WHEN** 租户管理员把一个已发布共享智能体转回私有
- **THEN** 成员立即可见性被移除，发布历史保留，绑定与工作区不变

#### Scenario: 目标为租户默认时拒绝
- **WHEN** 转换请求把租户默认智能体转为私有
- **THEN** 按既有规则拒绝且不产生部分状态
