## ADDED Requirements

本轮在真实 Web 和后端验收安装、配置及展示；Desktop 展示验证按 tasks 12.3 后补，不以 Web 结果推定桌面通过。

### Requirement: 技能目录安装和创建沿用资源范围与维护资格

获权管理者 SHALL 能从配置的受信技能目录按名称安装，或在合法技能根创建技能及其资源文件；目录搜索不自动授予安装、启用或执行资格。操作 SHALL 沿用当前技能资源、管理资格和动作授权，不因私有 Agent 所有权获得公共安装权。安装与编辑 SHALL 保持包资源和原始文本；路径穿越、同名歧义、重叠目录、非法包及越租户目标必须在发布前拒绝。目录凭据 SHALL 仅用于其受信目标，回退公共目录或重定向时不得转发私有令牌。

#### Scenario: 管理者安装或创建技能
- **WHEN** 具备所需管理资格和动作授权的用户向合法范围安装目录技能或创建新技能
- **THEN** 原技能库登记完整资源及稳定标识，配置和列表可读取，实际启用/使用仍按独立授权决定

#### Scenario: 普通成员尝试公共安装
- **WHEN** 只持有技能读取或使用权的成员提交公共安装或创建请求
- **THEN** 请求被拒绝，不新增公共资源，不因拥有个人 Agent 绕过维护资格

#### Scenario: 私有目录未找到技能
- **WHEN** 私有目录查询未命中并按产品配置回退公共目录
- **THEN** 回退请求不携带私有目录令牌，安装目标和资源授权保持不变

### Requirement: 技能展示元数据与发布失败保持一致

技能列表及确认安装界面 SHALL 保留受信登记的展示名、说明、图标、版本和来源，技术标识仍独立承担资源定位，展示字段不能覆盖授权对象。替换、启停或配置保存失败 SHALL 明确报告并保留上一次有效安装及配置；并发操作不得留下半成品或覆盖其他资源。BOM、旧格式以及缺少展示字段的合法记录 SHALL 兼容读取，不因升级丢失既有选择。

#### Scenario: 安装确认显示目录元数据
- **WHEN** 受信目录返回名称、图标、版本及说明，用户确认安装
- **THEN** 当前客户端显示与已登记字段一致的结果，资源标识和权限不依赖展示名称

#### Scenario: 替换或启停保存失败
- **WHEN** 新包发布、配置落盘或并发版本检查失败
- **THEN** 旧技能及启用状态保持有效，接口返回失败或冲突，重试不读取半发布目录

#### Scenario: 读取历史技能配置
- **WHEN** 旧配置含合法 BOM、旧名称形式或缺少图标版本字段
- **THEN** 已有技能仍可正确定位和展示，其授权和启用选择不被重置
