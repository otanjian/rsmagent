## Purpose

让已认证成员在 Web 和 Desktop 中查找、管理和回溯本人对话产生的文件，同时让索引、文件预览及来源会话共同遵守当前租户、owner 和设备授权。索引是已有文件的发现入口，不产生新的文件所有权或执行许可。

## ADDED Requirements

本轮先验收 Web 及其后端文件/索引链路；Desktop 页面、原生桥及设备传输的实际验证保留 tasks 12.2–12.3 后补，相关合同不删除、不计为通过。

### Requirement: 产物目录按当前身份和真实来源过滤

系统 SHALL 提供跨获准 Agent 的本人产物列表，支持类型、Agent、关键字筛选及分页。列表、搜索、计数和分页 SHALL 在租户、会话 owner、Agent 与文件来源授权过滤后计算；平台或租户管理资格 MUST NOT 授予读取成员私有产物的权限。产物标识、会话标识、路径及 Agent 别名 MUST NOT 被当作授权证明，响应不得泄露未获准路径或会话信息。

#### Scenario: 成员浏览多个 Agent 的本人产物
- **WHEN** 成员在当前租户打开产物中心并筛选类型或 Agent
- **THEN** 当前客户端展示其获准范围内的本人产物及正确分页，切换 Agent 不混入其他成员记录

#### Scenario: 相同会话名或路径存在于不同归属
- **WHEN** 其他用户或租户拥有相同会话 ID、Agent 别名或相似路径，调用方修改筛选参数或直接请求产物 ID
- **THEN** 请求只返回本人合法范围内的数据或明确拒绝，不因标识碰撞扩大访问

### Requirement: 产物管理只改变获准索引且每次重验

系统 SHALL 支持为本人合法会话登记已有文件、置顶、修改展示标题和移除索引；登记 SHALL 验证文件真实存在、当前来源授权以及会话/Agent 归属。修改标题和移除索引 MUST NOT 重命名或删除原文件。同一作用域内相同产物的重复登记 SHALL 避免重复条目，并发更新 SHALL 保持其他产物和持久会话完整；写入失败不得返回成功。预览、下载和回溯 SHALL 再次验证当前权限，设备离线、文件消失或撤权 SHALL 给出可诊断结果，不回退读取服务器同名文件。

#### Scenario: 置顶改标题后移除
- **WHEN** 成员置顶本人产物、修改展示标题并移除该索引
- **THEN** 列表反映每次成功操作，原文件名和正文始终不变，其他成员索引不受影响

#### Scenario: 并发登记或数据库写入失败
- **WHEN** 同一产物被并发登记，或登记/管理事务无法提交
- **THEN** 成功提交后同一归属内不产生重复条目；失败操作明确报错并保留此前有效记录，不破坏会话消息

#### Scenario: 列表读出后权限或来源变化
- **WHEN** 成员取得产物条目后切换身份、失去授权、删除来源会话或设备离线
- **THEN** 后续预览、下载、回溯按当前状态拒绝或明确不可用，旧地址不延续访问资格

### Requirement: 产物索引迁移可恢复且不影响对话提交

索引升级 SHALL 兼容已有会话和消息；历史条目只能由可信会话归属和文件来源回填，无法确定的条目 SHALL 保持不可见且留待核查，不推测分配给默认用户或 Agent 当前租户。索引失败 MUST NOT 造成已提交消息重复保存或丢失；恢复或重试 SHALL 可重复执行，并准确反映产物尚未完成索引的状态。预览生成的 HTML 等不可信内容 SHALL 沿用既有隔离展示边界，不获得原生桥、平台凭据或未授权文件访问。

#### Scenario: 旧数据库包含无法确认归属的产物
- **WHEN** 升级或重建索引时遇到归属不明的历史记录
- **THEN** 其原始消息和文件保留，记录不进入任意成员列表，迁移报告说明待核查范围

#### Scenario: 消息已保存但索引失败
- **WHEN** 对话消息提交成功而产物索引写入失败，随后执行重试
- **THEN** 消息仅保留一份，重试仅补齐索引，未成功索引的状态不伪报已完成

#### Scenario: 预览含脚本的产物
- **WHEN** 成员预览自己生成的 HTML 文件
- **THEN** 文件在受控展示环境中打开，脚本无法调用 Desktop 原生桥或读取其他文件及平台秘密
