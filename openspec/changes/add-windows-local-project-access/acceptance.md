## 证据要求

- 单元/契约验证schema、工具集合、错误映射；原生进程测试使用实际句柄/文件及并发替换；安装包/真实模型测试验证派发和UI，层次不可互相替代。
- 一份当前版本有效证据可覆盖多个用例；沿用旧change的已验证登录/网关结果时记录版本与适用范围，不能据其推断本次新文件后端已通过。
- 每项记录步骤、预期、实际、输入/产出摘要及结论；全部使用合成数据，不保存Bearer/原生回调秘密/个人文件正文。API资料不算实际探针结果。
- 脚本边界不在W01–W16范围，须另外完成S01–S12；不能以文件测试通过宣称脚本/所有技能已支持。
