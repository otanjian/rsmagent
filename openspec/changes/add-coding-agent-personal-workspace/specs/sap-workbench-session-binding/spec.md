## ADDED Requirements

### Requirement: 个人工作区与场景控制关联分别核验

个人模式 SAP 场景 SHALL 在既有绑定中区分配置项目根、个人工作区与实际远端会话，恢复、分叉及重新关联 SHALL 同时核验这些语义，不能将个人目录 U 与项目安装根 P 的差异误判为跨项目。共享 U MUST NOT 替代场景会话、用户、租户、服务及控制代次的既有授权。

场景已支持的导出、下载或文件交付 SHALL 进入当前绑定 U 的对应会话目录并使用受控引用返回，不进入全局默认下载位置。本要求不新增尚未交付的 SAP 自动操作能力，也不将个人文件接入验收作为统一登录或其他未完成场景能力已经验收的证明。

#### Scenario: 恢复和导航个人 SAP 会话
- **WHEN** 用户恢复或导航到合法关联的个人 Code 会话，其运行目录 U 与项目安装根 P 不同
- **THEN** 场景按两个独立字段验证，不错误拒绝合法绑定，也不放宽既有会话和控制权检查

#### Scenario: 同个人目录的另一个会话
- **WHEN** 同账号另一 Code 会话共用 U 但尚未建立场景关联
- **THEN** 不能借用现有 SAP 页面、连接或控制权，按原场景绑定流程处理

#### Scenario: 场景导出到个人目录
- **WHEN** 已交付且获授权的 SAP 文件导出操作成功
- **THEN** 文件保存到当前个人会话的 U 内并可从顶部面板下载，不回传其他会话的文件
