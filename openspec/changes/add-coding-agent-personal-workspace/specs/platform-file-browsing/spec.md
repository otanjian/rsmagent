## MODIFIED Requirements

### Requirement: 工作区面板默认锚定当前 Agent 自己的目录并在无权时回落到本人私有 Agent

控制台对话页右侧工作区面板的顶栏入口 SHALL 在打开时锚定当前会话的实际业务目录：已选有效项目时使用项目目录；无项目的共享普通 Agent 或私有普通 Agent 使用 `<agent workspace>/user/<本人不可变用户ID>/`。新建与存量普通对象使用同一规则，落点 SHALL 与既有服务端默认目录及文件来源一致，前端路径计算不构成授权，不要求普通来源新增布局协议。入口打开后 SHALL 位于「文件」页签并重新列举该目录，MUST NOT 因上次预览过文件而停在预览页签，MUST NOT 沿用上次浏览的子目录或上一次的回落作用域，MUST NOT 以残留条目冒充当前 Agent 的目录。

已启用个人文件能力的 coding 顶栏入口 SHALL 按 coding-agent-personal-workspace 打开远端 `P/user/<登录账号>`，从账号目录显示面包屑，不能返回其父目录。个人会话使用已有 U 快照；旧会话按原项目快照打开本人 U，并明确其与旧执行目录的区别。创建、读取或授权失败 MUST 明确报告，MUST NOT 回落 P、平台本机同名目录、租户根或本人其他 Agent。未启用该能力的旧 coding 入口保持既有行为，已有个人会话不因新增开关关闭改变文件来源。

有效项目或不适用统一目录的既有入口按其实际工作区落点显示，MUST NOT 因不存在 `agents/<id>` 而报「不是目录」。普通 Agent 的本人目录尚未创建时 SHALL 经授权准备后列举，准备失败 MUST 明确报告，不得回落 Agent 根或租户根。用户自己浏览进入的路径不存在时 SHALL 照常报错。非 coding 个人来源回到获权父目录的面包屑仍可用，导航不改变执行 cwd。

对于仍适用既有回落契约的普通来源，当该目录的列举以一个**权限判定拒绝**作答（服务端对该 Agent 的租户绑定、私有归属或会话归属拒绝，返回 403/404）时，前端 SHALL 回落到**调用者本人的私有 Agent 实际业务目录**（普通 Agent 为该 Agent 的 user/<本人ID>）：以调用者本人的私有 Agent 作为该面板的作用域，并以该业务目录继续列举，保持该作用域用于面板后续的预览、读取与写入，同时 SHALL 以既有提示机制告知已切换到本人智能体目录。回落后的重试 SHALL 按回落后的 Agent 重新取路径，MUST NOT 复用被拒 Agent 的目录；面板回落不改变聊天目标和执行 cwd。

回落 MUST NOT 放宽任何授权：作用域仍由服务端按实际资源归属判定，客户端自报的 Agent 标识 MUST NOT 成为授权依据。回落 SHALL 至多发生一次（一次落点最多探询一次本人的私有 Agent），MUST NOT 形成重试循环。调用者没有本人的私有 Agent，或本人私有 Agent 的目录同样被拒时，面板 SHALL 给出本地化的「没有权限打开该智能体的目录」提示，MUST NOT 把服务端的原始拒绝串（如 `agent not found`）当作结果呈现，MUST NOT 回落到他人目录，MUST NOT 以成功状态伪装。

面板锚定的 Agent 因切换 Agent、切换会话或重新打开入口而改变时，SHALL 丢弃上一次的回落作用域，按当前 Agent 重新判定并重新落到其实际业务目录。账号、租户和文件来源变化时 SHALL 同时丢弃旧预览、上传和回收站状态，迟到响应不能覆盖当前来源。

#### Scenario: 打开入口即看到当前 Agent 自己的目录
- **WHEN** 用户在与某 Agent 的对话中点开顶栏工作区入口，且此前预览过另一个文件、浏览过某个子目录
- **THEN** 面板显示服务端投影的该会话业务目录，普通 Agent 无项目时为本人子目录；位于「文件」页签，必要的目录准备后只对该落点发起一次列举请求

#### Scenario: 工作区根之下没有该 Agent 的目录
- **WHEN** 当前会话已打开项目目录，或不适用统一目录的单 Agent 入口下工作区根即 Agent 目录，因此根之下不存在 `agents/<agent id>`
- **THEN** 面板显示工作区根的条目，不显示「不是目录」之类的错误

#### Scenario: 用户浏览进入的路径不存在
- **WHEN** 用户点进一个已被删除的目录
- **THEN** 面板照常报告该路径不存在，MUST NOT 悄悄退回工作区根

#### Scenario: 无权浏览该 Agent 目录时回落到本人私有 Agent
- **WHEN** 适用普通来源回落契约的当前 Agent 目录被服务端以 403/404 拒绝，且调用者拥有本人的私有 Agent
- **THEN** 面板改为列举调用者本人私有 Agent 的实际业务目录并保持该作用域，且提示已切换到本人智能体目录；聊天目标和执行 cwd 不改变

#### Scenario: 没有可供回落的目录时给出本地化提示
- **WHEN** 适用回落契约的当前 Agent 目录被拒绝，而调用者没有任何私有 Agent，或本人私有 Agent 的目录同样被拒
- **THEN** 面板显示本地化的「没有权限打开该智能体的目录」，不回落、不重复重试、不呈现服务端原始拒绝串

#### Scenario: 回落作用域不跨 Agent 与会话存活
- **WHEN** 用户在回落状态下切换到另一个 Agent 或另一个会话，随后再次打开面板
- **THEN** 面板按新的当前 Agent 重新判定并列举其实际业务目录，不沿用上一次的回落 Agent

#### Scenario: 本人目录首次打开与不安全容器
- **WHEN** 私有 Agent 的本人目录不存在，或 user 容器被替换为链接/文件
- **THEN** 前者经受控准备后显示本人目录；后者明确失败，不以打开根目录伪装成功

#### Scenario: 单 Agent 工作区就是实例根
- **WHEN** 普通 Agent 工作区就是实例根
- **THEN** 面板使用该根下 user/<本人ID>，不因为没有 agents/<id> 而落到实例根

#### Scenario: Code 个人目录首次打开及不可用
- **WHEN** 用户打开个人 Code 文件入口，远端本人目录尚未存在或不可准备
- **THEN** 成功时受控创建并列出账号根；失败时显示错误，不跳转到公共项目或其他 Agent

#### Scenario: Code 和普通来源之间快速切换
- **WHEN** 前一 Code 目录请求尚未返回，用户已切换账号或进入普通会话
- **THEN** 前一响应和上传状态不会进入新面板，普通来源继续原有行为

## ADDED Requirements

### Requirement: 远端个人文件复用面板操作语义

Code 个人来源 SHALL 复用现有面板的列举、搜索、预览、上传进度、下载与冲突提示，具体归属和落点按 coding-agent-personal-workspace 判定。远端上传 SHALL 保留所选 U 内子目录及文件夹相对结构，面板拖拽不创建聊天待发附件；上传、下载 URL、预览等独立入口 SHALL 使用同一来源，不能只让文件树支持远端。

远端编辑、重命名、删除与回收站 SHALL 按真实 capabilities 显示和授权；没有实现时 MUST NOT 展示或接受对应操作，不能回落本机执行。补齐这些可选能力不作为个人输入输出链路的前置，普通及桌面来源现有能力 SHALL 保持。

#### Scenario: 远端基本文件操作
- **WHEN** 用户在 Code 个人子目录拖入文件夹、搜索文件并预览下载
- **THEN** 操作均作用于同一远端 U，结构与冲突语义保持一致，不进入平台普通文件解析或聊天上传

#### Scenario: 未支持的远端操作
- **WHEN** 用户访问不支持编辑或回收站的远端来源
- **THEN** 对应按钮不可用且直接接口也拒绝，不影响上传下载，普通与桌面原有功能保持
