## Purpose

定义企业 Skill 向本地 Agent 的获权发现、完整资源分发、版本固定和执行兼容行为，使服务器维护的技能能够在桌面使用，同时保持来源身份、依赖、凭据与撤权边界可验证。

## ADDED Requirements

### Requirement: 技能运行目录按使用资格提供

系统 SHALL 根据当前身份的 `skill.use`、真实资源范围、全局启用状态和 Agent 有效选用集合向本地 Agent 提供可运行技能目录。运行目录 SHALL 与管理列表权限分离，不授予正文编辑、安装或启停资格。每个技能 SHALL 使用精确来源的资源标识，不以同名本地目录或其他来源技能借用授权。

#### Scenario: 获准使用但不可维护
- **WHEN** 成员可以使用某共享 Skill 但没有公共编辑权限
- **THEN** 本地 Agent 可以发现和获取该 Skill 的必要运行资源，不能修改公共正文或启停状态

#### Scenario: 同名或 Agent 未选用
- **WHEN** 本机和企业有同名技能，或 Agent 明确未选择某企业技能
- **THEN** 仅指定且获权的企业资源可被装配，同名和目录存在不扩大有效集合

### Requirement: 技能分发包含完整且可校验的运行资源

服务器 SHALL 为获权 Skill 提供版本化清单及完整运行包，包含必要指令、引用、模板和脚本，并声明平台、依赖和执行方式。分发 MUST NOT 包含公共/他人秘密、身份库、运行日志或客户数据。桌面 SHALL 验证文件集合、整体摘要、大小边界和路径安全后原子发布缓存；包不完整、摘要不符、路径穿越或软链接逃逸时不得加载任何部分作为可用版本。

#### Scenario: 有模板和引用的技能
- **WHEN** Skill 引用了模板、说明和脚本
- **THEN** 桌面取得同一授权版本的全部必要文件，可解析它们的包内相对引用

#### Scenario: 损坏或越界包
- **WHEN** 下载被中断、摘要不符，或包含越界路径
- **THEN** 安装失败并给出原因，旧已验证版本保持完整，新残缺版本不可运行

### Requirement: 技能缓存隔离并锁定运行版本

缓存 SHALL 以企业来源/实例、租户、用户、资源标识和摘要隔离，按需复用已验证字节；缓存命中仍 SHALL 在线重验使用资格。一次运行 SHALL 固定所用版本，更新不得混用新指令和旧脚本。有效运行引用的包不得被缓存回收破坏；新运行选择新版本时须完成同样校验。

个人 Skill 可编辑工作副本 SHALL 与运行缓存分离；同步提交完整版本后才可作为获权企业包分发。未同步/冲突的草稿不得通过同名缓存成为有效发布版本，运行缓存不得反向覆盖个人编辑。

#### Scenario: 运行中更新
- **WHEN** 服务器发布新版本而桌面仍有获权旧版本任务在运行
- **THEN** 原任务继续使用其固定版本，新任务可选择新版本，资源不会跨版本拼接

#### Scenario: 跨账号与回收
- **WHEN** 用户切换账号或缓存需要回收空间
- **THEN** 新账号不能发现或使用旧账号分区，正在运行的获权包不被回收破坏

#### Scenario: 个人 Skill 草稿尚未同步
- **WHEN** 本人修改个人 Skill 但提交失败或发生冲突
- **THEN** 保留可编辑草稿，企业运行仅可使用仍获权的已确认完整版本，不能直接装载该草稿冒充云端版本

### Requirement: 技能获取不依赖伪造远程执行任务

本地 Agent SHALL 能以自己已登记的企业运行和当前授权获取 Skill，而不要求服务器创建一次远程 Agent 循环或伪造设备命令。新获取方式 SHALL 仍绑定精确资源、版本和调用者用途，并重验授权；原有服务器下发任务的 Skill 分发接口继续保持其命令绑定约束。

#### Scenario: 本地 Agent 首次获取 Skill
- **WHEN** 新本机会话首次需要获权企业 Skill
- **THEN** 通过本地运行的授权用途下载，不生成重复服务器任务

#### Scenario: 旧远程命令继续分发
- **WHEN** 原 remote 模式按服务器设备命令下载 Skill
- **THEN** 原命令、设备、版本与授权校验仍生效，不被新入口削弱

### Requirement: 技能执行方式符合设备和服务依赖

指令与模板 SHALL 由本地 Agent 加载，可移植计算 SHALL 在具备依赖及执行能力的本机完成；企业连接和公共凭据步骤 SHALL 通过获权企业工具执行。缺少依赖、平台不支持、服务器绝对路径或不满足网络合同 SHALL 给出具体不可用原因，不能自动改为其他来源 Skill、直接下载秘密或转为服务器任意脚本。

#### Scenario: 本机计算配合企业查询
- **WHEN** Skill 先通过企业工具查询数据，再计算本地 Excel 并生成报告
- **THEN** 企业查询和本机计算分别在声明位置执行，公共秘密不进入本机环境

#### Scenario: Windows 或依赖不兼容
- **WHEN** Skill 需要尚未支持的 shell、运行库或脚本隔离能力
- **THEN** 显示该 Skill 的具体限制，不能把“包已下载”显示为“可正常执行”

### Requirement: 禁用和撤权阻止缓存继续授权

Skill 被禁用、指定版本撤销、成员或资源资格移除后，下一次模型上下文装配或脚本步骤 SHALL 拒绝使用，即使文件已缓存。权限收回与正常版本更新 SHALL 分别处理；退出和切换后旧下载响应不得发布到新上下文。系统 MUST NOT 宣称能收回用户已复制的技能内容。

#### Scenario: 缓存命中但技能禁用
- **WHEN** 已缓存技能被服务器禁用后，本地 Agent 开始下一步
- **THEN** 在线检查拒绝该 Skill，缓存命中不能绕过禁用

#### Scenario: 下载途中换租户
- **WHEN** 用户切换租户后旧下载才完成
- **THEN** 旧结果不进入新租户的目录或运行，临时资源按原归属清理
