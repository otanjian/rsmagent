## Purpose

定义本地 Agent 使用企业服务器配置、授权、模型、工具及个人状态的服务合同，使企业权限与消耗仍由服务器逐次判定，同时保持本机执行和企业动作的身份、计量及恢复语义一致。

## ADDED Requirements

### Requirement: 企业服务根据受信身份提供运行配置

企业服务 SHALL 从原生会话及已验证租户解析调用者，为本机运行提供获权 Agent 目录、有效配置和资源引用，并继续执行真实绑定及 owner 限制。请求携带的 Agent 选择 SHALL 在服务端确认；模型参数、客户端权限列表、本机同名 Agent 或本地身份库 MUST NOT 替换权威身份与企业配置。运行配置 SHALL 携带版本且不含秘密或服务器绝对路径。

#### Scenario: 选择共享 Agent
- **WHEN** 有效成员选择获准使用的企业 Agent
- **THEN** 本地 Agent 得到该资源的有效去秘密配置、能力引用和版本，服务器保持唯一维护权

#### Scenario: 伪造身份或跨租户 Agent
- **WHEN** 调用方在业务参数中声明其他用户、租户、管理员身份或其他租户 Agent
- **THEN** 服务端拒绝越权目标，不返回配置或以本机同名资源替代

### Requirement: 企业资格在每个模型与工具步骤前重验

每次企业模型、共享资源和工具动作 SHALL 复用既有主体、功能权限、资源范围、Agent 绑定/黑白名单、审批、执行隔离与硬配额规则。新本机执行步骤 SHALL 在取得执行槽位后在线取得并消费绑定精确身份、动作、参数、项目授权、Skill 版本及当前上下文代际的一次资格，消费时重验当前事实。缓存的目录、配置、历史或运行标识 MUST NOT 产生持续授权；身份服务故障或必要接缝缺失 SHALL 拒绝受影响步骤。

本机目录授权 SHALL 只限制可访问文件，不授予企业资源资格；会话权限模式 MUST NOT 被增加为替代企业角色/资源授权的依据。

#### Scenario: 排队后撤权
- **WHEN** 工具在本机排队时其使用 grant、成员资格或 Agent 绑定被撤销
- **THEN** 取得执行槽位后的在线检查拒绝该动作，不产生文件或企业业务副作用

#### Scenario: 参数变化或资格重放
- **WHEN** 已授权步骤改变工具、参数、项目、Skill 版本或 epoch，或者重复消费同一资格
- **THEN** 不能启动新的执行；相同已完成步骤只能查询原状态

#### Scenario: 缺失授权接缝
- **WHEN** 本机企业运行时无法取得服务端授权结果或必要 provider 未装配
- **THEN** 明确报告不可用，不沿用无身份的单机兼容放行

### Requirement: 企业模型只代理单次调用且统一计量

企业模型服务 SHALL 只为本地循环执行单次获权模型请求，保持流、工具调用、取消和错误合同。公共供应商秘密 SHALL 仅在服务器按用途解析，不进入桌面或模型输入。所有 provider SHALL 复用既有统一计量和硬配额入口，同一调用只结算一次，未测用量不得视为零；恢复中断流不得无确认地发起新的模型消耗。计量写入与配额控制遵守各自既有失败语义。

#### Scenario: 流式模型返回工具调用
- **WHEN** 本地 Agent 调用获权企业模型并接收工具调用结果
- **THEN** 桌面继续自己的工具循环，服务器不再启动 Agent 循环，用量仅在统一调用入口记录一次

#### Scenario: 流中断或额度不足
- **WHEN** 流在已产生消耗后中断，或下一步已超硬配额
- **THEN** 已有消耗被保留并可诊断，新消耗按配额拒绝，不通过重试重复调用或改用未授权模型

### Requirement: 企业工具在所属服务执行并保留凭据边界

企业连接工具 SHALL 根据服务器登记的资源和执行位置调用，继续执行现有连接分配、功能/资源权限、owner、审批、凭据用途和配额。客户端 MUST NOT 提交任意 URL、服务器路径、连接串或凭据引用来扩大工具能力。公共或他人秘密不得通过 Skill 包、环境、返回值或日志下发到桌面；涉及本地文件传输时 SHALL 使用明确的授权资源引用与传输范围。

#### Scenario: Skill 需要企业业务服务
- **WHEN** 本机 Skill 的某步骤调用获权 ERP 或 MCP 业务工具
- **THEN** 仅该步骤在企业服务执行并返回必要结果，公共连接秘密留在服务器，本地编排继续

#### Scenario: 已分配连接仍缺少执行条件
- **WHEN** 工具曾出现在目录但调用时连接失效、分配被移除或适用审批未满足
- **THEN** 服务端拒绝实际动作，不因目录可见或本机执行模式放行

### Requirement: 运行登记与回执支持幂等和可信来源区分

本机企业运行 SHALL 使用现有业务执行登记与步骤关联，保留身份、Agent、会话、设备和执行位置。开始、消费、取消及回执 SHALL 可幂等处理；服务端 SHALL 区分自己执行的动作、授予本机的资格和客户端报告的结果，不将后者表示为服务端亲自验证的文件副作用。未确认结果 SHALL 显式保留，不能自动重新执行；未完成计量/并发占用 SHALL 有可恢复、不可重复结算的终态处理。

#### Scenario: 回执丢失后重连
- **WHEN** 本地文件已生成但服务端未收到成功回执
- **THEN** 客户端按原步骤补报或查询，保留客户端报告来源，不重复生成或再次扣除该动作额度

#### Scenario: 两台设备并发
- **WHEN** 同一用户从两台桌面同时发起企业运行
- **THEN** 不同会话的运行/步骤相互区分且共享真实租户/用户配额；同一会话只允许一个执行者，不能双花并发资格或启动重复循环

#### Scenario: 结果无法确定
- **WHEN** 进程崩溃后无法证明某副作用是否完成
- **THEN** 状态为待确认且禁止自动重做，不以取消或失败掩盖可能已发生的动作

### Requirement: 企业个人状态继续使用原有所有权

本地运行需要的企业个人记忆及参数 SHALL 通过现有本人作用域服务按需访问，已提交状态与统一同步版本保持一致，不复制为独立本机权威。桌面可以保存待提交草稿，读取、同步或写入 SHALL 继续执行 tenant、owner、资源及并发规则；凭据只使用受控引用，本地项目索引不得被自动写入共享或企业个人状态。

#### Scenario: 使用本人企业记忆
- **WHEN** 本机 Agent 需要当前使用者获准的企业个人上下文
- **THEN** 服务端只返回本人范围，管理员身份不能代用其他成员私有数据

#### Scenario: 本机索引与断网
- **WHEN** 本机建立项目索引或访问企业个人状态时断网
- **THEN** 项目索引保持本地归属，企业状态操作明确失败或待重试，不改写另一份本地企业真值
