## Purpose

定义本地 Agent 对企业共享及获准私有知识的在线检索和来源回读，使知识权威与访问控制保留在服务器，同时允许桌面项目索引参与分析且不会自动复制整库或混淆数据归属。

## ADDED Requirements

### Requirement: 本地 Agent 可以检索获权企业知识

系统 SHALL 允许本地 Agent 使用企业知识检索及必要正文回读。服务端 SHALL 复用当前租户、Agent 数据根、私有 owner、知识读取资格及 Agent 知识绑定，在候选查询、排序和计数前限定范围；共享/独立模式遵守既有数据根规则。客户端提交的过滤条件只能收窄范围，不能扩大访问或选择任意服务器文件。

#### Scenario: 获权共享知识参与本地分析
- **WHEN** 用户在本机分析文件且当前 Agent 获准使用企业共享知识
- **THEN** 检索返回授权范围内的相关内容，本地 Agent 可用于分析，不需要整库下载

#### Scenario: 私有内容和知识绑定
- **WHEN** 非 owner 管理员检索他人私有知识，或当前 Agent 仅绑定部分条目
- **THEN** 他人私有内容和绑定范围外条目不进入候选、结果、数量或建议词

### Requirement: 检索结果有界且来源可复验

检索 SHALL 返回有界片段及企业来源、资源/文档标识、版本、片段定位和标题等引用信息，回读 SHALL 重新校验当前权限与来源状态。响应 MUST NOT 返回宿主绝对路径或将全文、二进制原件作为默认检索结果。来源更新或失效 SHALL 可区分，不得用同名新文档静默替换旧引用。

#### Scenario: 从分析结果打开引用
- **WHEN** 用户打开报告所引用的企业知识片段
- **THEN** 按该来源标识和版本重验并回读，显示对应内容或明确的版本/权限失效提示

#### Scenario: 大文档检索
- **WHEN** 命中的原始文档很大或为二进制资料
- **THEN** 仅返回约定上限内片段与来源，不默认上传/下载整个文档

### Requirement: 企业检索与本地项目索引独立

桌面 SHALL 可以检索已授权项目的本地索引，并将结果标明为本机来源；本地和企业结果组合时 SHALL 保留各自归属、版本和引用。系统 MUST NOT 因路径或名称相同互相替代，也不得自动把本地索引、文件和产物写入共享知识库。企业导入、更新、删除继续走原获权管理入口。

本人明确纳入个人知识库的文档及资料 SHALL 按统一存储/同步合同维护，目标必须是实际获权的自有知识根；个人知识同步不得被解释为镜像整个共享库或上传本地项目索引。

#### Scenario: 两侧同名文件
- **WHEN** 本机和企业知识中都有名为“财务制度”的文档
- **THEN** 搜索结果分别标识来源，引用回读到对应内容，不以本机版本冒充企业制度

#### Scenario: 本地建立索引
- **WHEN** 用户授权目录后进行文件索引和检索
- **THEN** 索引仅属于本机项目，未发起获准导入时服务器知识及其权限不变

#### Scenario: 显式导入个人知识后检索
- **WHEN** 本人选择本地文档导入自有知识库且服务器提交和索引完成
- **THEN** 可在 Web 及桌面按当前授权检索该服务器版本，原项目中其他文件和本地索引不随之上传

### Requirement: 失效和故障不伪装为合法空结果

企业知识访问 SHALL 在每次新检索及回读重验。禁用、删除、owner/Agent 范围变化和撤权 SHALL 阻止后续未授权访问；首期缓存不提供企业离线检索权。无命中、未授权、版本失效、索引未就绪和网络故障 SHALL 有可区分结果。已展示历史内容不能被当作新的读取资格，系统不得承诺撤回用户已获得的副本。

#### Scenario: 撤权后重用引用
- **WHEN** 知识访问资格在任务中途撤销，后续步骤再次检索或回读旧引用
- **THEN** 请求被拒绝，旧上下文或引用标识不能续用权限

#### Scenario: 服务不可达
- **WHEN** 企业检索服务断网或索引未就绪
- **THEN** 显示可诊断的不可用状态，不能回复“企业没有相关资料”或自动扫描其他租户目录
