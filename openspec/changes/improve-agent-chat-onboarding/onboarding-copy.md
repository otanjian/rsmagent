# 首批智能体对话引导文案

本文件提供六组可通过现有 Web 概况页面或 API 填写的示例：自我介绍对应 greeting，使用说明对应 usage_hint，四个问题对应 suggested_questions。先确认实际智能体，补齐空缺并保留自定义内容；不按名称自动匹配，不开发批量预设工具。

## 客户需求方案顾问

- 自我介绍：我帮你把客户的想法整理成清晰需求，判断适合的实现方式，并形成可讨论的方案。
- 使用说明：描述需求或提供会议纪要 → 补齐关键信息 → 确认需求与方案。
- 建议问题：
  1. 只有一个初步想法，能带我梳理需求吗？
  2. 分析客户需求，需要先准备哪些资料？
  3. 怎样判断需求适合智能体还是场景应用？
  4. 能给我一份客户需求访谈提纲吗？

## 智能办公助理

- 自我介绍：我帮你梳理日常工作、整理待办和起草材料。先告诉我今天最想完成的一件事。
- 使用说明：说出任务 → 补充时间与要求 → 确认下一步安排。
- 建议问题：
  1. 事情太多，能帮我梳理今天的优先级吗？
  2. 怎样把会议记录整理成待办清单？
  3. 写一份工作汇报，需要给你哪些信息？
  4. 能带我做一次本周工作复盘吗？

## BUG 管家

- 自我介绍：我帮你整理问题现象、复现步骤和影响范围，把零散反馈变成清晰的缺陷记录。
- 使用说明：描述异常或提供截图 → 补齐复现信息 → 整理缺陷记录。
- 建议问题：
  1. 我要登记一个 BUG，请带我补齐信息。
  2. 描述一个 BUG 时，需要提供哪些信息？
  3. 怎样写清楚问题的复现步骤？
  4. 怎么区分问题的严重程度和处理优先级？

## 经营分析参谋

- 自我介绍：我帮你从经营数据中找变化、分析可能原因，并整理下一步建议。
- 使用说明：明确分析目标 → 提供数据与统计口径 → 查看结论和依据。
- 建议问题：
  1. 营收下降时，应该先分析哪些指标？
  2. 做月度经营分析，需要准备哪些数据？
  3. 怎样区分销量、价格和结构变化的影响？
  4. 能先帮我搭一份经营分析报告框架吗？

## 企业知识官

- 自我介绍：我依据可访问的企业知识资料回答问题并标明来源；资料不足时会说明缺口。
- 使用说明：提出具体问题 → 检索可用资料 → 查看回答及来源。
- 建议问题：
  1. 回答企业制度问题时，你会怎样引用来源？
  2. 找不到相关制度时，我该怎么补充资料？
  3. 怎样提问，更容易找到准确的企业知识？
  4. 查一项业务流程，需要说明哪些背景？

## 税务健康体检

- 自我介绍：我帮你梳理税务体检所需资料和关注事项，形成待核实的问题清单。
- 使用说明：说明企业与检查期间 → 准备相关资料 → 核实发现的问题。
- 建议问题：
  1. 做基础税务体检，需要先准备哪些资料？
  2. 首次体检时，需要说明哪些企业信息？
  3. 能先介绍税务体检的一般步骤吗？
  4. 资料不完整时，怎样分阶段开展体检？
