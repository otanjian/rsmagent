本 delta 仅规定 Web 普通智能体的两个展示字段及表单，不扩展 Desktop 客户端或 OpenCode 类智能体的行为与验收范围。

## ADDED Requirements

### Requirement: 使用说明与建议问题为可选展示字段

Web 普通智能体使用的档案 SHALL 支持可选 `usage_hint`（使用说明文本，最多 200 字）和 `suggested_questions`（有序字符串列表，最多四条、每条最多 200 字）；自我介绍 SHALL 继续使用 `greeting`。新字段 SHALL 与现有档案共用存储、权限和 revision，不改变模型、工具或知识库授权。

保存 SHALL 去除首尾空白和空问题条目，拒绝错误类型、超长或超过四条的问题，并指出错误。建议问题 SHALL 为普通文本，MUST NOT 以 `/` 开头或包含 `@` 路由标记。已有 Web 普通智能体配置缺字段 SHALL 正常加载；更新省略字段 SHALL 保留原值，空字符串/空列表 SHALL 清空对应配置并采用展示默认值。现有复制路径 SHALL 保留这两个字段，不要求新建导入导出能力。

#### Scenario: 合法保存与读取
- **WHEN** 有编辑权限的用户以当前 revision 保存使用说明和问题
- **THEN** 后续管理读取和获准使用投影返回同样的归一化字段，显示顺序与保存顺序一致

#### Scenario: 非法配置或并发冲突
- **WHEN** 提交错误类型、过长文本、五条问题、命令/路由文本或过期 revision
- **THEN** 保存返回字段错误或原有版本冲突，不部分更新档案

#### Scenario: 省略字段和清空
- **WHEN** Web 管理 API 更新其他字段而省略新字段，或用户显式清空新字段
- **THEN** 省略时保留原配置，显式空值时回退默认引导；其他档案字段不受影响

#### Scenario: 权限与复制
- **WHEN** 用户读取、修改或复制带有引导字段的智能体
- **THEN** 操作遵循现有对象权限；获准复制保留文本，未获准调用不能借新字段读取或修改其他对象

### Requirement: Web 概况页直接编辑引导内容

Web 普通智能体概况 SHALL 在原有问候语旁提供使用说明和最多四个问题的普通输入控件，问题按输入顺序显示；保存、取消与冲突处理 SHALL 复用原流程。不具备编辑资格时 SHALL 不允许保存。

该扩展 SHALL 复用现有 Web 表单控件，不要求实时预览、拖拽排序或独立配置页。

#### Scenario: 编辑后生效
- **WHEN** 用户在 Web 概况修改使用说明和问题并保存成功，再进入该智能体的新会话
- **THEN** 欢迎页显示已保存的内容；取消编辑或保存失败时仍使用原配置
