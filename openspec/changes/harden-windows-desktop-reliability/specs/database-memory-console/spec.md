## ADDED Requirements

### Requirement: Windows 个人记忆合法访问保持安全与版本语义

个人记忆服务 SHALL 在 Windows 开发模式和安装包本机后端中支持当前有效租户成员对合法本人目录的获准操作，不因合法 Windows 路径或锁语义误报目录替换。修复 MUST 保留既有真实归属、防替换、版本、清空 generation 和索引恢复要求，不通过跳过校验、删除目录或重建记忆恢复可用性。远程模式 SHALL 操作服务器本人记忆，不访问客户端同名路径。

#### Scenario: 中文路径和不同盘符下管理本人记忆
- **WHEN** 有效成员的真实个人根位于合法中文或空格路径以及适用盘符，目录并未被替换
- **THEN** 列表、正文及已获准保存/删除正常，原有内容版本与索引恢复行为保持

#### Scenario: junction 或并发替换越界
- **WHEN** 根、中间目录或条目被链接或替换到另一用户、租户或未授权位置
- **THEN** 读取元数据前拒绝或保持原可信对象边界，不泄露或修改目标，不因修复 Windows 而放宽检查

#### Scenario: 并发修改与清空
- **WHEN** Windows 上的保存、后台固化和清空发生受控交错
- **THEN** 仍按既有 generation 和内容版本拒绝过期发布，不复活已清空正文或索引

### Requirement: 个人记忆安全故障提供真实分类

服务端 SHALL 保留记忆拒绝的内部异常原因、失败阶段和诊断标识，向客户端返回不泄密的分类。路径不安全、归属无法验证、锁冲突、权限不足、身份失效和一般服务失败 SHALL 提供相应动作；MUST NOT 将所有安全异常描述为目录已被替换，或将所有 403 引导为重新登录。内部日志 MUST NOT 包含其他用户正文或可探测路径。

#### Scenario: 安全拒绝与身份失效分别显示
- **WHEN** 请求因真实路径安全问题被拒绝，或因已确认的登录会话失效失败
- **THEN** 前者显示安全拒绝及诊断入口，后者提供重新授权；安全问题不因刷新或登录被宣称已恢复

#### Scenario: 合法目录遇到锁竞争
- **WHEN** 合法本人目录遇到可恢复锁竞争或服务暂不可用
- **THEN** 显示暂不可用及适当重试，不描述为目录被替换、不显示空列表、不自动清空数据
