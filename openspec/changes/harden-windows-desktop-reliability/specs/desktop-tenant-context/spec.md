## ADDED Requirements

### Requirement: 远程桌面连接与本机业务运行明确分离

Desktop 的 remote 模式 SHALL 使用用户明确配置的精确 HTTPS origin，由服务器承载 Agent 业务运行和服务器数据，不启动本机 Python 业务后端。客户端 SHALL 明示运行位置；普通远程连接不要求用户安装 Python、获取公网 IP 或开放本机公网入站端口。切换模式 SHALL 清理旧作用域并重新建立适用身份，不静默迁移数据或切换执行位置。

#### Scenario: 无本机 Python 的远程使用
- **WHEN** Windows 安装包配置兼容远程服务器并完成原生授权及 Web 配对，本机没有 Python
- **THEN** 聊天、流式回复及获权服务器页面可用，没有本机 Python 启动或依赖错误

#### Scenario: 远程服务器不可用
- **WHEN** 当前远程服务不可达或业务请求失败
- **THEN** 显示远程故障和服务器运行位置，不自动切换到本机后端或伪造本机历史

#### Scenario: 切换来源或运行模式
- **WHEN** 用户明确切换服务器 origin 或本机/远程模式
- **THEN** 旧身份、连接和迟到响应失效，依既有授权流程建立新上下文，旧请求不自动重放到新来源

### Requirement: 远程连接故障按原因诊断且探测有界

Desktop SHALL 对服务器 metadata、必需协议、证书、浏览器授权和 Web 配对使用有期限的探测或操作，并区分网络不可达、TLS 拒绝、协议不兼容、身份失效、服务能力关闭与可选设备通道故障。证书或协议失败 MUST NOT 降级 HTTP、跳过验证或反复引导登录；身份失效按原生授权恢复。可选设备能力故障 MUST NOT 把已正常的服务器聊天误报为全部未连接。

#### Scenario: 证书拒绝或旧协议
- **WHEN** 证书过期、不匹配或不受信，或服务器缺少兼容必需协议
- **THEN** 显示证书或升级原因，停止该连接阶段，不启动登录循环或降级传输

#### Scenario: 网络断开后恢复
- **WHEN** 有效远程连接经历短暂断网并恢复
- **THEN** 按有界退避恢复，保持当前身份重验和迟到响应隔离，不重复提交未确认写操作

#### Scenario: 设备网关不可达但服务器聊天正常
- **WHEN** 服务器页面与聊天可用，而可选设备网关握手失败
- **THEN** 只显示对应设备能力故障及部署诊断，不阻断正常服务器业务或要求重复登录

#### Scenario: 探测挂起或授权取消
- **WHEN** 服务器探测超时或用户取消浏览器授权
- **THEN** 结束本次操作、清理临时资源，显示可操作的超时或取消状态，不无限显示连接中
