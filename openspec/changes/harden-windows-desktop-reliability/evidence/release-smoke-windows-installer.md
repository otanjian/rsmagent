## 3. 过程中的两个插曲（都不是产品缺陷，记录以免误判）

1. **静默退出**：首次启动安装版时它"起来就退出、零输出、无日志"。原因是我这个 shell 里带着 **`ELECTRON_RUN_AS_NODE=1`**——Electron 被当成纯 Node 运行。清除后一切正常。这正是本 change 任务 2.4 记录并处理的那个陷阱（`dev-windows.ps1` 会在启动 Electron 的进程里清除它）；真实用户双击不受影响。
2. **窗口显示 Chromium 错误页**：打包版与开发运行**共用同一 userData**（`%APPDATA%\CowAgent`），其中记住了开发后端地址 `http://127.0.0.1:9899/knowledge`；打包版后端实际在 **9876**，故加载 9899 失败 → `chrome-error://chromewebdata/`。**以全新 `--user-data-dir` 复测（等价干净装机）后页面完全正常**（见上表"登录"）。→ 属**测试环境状态污染**，不是产品缺陷。
