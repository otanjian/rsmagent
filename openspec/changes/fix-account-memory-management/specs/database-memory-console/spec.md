## MODIFIED Requirements

### Requirement: 记忆浏览兼容入口明确个人和智能体作用域

系统 SHALL 以现有记忆管理页面及正式记忆接口提供同一列表、分页、类别、内容和管理动作，普通用户与管理员共用字段、流程和反馈。正式页面 SHALL 固定显示当前登录账号在当前有效租户内的个人记忆，MUST NOT 提供 Agent 或他人目标选择，MUST NOT 随当前聊天智能体变化而切换记忆归属。页面 SHALL 显示当前账号及个人归属说明；管理员访问此页同样仅管理本人记忆。

个人请求 SHALL 明确个人作用域，MUST NOT 自动附加 Agent 目标。缺少可信账号/租户、混合个人与 Agent 参数或错误目标 SHALL 明确拒绝，不得回落共享根、另一用户或默认智能体。读载荷 SHALL 按实际能力报告动作，页面不得广告必然被拒绝的写入。

旧客户端显式指定 Agent 的请求 SHALL 保留兼容字段、原实际目标及授权规则：普通用户仅可读取本人获准私有 Agent，管理共享目标仍需管理资格；与共享范围共根的写入要求对所有实际读取范围有资格。系统只读 Agent 类别不因角色变化转为可写。旧个人接口 SHALL 仅委托统一服务，不保留独立个人功能。

#### Scenario: 两种角色操作本人记忆
- **WHEN** 有效普通成员或管理员进入记忆管理
- **THEN** 页面自动显示其当前租户本人记忆，无 Agent 下拉框，使用相同列表、内容及获准管理动作

#### Scenario: 切换聊天智能体
- **WHEN** 同一租户同一账号切换到另一获准智能体后再次打开记忆管理
- **THEN** 返回相同个人记忆，不读新智能体工作区或共享根

#### Scenario: 本人浏览个人记忆
- **WHEN** 当前有效成员的个人根中已有记忆文件并进入正式页面
- **THEN** 无需选择目标即可查看本人条目及正文，使用与管理员相同的响应和交互

#### Scenario: 个人请求与通用请求处理组合
- **WHEN** 页面通过真实通用请求处理发出个人记忆列表、内容、保存、删除或清空请求
- **THEN** 发出的请求只含个人目标，保留登录及租户信息，不被自动添加 Agent 参数

#### Scenario: 混合目标被拒绝
- **WHEN** 请求同时指定个人作用域与 Agent 目标
- **THEN** 明确返回歧义目标错误，不静默忽略其中一个目标或访问任何替代根

#### Scenario: 普通用户请求共享目标
- **WHEN** 普通用户通过兼容参数指定共享记忆，即使拥有该共享智能体聊天使用权限
- **THEN** 管理访问被拒绝，不返回共享条目、统计或正文

#### Scenario: 成员请求写入与共享范围共根的智能体记忆
- **WHEN** 成员通过兼容入口对本人私有智能体的租户共享记忆根提交写入
- **THEN** 请求被拒绝且共享根不变，合法读取仍标明实际范围及不可用写动作

#### Scenario: 旧客户端目标明确
- **WHEN** 兼容客户端显式指定其有权读取或管理的原 Agent 目标
- **THEN** 返回原目标的兼容响应并明确实际作用域，不静默替换为本人或默认智能体

#### Scenario: 旧客户端指定智能体
- **WHEN** 旧客户端通过已支持的参数指定一个本人有权读取的智能体记忆目标
- **THEN** 响应保留兼容字段且正确标明作用域，不静默替换为默认智能体、本人个人域或其他共享根

### Requirement: 记忆浏览与个人写入使用同一内容版本

正式记忆管理、兼容入口、检索和后台固化 SHALL 使用同一真实归属、内容版本和恢复协议，不得复制独立 CRUD 或检索真值。个人编辑、删除和清空 SHALL 在当前账号与租户范围内重验权限、版本和 generation，覆盖长期/每日/主动记忆以及本人进化与梦境记录；共享 Agent 兼容写入仍须对实际根的所有读取范围具有资格。实际文件访问、索引屏蔽及失败重试 SHALL 遵守既有安全和版本协议，不能清空其他用户或共享根。

个人页面 SHALL 接通获准编辑、删除、清空和恢复动作，不得将本人数据固定标记只读。动作尚未开放或写入开关关闭时 SHALL 如实报告，不能将只读浏览描述为完整管理完成；本人获准读取、删除、清空和必要清理恢复 SHALL 不因新增/修改开关关闭而被锁死。索引待恢复 SHALL 如实呈现并提供重试，不伪报完整成功。

#### Scenario: 统一页面编辑后旧接口读取
- **WHEN** 用户在正式页面成功编辑本人条目，兼容接口随后读取
- **THEN** 返回同一版本，正式记忆的获准检索反映新版本，无第二套个人实现

#### Scenario: 个人页面编辑后旧入口读取
- **WHEN** 用户在正式记忆管理编辑本人条目后经旧个人入口读取
- **THEN** 返回同一版本，旧入口只委托统一服务，无独立个人实现

#### Scenario: 并发清空与索引失败
- **WHEN** 清空跨越旧固化或索引发布，或索引清理失败后重启
- **THEN** 过期内容不复活，未完成状态可恢复且如实呈现，不误清其他目标

#### Scenario: 清空后原入口和旧索引访问
- **WHEN** 本人清空完成后，原浏览入口、搜索或清空前排队的任务访问已清除内容
- **THEN** 不返回或恢复已删除正文，遵循同一版本协议且不影响共享记忆

#### Scenario: 撤回个人写入能力
- **WHEN** 个人记忆新增/修改能力被关闭
- **THEN** 页面及直接接口拒绝新增/修改，但仍可按原权限读取、删除、清空和恢复清理，不回落 Agent 目标

## ADDED Requirements

### Requirement: 个人记忆保留完整文档管理体验

个人记忆页面 SHALL 提供文件名、类型、大小、更新时间及分页，保留长期记忆与每日/主动记忆分类，并在“自主进化”合并展示本人进化记录和梦境日记。条目标识 SHALL 唯一地区分不同分类的同名文件。本人四类 Markdown 文件 SHALL 支持正文渲染、编辑、保存、退出编辑、Ctrl/Cmd+S、未保存提醒和并发修改冲突反馈。修改进化或梦境记录文本 MUST NOT 被当作撤销进化操作。

#### Scenario: 浏览两类标签
- **WHEN** 本人有长期记忆、每日记忆以及同日期的进化和梦境文件
- **THEN** 两个标签分别展示相应列表和分页，点击同名记录时打开各自正确正文

#### Scenario: 编辑与快捷保存
- **WHEN** 本人修改任意获准 Markdown 条目并使用按钮或 Ctrl/Cmd+S 保存
- **THEN** 保存后的正文、版本、大小和更新时间一致，退出编辑后显示新正文

#### Scenario: 离开未保存编辑
- **WHEN** 本人在同一身份下切换标签、文件、页面或关闭含未保存编辑的界面
- **THEN** 系统提供丢弃提醒，不静默丢失草稿；确认丢弃后才完成正常页面内切换

#### Scenario: 编辑期间后台更新
- **WHEN** 页面提交基于旧版本的修改，而后台已发布新版本
- **THEN** 返回冲突并保留草稿，可重新加载或明确确认基于最新版本重新提交，不能无条件覆盖

#### Scenario: 编辑进化记录
- **WHEN** 本人保存进化或梦境记录文本
- **THEN** 只更新对应记录，不触发备份恢复或撤销实际进化改动

### Requirement: 个人页面区分数据状态并隔离账号切换

页面 SHALL 分别展示加载中、真实空数据、请求失败、无权限及索引待恢复状态；只有成功响应确认为零条目时 SHALL 显示“暂无记忆”。账号、租户或登录态变化时 SHALL 清除旧列表、正文及编辑上下文，使旧请求的迟到结果失效；旧身份打开的草稿 MUST NOT 在新身份下保存。

#### Scenario: 加载失败不显示空态
- **WHEN** 请求因网络、服务错误、身份失效或作用域冲突失败
- **THEN** 显示相应错误及适当的重试或重新登录入口，不显示为账号没有记忆

#### Scenario: 新账号没有记忆
- **WHEN** 成功读取本人范围且不存在任何该分类条目
- **THEN** 显示真实空态及记忆产生方式说明，不制造空白记忆文件充数

#### Scenario: 切换后旧请求返回
- **WHEN** 账号或租户切换完成后旧记忆请求返回
- **THEN** 旧响应不覆盖新列表或正文，旧编辑上下文不可向新身份提交

### Requirement: 个人清空明确范围且兼容历史调用

正式页面“清空我的记忆” SHALL 明确告知当前账号/租户及受影响分类，并经用户确认后删除本人长期、每日、主动记忆以及进化和梦境记录；操作 SHALL 使用这些分类的集合版本并清理相关派生索引、失效旧发布者。聊天历史、个人人设、技能、进化备份、Agent 共享文件和他人数据 MUST NOT 被删除。旧客户端未显式请求全分类清空时 SHALL 保持原 memory 分类清空范围，不得升级即扩大删除范围。

#### Scenario: 清空本人全部记忆
- **WHEN** 用户确认全分类清空且集合版本仍有效
- **THEN** 本人两个标签对应的文件被清除，相关旧检索结果不可返回，范围外数据保持不变

#### Scenario: 清空前集合发生变化
- **WHEN** 确认清空时使用的集合版本已经过期
- **THEN** 返回冲突并要求刷新确认范围，不删除确认之后新增或更新的文件

#### Scenario: 旧清空调用不扩大范围
- **WHEN** 旧客户端提交原有清空请求而未显式指定全分类
- **THEN** 仍仅清理原 memory 分类，保留其原本不涉及的进化与梦境记录
